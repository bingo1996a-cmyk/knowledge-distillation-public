# 数学知识库

这个子库位于 `知识蒸馏计划/数学/` 之下，目标不是做一本单线教材，也不是做某个专业的速查手册，而是逐步形成一套可扩展、可离线阅读、可按对象 / 方法 / 应用 / 路径切换的数学知识工程。

当前版本继续沿两条主线并行扩写：

1. **控制 / 优化 / 随机系统高阶链**  
   服务控制、强化学习、运筹、估计、系统工程、风险决策、多主体与安全自主方向。
2. **去偏科主线**  
   持续补代数、几何、分析、数论、逻辑、拓扑、范畴论、表示论、PDE、泛函分析、计算理论、社会科学与制度分析入口，避免知识库收缩成单一专业手册。

## 已成形主线一览

知识库沿 9 条主线展开，每条主线都连接了分支总览、核心概念与关键方法：

1. **基础与证明线**：从集合、证明到逻辑基础与类型论
2. **分析与空间线**：从实分析、测度论到泛函分析、PDE 与随机分析
3. **代数与抽象结构线**：从群环域到 Lie 理论、表示论、范畴论
4. **几何与拓扑**：从微分几何到代数拓扑
5. **概率、统计与因果**：从概率论、统计推断到图模型、因果推断
6. **优化与数值**：从凸优化、线性规划到 ADMM、分布鲁棒优化
7. **控制、估计与决策**：从状态空间、滤波到 MPC、安全强化学习
8. **网络、博弈与多主体**：从博弈论到均值场博弈、机制设计
9. **逻辑、计算与验证**：从数理逻辑、可计算性到依赖类型、程序验证

详细映射见 [分支-概念-方法映射表](./07-参考/分支概念方法映射.md)。
