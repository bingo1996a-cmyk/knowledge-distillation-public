## 建模的一般流程

```
现实问题 → 提取关键变量与关系 → 数学表述（方程/优化/概率）
    → 求解（解析/数值/定性） → 验证（数据拟合/预测检验） → 改进
```

## 前置知识

- 微积分（导数、积分、微分方程）
- 线性代数（矩阵、特征值）
- 概率统计（分布、估计、随机过程）
- 基础编程（Python/Matlab 数值计算）

## 与其他路径的交叉

- **算法路径**：数值算法是 PDE 和优化模型的计算实现
- **控制/优化路径**：最优控制 = 动态系统的优化建模
- **数据科学路线**：统计模型 → 数据驱动建模
