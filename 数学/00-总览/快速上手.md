# 数学知识库快速上手

## 一分钟定位

数学知识库目前有 **~360 篇笔记**，覆盖 40 个数学分支、70 个核心概念、~140 个定理/方法和 15 个完整案例。

## 第一步：选入口

| 你的背景 | 推荐入口 |
|---------|---------|
| 想先看整体地图 | [知识库说明](知识库指南.md) -> [数学总地图](数学总地图.md) |
| 想系统学习某方向 | [阅读路径](阅读路径.md) -> 对应学习路线 |
| 想查某个概念 | [按概念索引](../08-索引/按概念索引.md) |
| 想查某个方法 | [方法分类索引](../03-定理与方法/README.md) |
| 想了解数学思想史 | [数学思想](../06-思想史与文化/数学思想.md) |
| 想看具体领域建模 | [数学建模库](../10-数学建模/README.md) — 15个领域的数学模型 |
| 想学经典与现代算法 | [算法库](../11-算法/README.md) — 排序/DP/图/随机化/ML/密码 |

## 第二步：选路线

知识库提供 19 条学习路径，覆盖从初等到专业的不同目标：
- 初等：[初等数学路线](../05-学习路径/初等数学.md)
- 通识：[广度优先通识路线](../05-学习路径/广度优先通识.md)
- 工程：[工程路线](../05-学习路径/工程.md)
- 计算机：[计算机路线](../05-学习路径/计算机科学.md)
- 控制/优化：[控制与运筹路线](../05-学习路径/控制AI与运筹学.md)
- 纯数学：[纯数学路线](../05-学习路径/纯数学.md)
- 案例实战：[案例库](../09-案例库/README.md)
- 更多路径见 [阅读路径](阅读路径.md)

## 第三步：交叉阅读

知识库的核心结构是分层组织，但建议阅读时跨层回链：
- 分支总览(`01-分支`) -> 核心概念(`02-核心概念`) -> 定理/方法(`03-定理与方法`)
- 应用入口(`04-应用`) 是理解"数学能做什么"的快捷方式
- 案例库(`09-案例库`) 提供完整的问题→建模→代码→解读流程

## 注意事项

- 知识库仍在持续扩写，部分条目为骨架而非定稿
- 每个条目都有"待补充"标记当前已知缺口
- 建议从总览出发，选 1-2 条主线深入，不要一次性读完全部
