# 案例 12：PDE 弱解的 1D 有限元实例

## 问题陈述

求解一维 Poisson 方程：
$$
-u''(x) = f(x) \quad\text{在 }(0,1)\text{ 上},\quad u(0)=0,\; u(1)=0
$$
其中 $f(x)=2$（常数载荷）。精确解为 $u(x)=x(1-x)$（抛物线，两端为零，中间最高）。

用有限元方法离散化这个最简单的 PDE，展示"弱形式→Galerkin 逼近→线性系统→数值解"的完整流程。

## 数学建模

### 弱形式

乘测试函数 $v$（满足 $v(0)=v(1)=0$）并分部积分：
$$
\int_0^1 u'(x)v'(x)\,dx = \int_0^1 f(x)v(x)\,dx \quad \forall v
$$

这是原 PDE 的弱形式——从逐点满足变为积分意义下满足。

### Galerkin 有限元

将 $(0,1)$ 均匀划分为 $n$ 个单元（$h=1/n$）。使用分段线性"帽函数" $\phi_i(x)$ 作为基函数：
- $\phi_i(x_j)=\delta_{ij}$（在节点 $i$ 处为 1，其他节点为 0）
- 在相邻节点间线性变化

近似解：$u_h(x)=\sum_{j=1}^{n-1} u_j \phi_j(x)$（$n-1$ 个内部节点未知量）

代入弱形式，取 $v=\phi_i$，得线性系统 $Au=f$：
- $A_{ij}=\int\phi_i'\phi_j'\,dx$（刚度矩阵，三对角）
- $f_i=\int f\phi_i\,dx$（载荷向量）

### 刚度矩阵与载荷

标准结果（均匀网格 $h$）：
$$
A = \frac{1}{h}\begin{pmatrix}
2 & -1 & & \\
-1 & 2 & -1 & \\
& \ddots & \ddots & \ddots \\
& & -1 & 2
\end{pmatrix},\quad f_i = \int_0^1 f(x)\phi_i(x)\,dx
$$

对于 $f(x)=2$：$f_i = 2h$（常数载荷的帽函数积分 = 底×高/2 ×2 = $h$... 精确计算得 $f_i = 2h$）。

## 数值实现（伪代码）

```python
import numpy as np

n = 5  # 单元数（内部节点 n-1 = 4 个未知量）
h = 1.0 / n
x_nodes = np.linspace(0, 1, n+1)

# 组装刚度矩阵 A (n-1 x n-1)
A = np.zeros((n-1, n-1))
for i in range(n-1):
    A[i,i] = 2.0 / h
    if i > 0:
        A[i,i-1] = -1.0 / h
    if i < n-2:
        A[i,i+1] = -1.0 / h

# 载荷向量 f_i = int_0^1 2*phi_i dx
f = 2 * h * np.ones(n-1)

# 求解
u_inner = np.linalg.solve(A, f)
u_fem = np.zeros(n+1)
u_fem[1:-1] = u_inner  # 边界值为0

# 精确解
u_exact = x_nodes * (1 - x_nodes)

print("Node   FEM        Exact      Error")
for i in range(n+1):
    print(f"x={x_nodes[i]:.1f}  {u_fem[i]:.6f}  {u_exact[i]:.6f}  {abs(u_fem[i]-u_exact[i]):.2e}")

# 输出（分段线性有限元对二次函数是精确的！）:
# Node   FEM        Exact      Error
# x=0.0  0.000000  0.000000  0.00e+00
# x=0.2  0.160000  0.160000  0.00e+00
# x=0.4  0.240000  0.240000  0.00e+00
# x=0.6  0.240000  0.240000  2.78e-17
# x=0.8  0.160000  0.160000  0.00e+00
# x=1.0  0.000000  0.000000  0.00e+00
```

## 结果解释

- **节点击中**：分段线性有限元对 Poisson 方程 $f=\text{const}$ 在节点上给出了精确解（误差为零至机器精度）——因为真解是二次函数，而分段线性基的 Galerkin 投影在网格尺寸 $h\to0$ 时给出最优逼近
- **刚度矩阵稀疏性**：$A$ 是三对角矩阵——大型有限元计算的核心优势是稀疏线性系统的高效求解
- **收敛阶**：$\|u-u_h\|_{L^2}=O(h^2)$，$\|u'-u_h'\|_{L^2}=O(h)$。二分网格 → $L^2$ 误差减至 1/4

## 局限性

- **1D 玩具问题**：真实 PDE 在 2D/3D 上需处理网格生成和稀疏线性系统求解器
- **低阶基**：分段线性基对外力不连续的 PDE 精度不足（需要更高阶或自适应网格）
- **仅椭圆型**：抛物和双曲 PDE 需时间离散 + 空间有限元的结合
