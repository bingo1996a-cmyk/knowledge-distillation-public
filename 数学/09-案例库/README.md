# 数学案例库

本目录收录中等深度的完整数学案例，每个案例按统一格式编写：

```
问题陈述 → 数学建模 → 方法选择 → 数值/计算实现（伪代码） → 结果解释 → 局限性
```

目标：连接"概念-方法"与"实际使用"，展示数学如何从问题出发，经过建模和计算，回到对问题的解答。
