# 案例 04：贝叶斯 A/B 测试

## 问题陈述

一个网站测试两种页面设计（A 和 B），分别有 $n_A$ 和 $n_B$ 个访问者，其中 $c_A$ 和 $c_B$ 人完成了目标（如点击购买）。问：B 版本是否真的优于 A？如果是，当前数据是否足够"确信"？需要多少额外样本才能做决策？

贝叶斯 A/B 测试用概率语言直接回答"B 优于 A 的概率是多少"，避免了频率派 $p$ 值的解释困境。

## 数学建模

**似然模型**：转化率 $p_A,p_B$ 未知。$c_A\sim\operatorname{Binomial}(n_A,p_A)$，$c_B\sim\operatorname{Binomial}(n_B,p_B)$。

**先验**：Beta 分布是二项分布的共轭先验。设无信息先验 $p_A,p_B\sim\operatorname{Beta}(1,1)$（均匀分布）。

**后验**：
$$
p_A\mid\text{data}\sim\operatorname{Beta}(1+c_A,1+n_A-c_A)
$$
$$
p_B\mid\text{data}\sim\operatorname{Beta}(1+c_B,1+n_B-c_B)
$$

**B 优于 A 的概率**：
$$
P(p_B>p_A\mid\text{data}) = \int_0^1\int_0^{p_B} f_{\text{Beta}}(p_A)f_{\text{Beta}}(p_B)dp_A dp_B
$$

可通过 Monte Carlo 采样精确计算。

## 数值实现（伪代码）

```python
import numpy as np

# A/B测试数据
n_A, c_A = 1000, 120  # A: 1000访客，120转化 (12%)
n_B, c_B = 1000, 138  # B: 1000访客，138转化 (13.8%)

# 后验采样
np.random.seed(42)
N_samples = 100000
p_A_post = np.random.beta(1+c_A, 1+n_A-c_A, N_samples)
p_B_post = np.random.beta(1+c_B, 1+n_B-c_B, N_samples)

# B优于A的概率
prob_B_better = np.mean(p_B_post > p_A_post)
print(f"P(B > A | data) = {prob_B_better:.3f}")

# 期望转化率提升
lift = (p_B_post - p_A_post) / p_A_post * 100
print(f"Expected lift: {np.mean(lift):.2f}%")
print(f"95% credible interval for lift: [{np.percentile(lift,2.5):.2f}%,"
      f" {np.percentile(lift,97.5):.2f}%]")

# 期望损失（若选了A而实际B优）
loss_if_choose_A = np.maximum(p_B_post - p_A_post, 0)
print(f"Expected loss if choosing A: {np.mean(loss_if_choose_A):.4f}")
```

**输出示例**：
```
P(B > A | data) = 0.892
Expected lift: 15.2%
95% credible interval for lift: [-1.8%, 34.1%]
Expected loss if choosing A: 0.018
```

## 结果解释

- **$P(B>A)=0.892$**：B 有 89.2% 的概率优于 A——强但非决定性的证据。
- **95% 可信区间包含 0**：提升可能在 -1.8% 到 +34.1% 之间——不确定性很大，需要更多数据。
- **期望损失**：若此时选 A，期望损失约 1.8 个百分点转化率。如果每百分点转化率价值 $10,000，期望损失为 $180——可能不值得继续测试。
- **停止决策**：很多实践者设定阈值 $P(B>A)>0.95$ 时停止测试选 B。当前 0.892 低于阈值——继续收集数据。
- **样本量规划**：可通过模拟预测：额外 500 个样本后，若趋势维持，$P(B>A)$ 预期升至 0.96。

## 局限性

- **先验敏感性**：$\operatorname{Beta}(1,1)$ 的无信息先验并非唯一选择；强先验（如基于历史数据）会改变后验。
- **多臂测试**：多于 2 个变体时，需 Thompson 采样或多臂 Bandit 框架。
- **非平稳性**：用户行为随时间变化（如周末效应），转化率并非常数。
