# 案例 05：排队系统 M/M/1 性能分析

## 问题陈述

一个客服中心只有 1 个服务台。客户到达服从 Poisson 过程（平均 $\lambda$ 人/小时），服务时间服从指数分布（平均 $1/\mu$ 小时/人）。问：
1. 客户平均等待多长时间？
2. 系统中平均有多少客户（等待 + 被服务）？
3. 服务台空闲的时间比例是多少？
4. 当服务率 $\mu$ 接近到达率 $\lambda$ 时，系统会怎样？

这是排队论中最基本、最重要的模型。

## 数学建模

M/M/1 队列的 Kendall 符号：M = Markov（Poisson 到达 + 指数服务），1 = 1 个服务台。

**状态**：$n$ = 系统中的客户数（含正在服务的）。转移率为生灭过程：

- 从 $n$ 到 $n+1$：速率 $\lambda$（客户到达）
- 从 $n$ 到 $n-1$：速率 $\mu$（服务完成，$n\ge1$）

**流量强度**：$\rho=\lambda/\mu$（系统负载比）。$\rho<1$ 是稳态存在的充要条件。

**稳态分布**：解平衡方程得几何分布：
$$
\pi_n = P(\text{系统中有}n\text{个客户}) = (1-\rho)\rho^n
$$

## 关键性能指标

| 指标 | 公式 | 含义 |
|------|------|------|
| 平均系统人数 | $L = \frac{\rho}{1-\rho}$ | 系统中平均总人数 |
| 平均排队人数 | $L_q = \frac{\rho^2}{1-\rho}$ | 等待队列的平均长度 |
| 平均逗留时间 | $W = \frac{1}{\mu-\lambda}$ | 客户在系统中的平均总时间 |
| 平均等待时间 | $W_q = \frac{\rho}{\mu-\lambda}$ | 客户在队列中的平均等待时间 |
| 空闲概率 | $\pi_0 = 1-\rho$ | 系统为空的概率 |

**Little 定律**：$L=\lambda W$，$L_q=\lambda W_q$。这是一个不依赖 M/M/1 假设的普遍规律。

## 数值实现（伪代码）

```python
import numpy as np

# 参数
lmbda = 10   # 到达率：10人/小时
mu = 12      # 服务率：12人/小时
rho = lmbda / mu

if rho >= 1:
    print("系统不稳定！")
else:
    L = rho / (1 - rho)            # 平均系统人数
    Lq = rho**2 / (1 - rho)        # 平均排队人数
    W = 1 / (mu - lmbda)           # 平均逗留时间（小时）
    Wq = rho / (mu - lmbda)        # 平均等待时间（小时）
    pi0 = 1 - rho                  # 空闲概率

    print(f"流量强度 ρ = {rho:.3f}")
    print(f"空闲概率   = {pi0:.1%}")
    print(f"平均系统人数 L = {L:.1f} 人")
    print(f"平均排队人数 Lq = {Lq:.1f} 人")
    print(f"平均逗留时间 W = {W*60:.1f} 分钟")
    print(f"平均等待时间 Wq = {Wq*60:.1f} 分钟")

# 输出:
# 流量强度 ρ = 0.833
# 空闲概率   = 16.7%
# 平均系统人数 L = 5.0 人
# 平均排队人数 Lq = 4.2 人
# 平均逗留时间 W = 30.0 分钟
# 平均等待时间 Wq = 25.0 分钟
```

## 结果解释

- **$\rho=0.833$**：系统 83.3% 的时间在忙，16.7% 空闲——负载较重但可持续。
- **平均等待 25 分钟**：若服务标准要求在 2 分钟内响应，需要增加服务台或提高服务率。
- **当 $\rho\to 1$** 时：$L\to\infty$，等待时间爆炸式增长。例如 $\rho=0.99$ 时 $L=99$ 人——仅多 1% 负载就使系统从可管理变为瘫痪。这是排队论最关键的洞见：**负载越高，拥堵对负载越敏感**。
- **$L=5$**：平均每天有 5 人在系统中。经理需安排约 5 人的等待区域。

## 敏感性分析

| $\rho$ | $L$ | $W$ (分钟) |
|-------|-----|-----------|
| 0.5 | 1.0 | 6.0 |
| 0.8 | 4.0 | 24.0 |
| 0.9 | 9.0 | 54.0 |
| 0.95 | 19.0 | 114.0 |
| 0.99 | 99.0 | 594.0 |

当 $\rho$ 从 0.8 升到 0.9，等待时间翻倍——非线性爆炸。

## 局限性

- **M/M/1 假设**：实际到达可能非 Poisson（如批到达、预约），服务时间可能非指数（如定长服务）
- **单服务台**：扩展到 M/M/c（多服务台）更符合实际
- **无限队列假设**：真实系统中队列容量有限
