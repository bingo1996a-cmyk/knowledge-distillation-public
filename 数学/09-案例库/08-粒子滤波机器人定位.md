# 案例 08：粒子滤波——机器人定位

## 问题陈述

一个机器人在已知的二维地图中移动，装备了一个能测量到几个已知地标距离的传感器。运动有噪声（轮子打滑），传感器也有噪声。机器人需要从含噪观测中实时估计自己的位置 $(x,y)$ 和朝向 $\theta$——这是移动机器人学中最基础的定位问题。

## 数学建模

**状态**：$x_t = (x_t, y_t, \theta_t)^\top$

**运动模型**（里程计，带噪声）：
$$
x_{t+1} = \begin{pmatrix}x_t + v_t\Delta t\cos\theta_t\\ y_t + v_t\Delta t\sin\theta_t\\ \theta_t + \omega_t\Delta t\end{pmatrix} + w_t
$$
其中 $w_t\sim\mathcal{N}(0,Q)$，$v_t$ 是线速度，$\omega_t$ 是角速度。

**观测模型**（到 $K$ 个地标的距离）：
$$
z_t^k = \sqrt{(x_t - m_x^k)^2 + (y_t - m_y^k)^2} + v_t^k
$$
其中 $v_t^k\sim\mathcal{N}(0,R)$。

## 方法选择：粒子滤波（Particle Filter）

当运动或观测模型非线性时，Kalman 滤波的线性假设失效。粒子滤波用一组带权重的"粒子"（假设状态）来近似后验分布：

1. **预测**：每个粒子按运动模型 + 随机噪声向前传播
2. **更新**：根据观测给粒子赋权重（似然越高的粒子权重越大）
3. **重采样**：按权重重新采样粒子（防止权重退化）

## 数值实现（伪代码）

```python
import numpy as np

# 地标位置（已知）
landmarks = np.array([[2, 2], [8, 2], [5, 8]])

# 运动模型（添加噪声）
def motion_model(x, v, w, dt, Q):
    x_new = np.zeros_like(x)
    x_new[:,0] = x[:,0] + v*dt*np.cos(x[:,2])
    x_new[:,1] = x[:,1] + v*dt*np.sin(x[:,2])
    x_new[:,2] = x[:,2] + w*dt
    # 添加过程噪声
    x_new += np.random.randn(*x.shape) @ np.linalg.cholesky(Q)
    return x_new

# 观测似然
def measurement_likelihood(particles, z, R):
    weights = np.ones(len(particles))
    for k, (zx, zy) in enumerate(z):
        dx = particles[:,0] - zx
        dy = particles[:,1] - zy
        dist = np.sqrt(dx**2 + dy**2)
        # 高斯似然（假设观测了距离到地图匹配点）
        # 简化：直接用距离误差
    return weights

# 粒子滤波主循环
N_particles = 1000
particles = np.random.rand(N_particles, 3) * 10  # 初始均匀分布
particles[:,2] = np.random.rand(N_particles) * 2*np.pi
weights = np.ones(N_particles) / N_particles

dt, Q, R = 0.1, np.diag([0.01, 0.01, 0.001]), 0.1

for t in range(100):
    # 1. 预测（运动更新）
    v, w = 1.0, 0.05  # 控制输入
    particles = motion_model(particles, v, w, dt, Q)
    
    # 2. 更新（观测修正）
    # 对每个粒子计算到最近地标的距离
    for i in range(N_particles):
        dists = np.sqrt(np.sum((landmarks - particles[i,:2])**2, axis=1))
        min_dist = np.min(dists)
        # 高斯似然
        weights[i] = np.exp(-min_dist**2 / (2*R))
    weights /= weights.sum()
    
    # 3. 重采样（系统重采样）
    if 1/np.sum(weights**2) < N_particles/2:  # 有效粒子数阈值
        idx = np.random.choice(N_particles, N_particles, p=weights)
        particles = particles[idx]
        weights = np.ones(N_particles) / N_particles
    
    # 4. 估计
    x_est = np.average(particles, weights=weights, axis=0)
    cov_est = np.cov(particles.T, aweights=weights)
```

## 结果解释

- **粒子多样性**：初始粒子分散（高不确定性），随运动和观测逐渐聚集到真实位置附近。
- **重采样**：权重退化时（少数粒子权重极高），重采样恢复多样性。阈值控制何时重采样。
- **非线性处理**：粒子滤波无需线性化，直接在原始非线性模型上工作——代价是 $N$ 越大越精确但越慢。

## 局限性

- **粒子数量**：高维状态需指数级粒子（维数诅咒）——实际中状态维数 > 10 时粒子滤波可能失效
- **提议分布**：标准的运动模型作为提议分布可能导致低效采样（改进：Rao-Blackwellized PF）
- **传感器模型**：需要准确的似然模型——多峰观测需要足够多粒子覆盖
