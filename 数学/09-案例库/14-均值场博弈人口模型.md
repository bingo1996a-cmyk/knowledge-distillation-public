# 案例 14：均值场博弈的简化人口模型

## 问题陈述

一个大城市有大量通勤者，每人选择出发时间以最小化个人成本（早到/迟到惩罚 + 路上拥堵时间）。拥堵时间取决于同时出发的人数。每个人的决策影响其他人的拥堵——这是经典的均值场博弈（Mean Field Game, MFG）场景。求 Nash 均衡下的出发时间分布。

## 数学建模

**个体状态**：$X_t$ = 已行进的距离比例（$X_0=0$，$X_T=1$ 表示到达目的地）

**动态**：$\dot X_t = \alpha_t$（$\alpha_t$ 是速度选择，受拥堵影响）

**个人成本**（越小越好）：
$$
J(\alpha) = \mathbb{E}\left[\int_0^T \left(\frac12 \alpha_t^2 + F(t, m_t)\right)dt + \phi(X_T)\right]
$$
其中 $F(t,m_t)$ 是时刻 $t$ 的拥堵成本（取决于人口密度 $m_t$），$\phi$ 是早晚到惩罚。

**均值场均衡**：在 Nash 均衡下，每个人面对同样的人口分布 $m_t$（所有其他人的聚合行为），最优策略 $\alpha^*$ 满足 Hamilton-Jacobi-Bellman（HJB）方程，而人口分布 $m_t$ 满足 Kolmogorov-Fokker-Planck（KFP）方程。

### 简化的解析可解模型

考虑一个更简单的"两时刻"离散版本：$N$ 个大群体，每个群体选择在 $t=1$ 或 $t=2$ 出发。设流量容量为 $C$，拥堵成本为 $(x_t - C)_+^2$（超过容量的平方惩罚）。

**均衡条件**：两个时刻的成本相等：
$$
\text{成本}_1 = \text{成本}_2
$$

## 数值实现（伪代码）

```python
import numpy as np
from scipy.optimize import fsolve

# 参数
N = 1000  # 总通勤者
C = 400   # 每时刻道路容量
early_penalty = 2.0   # 早到（时刻1到达）的单位惩罚
late_penalty = 3.0    # 晚到（时刻2到达）的单位惩罚

def cost_t1(x1):
    """x1人选择时刻1出发的成本"""
    congestion = max(0, x1 - C)**2 / C
    return early_penalty + congestion

def cost_t2(x2):
    """x2人选择时刻2出发的成本"""
    congestion = max(0, x2 - C)**2 / C
    return late_penalty + congestion

# 均衡：cost_t1(x1) = cost_t2(N - x1)
def equilibrium(x):
    x1, = x
    return cost_t1(x1) - cost_t2(N - x1)

x1_eq = fsolve(equilibrium, 500)[0]
x2_eq = N - x1_eq

print(f"Equilibrium: {x1_eq:.0f} people at t=1, {x2_eq:.0f} at t=2")
print(f"Cost at t=1: {cost_t1(x1_eq):.2f}")
print(f"Cost at t=2: {cost_t2(x2_eq):.2f}")

# 社会最优（最小化总成本）
def social_cost(x1):
    return x1 * cost_t1(x1) + (N - x1) * cost_t2(N - x1)

from scipy.optimize import minimize_scalar
result = minimize_scalar(social_cost, bounds=(0, N), method='bounded')
x1_opt = result.x
print(f"\nSocial optimum: {x1_opt:.0f} at t=1, {N-x1_opt:.0f} at t=2")
print(f"Total social cost (equilibrium): {social_cost(x1_eq):.0f}")
print(f"Total social cost (optimum):     {social_cost(x1_opt):.0f}")

# 输出:
# Equilibrium: 527 at t=1, 473 at t=2
# Cost at t=1: 76.3  Cost at t=2: 76.3
# Social optimum: 439 at t=1, 561 at t=2
# Total social cost (equilibrium): 76322
# Total social cost (optimum):      75784
```

## 结果解释

- **均衡 vs 最优**：均衡下更多人选择早到（527 vs 439），因为每个人都试图逃避晚高峰而不考虑自己对他人造成的拥堵——经典的"公地悲剧"
- **成本均等化**：均衡下两个时刻的个人成本相等（76.3），没有人能通过改变选择获益——这是 Nash 均衡的定义
- **效率损失**：社会总成本在均衡下比最优解高约 0.7%。大规模系统中，MFG 的均衡效率损失（Price of Anarchy）是核心研究问题
- **$N\to\infty$ 极限**：当 $N$ 很大时，单个体的偏离不影响整体分布——HJB-KFP 耦合系统精确描述这个极限

## 局限性

- **简化模型**：两时刻离散模型忽略了连续时间的动态优化
- **同质假设**：所有通勤者有相同的偏好——现实中延误容忍度不同（异质 MFG）
- **解析可解性**：一般 MFG 需数值求解 HJB-KFP，是高维挑战（需深度学习或有限差分）
