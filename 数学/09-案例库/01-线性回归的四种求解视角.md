# 案例 01：线性回归的四种求解视角

## 问题陈述

给定 $n$ 个数据点 $(x_i,y_i)$（$i=1,\dots,n$），$x_i\in\mathbb{R}^d$，$y_i\in\mathbb{R}$。求参数向量 $\beta\in\mathbb{R}^d$ 最小化残差平方和：

$$
\min_\beta \sum_{i=1}^n (y_i - x_i^\top\beta)^2 = \|y - X\beta\|_2^2
$$

这是最经典的统计学习问题。同一个目标函数有四种截然不同的求解路径，分别揭示了线性回归的几何、代数和数值本质。

## 数学建模

设 $X\in\mathbb{R}^{n\times d}$ 为设计矩阵，$y\in\mathbb{R}^n$。目标：

$$
\hat\beta = \arg\min_\beta \|y-X\beta\|^2
$$

### 视角一：正规方程（微积分）

令梯度为零：$\nabla_\beta\|y-X\beta\|^2 = -2X^\top(y-X\beta)=0$，得

$$
X^\top X \hat\beta = X^\top y
$$

直接求解 $d\times d$ 线性系统。计算复杂度 $O(nd^2+d^3)$。

### 视角二：QR 分解（数值稳定性）

设 $X=QR$，其中 $Q\in\mathbb{R}^{n\times d}$ 列正交，$R\in\mathbb{R}^{d\times d}$ 上三角。则

$$
\hat\beta = R^{-1} Q^\top y
$$

避免显式构造 $X^\top X$（条件数不平方），数值更稳定。

### 视角三：SVD / 伪逆（完全谱分解）

设 $X=U\Sigma V^\top$（SVD），则

$$
\hat\beta = V\Sigma^+ U^\top y = (X^\top X)^{-1}X^\top y
$$

SVD 揭示了 $X$ 的奇异性结构，适合处理病态和秩亏情形。

### 视角四：梯度下降（迭代优化）

$$
\beta^{(k+1)} = \beta^{(k)} - \alpha X^\top(X\beta^{(k)}-y)
$$

适合 $n$ 极大或 $d$ 极大的场景（SGD 变体）。收敛速度取决于 $X^\top X$ 的条件数。

## 数值实现（伪代码）

```python
import numpy as np

# 生成数据
n, d = 100, 3
X = np.random.randn(n, d)
beta_true = np.array([2.0, -1.5, 0.5])
y = X @ beta_true + 0.1 * np.random.randn(n)

# 方法1: 正规方程
beta_ne = np.linalg.solve(X.T @ X, X.T @ y)

# 方法2: QR分解
Q, R = np.linalg.qr(X)
beta_qr = np.linalg.solve(R, Q.T @ y)

# 方法3: SVD/伪逆
U, S, Vt = np.linalg.svd(X, full_matrices=False)
beta_svd = Vt.T @ np.diag(1/S) @ U.T @ y

# 方法4: 梯度下降
beta = np.zeros(d)
lr = 0.01
for k in range(1000):
    grad = -X.T @ (y - X @ beta)
    beta -= lr * grad
beta_gd = beta

print(f"True:     {beta_true}")
print(f"NormalEq: {beta_ne}")
print(f"QR:       {beta_qr}")
print(f"SVD:      {beta_svd}")
print(f"GradDesc: {beta_gd}")
```

## 结果解释

- **条件数好的数据**（$\kappa(X^\top X)$ 小）：四种方法给出几乎相同结果。正规方程最快，但条件数平方可能引入误差。
- **接近共线的数据**（$\kappa$ 大）：正规方程失稳，QR 和 SVD 保持稳定。SVD 可显式识别零奇异值（秩亏）。
- **大规模数据**（$n\gg d$ 或 $d$ 极大）：梯度下降（SGD）是唯一可行选择。

## 局限性

- 线性假设：$y\approx X\beta$ 在非线性关系中失效
- 异方差性：误差方差恒定假设不成立时需加权最小二乘
- 离群值：平方损失对离群值敏感，可改用 Huber 损失或 L1 正则化
- 高维：$d>n$ 时需要正则化（Ridge/Lasso）
