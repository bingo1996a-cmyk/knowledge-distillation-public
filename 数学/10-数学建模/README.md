## 建模的一般方法论

1. **问题抽象**：从物理/工程/社会现象中提取关键变量和关系
2. **数学表述**：用微分方程、优化问题或概率模型刻画
3. **求解与分析**：解析解、数值解或定性分析
4. **验证与校准**：用数据检验模型参数和预测能力
5. **局限与改进**：识别模型假设的边界，增加复杂性
