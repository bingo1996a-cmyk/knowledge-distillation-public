# 变分消息传递与稀疏图优化

## 作用

这一条目研究如何在大规模图结构上做近似推断与优化。变分消息传递（Variational Message Passing, VMP）提供概率近似推断框架，稀疏图优化则利用局部依赖带来的稀疏结构提高数值效率。

## 一个因子分解起点

$$
p(x) \propto \prod_{a\in \mathcal A} f_a(x_a)
$$

若联合分布或目标函数可以按局部因子分解，就有机会通过消息传递、块坐标更新或稀疏线性代数实现高效求解。

## 为什么重要

### 1. 它把“大问题”拆成局部关系网络

### 2. 它连接概率推断、优化、图计算和数值线性代数

### 3. 它在 SLAM、视觉、编码、贝叶斯网络和科学计算中都高复用

## 最小例子

### 问题陈述
考虑一个简单的高斯图模型：$x_1 \sim \mathcal{N}(0, 1)$，$x_2 \mid x_1 \sim \mathcal{N}(x_1, 2)$。用变分消息传递（VMP）近似推断后验 $p(x_1, x_2 \mid y)$ 并求边后验均值。

### 数学表达
联合分布 $p(x_1) p(x_2 \mid x_1)$ 的因子图有两个因子节点：$f_1(x_1) = \mathcal{N}(x_1; 0, 1)$，$f_2(x_1, x_2) = \mathcal{N}(x_2; x_1, 2)$。VMP 用平均场近似 $q(x_1, x_2) = q_1(x_1) q_2(x_2)$，通过交替更新因子节点向变量节点发送消息来最小化 KL 散度。

### 计算/推理步骤
1. 对于指数族分布，VMP 更新规则为：变量 $x_j$ 的变分参数等于所有连接到该变量的因子节点的自然参数之和。
2. 设 $q_1(x_1) \propto \exp\{-\frac12 (x_1^2 + \mathbb{E}_{q_2}[(x_2 - x_1)^2]/2)\}$。展开得 $q_1(x_1) \propto \exp\{-\frac12 [x_1^2 + (1/2)(x_1^2 - 2x_1\mathbb{E}[x_2] + \mathbb{E}[x_2^2])]\}$，化简得 $q_1(x_1) \propto \exp\{-\frac12 (\frac32 x_1^2 - x_1\mathbb{E}[x_2] + \text{常数})\}$。
3. 因此 $q_1 = \mathcal{N}(\mu_1, \sigma_1^2)$ 其中 $\sigma_1^2 = 2/3$，$\mu_1 = (\mathbb{E}[x_2]/2) \cdot (2/3) = \mathbb{E}[x_2]/3$。同理 $q_2 = \mathcal{N}(\mu_2, \sigma_2^2)$ 其中 $\sigma_2^2 = 2$，$\mu_2 = \mathbb{E}[x_1]$。
4. 迭代更新至收敛：设初值 $\mathbb{E}[x_2] = 0$，则 $\mu_1 = 0$，$\mathbb{E}[x_1] = 0$，$\mu_2 = 0$。最终收敛到 $\mu_1 = \mu_2 = 0$，$\sigma_1^2 = 2/3$，$\sigma_2^2 = 2$，与精确后验一致。

### 结果解读
VMP 通过**交替计算因子到变量的期望消息**实现高效近似推断。对于共轭指数族模型（如本例的高斯-高斯），消息更新有闭式解，VMP 与精确推断等价。但在非共轭或复杂图结构中，VMP 比信念传播更易于扩展到广义线性模型和深度生成模型。

## 风险与约束

- 近似推断的收敛性与偏差需要单独审计
- 有环图和强耦合结构会显著增加难度
- 稀疏结构利用不当，复杂度优势会很快消失
