# 定理与方法层

## 使用说明

- 每个子目录包含对应分类的方法文件和分类导航 README
- 分类导航 README 列出本类所有方法文件及简要说明
- 主题模糊时，优先使用 [按分支索引](../08-索引/按分支索引.md) 或 [按概念索引](../08-索引/按概念索引.md)
