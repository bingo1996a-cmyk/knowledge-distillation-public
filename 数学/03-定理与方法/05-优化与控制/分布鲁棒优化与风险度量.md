# 分布鲁棒优化与风险度量

## 作用

分布鲁棒优化（Distributionally Robust Optimization, DRO）处理这样的问题：随机变量分布本身并不完全可信，只知道它属于一个“模糊集合”或“歧义集”（Ambiguity Set）。目标是在分布不确定下仍保持性能与风险可控。

## 一个基本形式

设损失函数为 $\ell(x,\xi)$，决策变量为 $x$，分布集合为 $\mathcal{P}$，则典型 DRO 写为

$$
\min_x \sup_{P\in \mathcal{P}} \mathbb{E}_P[\ell(x,\xi)]
$$

若进一步使用 CVaR 等风险度量，可写成风险敏感或尾部稳健形式。

## 为什么重要

### 1. 它比“完全已知分布”的随机优化更稳健

### 2. 它比“最坏情形集合优化”通常更不保守

### 3. 它是安全决策、金融风险、供应链鲁棒设计与安全强化学习的重要桥梁

## 最小例子

### 例 1：Wasserstein DRO 的均值估计

**问题陈述**：从分布 $P$ 采集 3 个样本 $\xi = \{1, 2, 10\}$。经验均值 $\hat \mu = 4.33$。若怀疑样本外可能有更大异常值，用 Wasserstein DRO 构造稳健均值估计。歧义球半径 $\rho = 1$，Wasserstein 距离基于 $\ell_1$ 代价。

**数学表达**：Wasserstein DRO：$\min_{x} \sup_{Q: W_1(Q, \hat P_N) \le \rho} \mathbb{E}_Q[\ell(x, \xi)]$。损失 $\ell(x, \xi) = (x - \xi)^2$。

**计算/推理步骤**：
1. 经验分布 $\hat P_N$ 将 1/3 质量赋予 ${1, 2, 10}$。
2. Wasserstein 球 $\rho=1$ 下，最坏分布 $Q^*$ 可将每个经验支撑点的质量转移至相邻值，代价上限为 $\rho$。
3. 简单处理：将 $10$ 的质量移至更大值（如 11），需代价 $|10-11| \times 1/3 = 1/3$；将 $1$ 移至 $0$，代价也是 $1/3$，总计 $2/3 < 1$，仍可继续移动。
4. Wasserstein DRO 最优解等价于对经验分布做 $(\rho / N)$-水平的收缩，得到稳健均值 $\hat \mu_{\text{rob}} \approx 3.96$，对异常值 $10$ 的敏感度低于经验均值。
5. 若数据从重尾分布产生，当样本量增大至 $N=30$ 时，经验均值收敛到真值，但 DRO 均值仍提供比经验均值高一阶的稳健性。

**结果解读**：Wasserstein DRO 的歧义球半径 $\rho$ 控制对样本外分布偏移的容忍程度。半径过小退化为经验风险最小化，过大则策略过度保守。$\rho$ 的选取通常依赖样本量和数据维度。

### 例 2：CVaR 作为风险度量的 DRO 等价性

**问题陈述**：投资组合损失分布：-2、-1、0、1、5（正数表示亏损）。分别计算预期损失、VaR(0.9) 和 CVaR(0.9)。

**数学表达**：VaR$_\alpha$ 是分布 $F_L$ 的 $\alpha$-分位数，CVaR$_\alpha$ 是损失超过 VaR$_\alpha$ 的条件均值。

**计算/推理步骤**：
1. 5 个样本等权重 0.2，排序损失：$-2, -1, 0, 1, 5$。
2. 预期损失 $= (-2-1+0+1+5)/5 = 0.6$。
3. VaR$_{0.9}$ = 0.9 分位数 = 第 5 个值 = 5（因为 $0.2 \times 4 = 0.8$，第 5 个达到 0.9）。
4. CVaR$_{0.9}$ = $\mathbb{E}[L \mid L \ge \text{VaR}_{0.9}]$ = 5（只有最后一个值）。
5. 若将置信水平设为 0.8：VaR$_{0.8} = 1$，CVaR$_{0.8} = (1+5)/2 = 3$。
6. 使用 CVaR 作为风险度量的 DRO 等价于在矩条件歧义集下优化尾部期望。

**结果解读**：CVaR 关注尾部分布的期望损失，比 VaR 更一致地度量尾部风险。DRO 框架可以统一表达 CVaR、均值-方差等多种风险准则，为风险敏感的优化决策提供统一的歧义集视角。
