# 文件命名规范 (File Naming Conventions)

本文件记录数学知识库的文件命名惯例、目录级规范以及内部链接规则。所有贡献者应遵循此规范以保持一致性。

## 命名规则

1. 全小写英文，单词间用连字符 `-` 连接。正确：`measure-theory.md`、`stochastic-process.md`；错误：`MeasureTheory.md`、`stochastic_process.md`
2. 不使用下划线或驼峰命名。
3. 文件名应反映文件的核心内容主题，使用该主题最标准、最常用的英文名称。避免使用缩写（除非该缩写是标准术语，如 pde、mpc、lqr）。
4. 避免不必要的通用后缀，不重复 "note"、"doc"、"article" 等。

## 各目录命名惯例

- **01-branches/**：直接使用分支标准译名的英文小写，如 `algebra.md`、`topology.md`、`measure-theory.md`、`partial-differential-equations.md`
- **02-core-concepts/**：使用核心概念的标准英文名，如 `set.md`、`group-ring-field.md`、`banach-and-hilbert-space.md`、`topological-space.md`
- **03-theorems-and-methods/**：使用方法名称或主题短语，如 `gradient-descent.md`、`kalman-filter.md`、`law-of-large-numbers-and-central-limit-theorem.md`。子目录 README 命名固定为 README.md，用序号前缀标识分类
- **04-applications/**：统一前缀 mathematics-in- + 领域名称，如 `mathematics-in-machine-learning.md`、`mathematics-in-physics.md`
- **05-learning-paths/**：路线描述 + 后缀 -path，如 `pure-math-path.md`、`engineering-path.md`、`functional-analysis-and-pde-path.md`
- **06-thought-history-culture/**：使用主题词描述，如 `mathematical-thinking.md`、`history-of-mathematics-overview.md`
- **07-reference/**：使用描述性名称，如 `glossary.md`、`symbol-table.md`、`branch-concept-method-map.md`
- **08-index/**：统一前缀 index-by- + 维度名称，如 `index-by-branch.md`、`index-by-concept.md`、`index-by-application.md`；全文件索引 `full-index.md`
- **90-appendices/**：使用描述性名称，如 `reference-textbooks.md`、`todo.md`、`changelog.md`

## 内容内链规则

- 所有内部链接使用相对路径。
- 引用同一目录下的文件：`[文本](filename.md)`
- 引用子目录下的文件：`[文本](subdir/filename.md)`
- 引用上级目录下的文件：`[文本](../dir/filename.md)`
- 引用兄弟目录下的文件：`[文本](../other-dir/filename.md)`
- 从任何子目录引用根 README：`[说明](../README.md)`

## 特殊说明

- 03-theorems-and-methods/ 采用软解耦策略：所有方法文件仍存放在扁平目录中，子目录只包含 README.md 索引文件。链接时按实际存放位置（扁平目录）进行引用。
- 文件名一旦确定不应轻易修改，以避免破坏已有交叉引用。确需重命名时，应同步更新所有引用该文件的内部链接。
- 新增文件时，建议先在相应索引文件（08-index/）中注册，再创建内容。
