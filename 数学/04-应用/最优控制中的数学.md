# 最优控制中的数学

## 定位

最优控制中的核心任务是：在系统动态与约束存在的条件下，设计控制输入，使长期性能指标达到最好。  
它是控制理论、运筹优化、强化学习和工程决策之间的重要交叉点。

## 主要数学底座

### 1. 动态系统建模

必须先明确状态、输入、输出与扰动的关系。  
这通常依赖 [状态空间模型](../02-核心概念/状态空间模型.md)。

### 2. 值函数与最优性条件

连续时间可从 Hamiltonian 与 Pontryagin 极大值原理入手；  
反馈最优性则进一步进入 HJB 方程与 Riccati 结构。

### 3. 优化理论与求解器

约束、可行性、凸性、对偶与数值算法决定了控制器能否被真正算出来。

### 4. 概率与随机性

在噪声、干扰和部分观测存在时，问题会延伸到 LQG、随机控制与估计耦合系统。

## 典型代表问题

- 线性二次调节（LQR）
- 线性二次高斯控制（LQG）
- 模型预测控制（MPC）
- 轨迹优化与制导问题
- 随机控制与强化学习近似控制

## 关键数学桥梁

### Bellman / HJB 视角

值函数满足离散或连续时间最优性递推。

### Hamiltonian / PMP 视角

轨迹最优性可写成状态方程、伴随方程与极值条件联立。

### 数值优化视角

求解通常落到大规模非线性规划、二次规划或锥规划上。

## 为什么重要

最优控制并不只是“控制 + 一个目标函数”。  
它真正困难的部分在于：

- 动态耦合
- 约束传播
- 不确定性
- 实时计算预算
- 模型误差与可实施性

## 关键假设与前提检查

1. 状态方程是否可信
2. 性能指标是否真正对应任务目标
3. 控制约束与安全约束是否完整表达
4. 数值求解器是否满足实时性要求

## 风险与约束

- 模型与实际系统失配会导致开环最优解不可部署
- 约束遗漏会导致理论最优但工程失效
- 高维系统的值函数方法会遭遇维数灾难
- 单看仿真代价下降不等于闭环鲁棒性足够

## 在资源受限条件下的可行最优路径

1. 先做低维、线性或局部线性近似
2. 优先求出可解释的 LQR 基线控制器
3. 有显式约束时再进入 MPC
4. 部分可观测时接入 Kalman / LQG
5. 只有在线性近似明显失效时，再进入更复杂随机控制或深度强化学习
