# 网络科学与大规模系统

## 这个分支研究什么

这个分支研究由大量节点、边、局部规则与全局涌现共同构成的系统。对象既可以是通信网络、电力网络、交通网络、社交网络，也可以是多智能体系统、平台系统与群体决策系统。

## 核心问题

- 网络结构如何影响传播、同步、鲁棒性与脆弱性
- 大规模主体在局部交互下如何形成全局行为
- 网络上的优化、控制、博弈与推断如何统一理解
- 稀疏结构、图分解与局部消息传递为何能降低复杂度

## 核心对象与方法

- 图、超图、因子图、随机图
- 一致性、同步、扩散、渗流
- 均值场（Mean Field）、大群体近似
- 分布式优化、网络博弈、匹配市场
- 稀疏线性代数、图优化与消息传递

## 与其他分支的关系

- 与 [图论](./图论.md) 相连：图结构是网络科学的基础语言
- 与 [概率与统计](./概率与统计.md) 相连：传播、估计与网络不确定性依赖随机模型
- 与 [优化](./优化.md) 相连：资源配置、协调与调度依赖优化
- 与 [博弈论与决策](./博弈论与决策.md) 相连：平台、市场与群体行为常具有博弈结构
- 与 [控制](./优化.md) 和 [Lie 理论](./Lie理论.md) 相连：大规模协同系统常涉及动态系统与几何状态空间

## 为什么重要

它既服务工程系统，也服务社会科学。很多现实问题并不是“单体最优”，而是“网络结构、局部规则和全局行为”共同决定结果。
