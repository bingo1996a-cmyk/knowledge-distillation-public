# 偏微分方程

## 这个分支研究什么

这个分支研究多变量函数的变化规律，尤其是由偏导数关系、边界条件与初始条件共同决定的连续介质系统、场方程与演化方程。

## 核心问题

- 方程是否有解，解是否唯一，解是否稳定
- 椭圆型、抛物型、双曲型方程分别代表什么物理或几何机制
- 为什么需要弱解、变分法与 Sobolev 空间
- 数值离散、稳定性与收敛性如何与连续理论对应

## 核心对象与方法

- 拉普拉斯方程、热方程、波动方程、输运方程
- 边界条件、初始条件、Green 函数
- 弱导数、弱解、Sobolev 空间
- 能量估计、最大值原理、变分法
- 有限差分、有限元、谱方法

## 与其他分支的关系

- 与 [分析](./分析.md) 和 [泛函分析](./泛函分析.md) 相连：PDE 的现代语言高度依赖这两者
- 与 [几何](./几何.md) 与 [微分几何](./微分几何.md) 相连：曲面与流形上的 PDE 需要几何背景
- 与 [计算数学](./计算数学.md) 和 [数值分析](./数值分析.md) 相连：实际求解高度依赖数值离散
- 与 [控制](../04-应用/最优控制中的数学.md) 相连：HJB 方程、分布参数系统与反问题都涉及 PDE
- 与 [材料、连续介质与 PDE 应用](../04-应用/材料与连续介质系统中的数学.md) 相连

## 为什么重要

大量物理、工程、材料、金融和几何问题最终都可表述为 PDE。它是把“变化、约束和空间结构”统一到同一个方程框架中的核心分支。
