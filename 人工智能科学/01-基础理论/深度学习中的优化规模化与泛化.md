# 深度学习中的优化、尺度扩展与泛化

## 1. 概念边界

这一页讨论深度学习（Deep Learning）为什么能在高维、非凸、过参数化（over-parameterized）条件下仍然实现有效训练与可接受泛化。它关注三条相互缠绕的主线：

1. **优化（optimization）**：参数如何被训练算法推进到低训练损失区域；
2. **尺度扩展（scaling）**：模型、数据、算力三者如何共同改变能力边界；
3. **泛化（generalization）**：模型为什么在训练集之外仍然有效。

它不是单一算法说明，而是理解现代深度学习理论与工程实践的基础页。

## 2. 核心问题

### 2.1 为什么非凸优化仍然可做

神经网络训练目标通常写成：

$$
\min_{\theta} \; \mathcal{L}(\theta)=
\frac{1}{N}\sum_{i=1}^{N}\ell(f_\theta(x_i), y_i)
$$

虽然这个目标通常非凸，但现代训练并不要求找到全局最优，而是要求找到：

- 训练损失足够低；
- 局部几何性质较平滑；
- 对分布扰动不过分脆弱；
- 与系统约束相容的可部署解。

### 2.2 为什么大模型往往更容易训练

过参数化并不天然保证成功，但它会改变损失面的可达性，使 SGD（Stochastic Gradient Descent）或 Adam 一类算法更容易找到低损失盆地。一个实用判断是：

- 参数量增加，表示能力提升；
- 数据量增加，估计误差下降；
- 训练计算增加，优化更充分；
- 但不匹配的扩展会带来数据浪费、过拟合或训练不稳定。

### 2.3 为什么训练误差低不等于泛化好

泛化误差可写为：

$$
\mathcal{E}_{gen}=\mathbb{E}_{(x,y)\sim \mathcal{D}}[\ell(f_\theta(x),y)] - 
\frac{1}{N}\sum_{i=1}^{N}\ell(f_\theta(x_i), y_i)
$$

训练误差反映拟合能力，泛化误差反映分布外推与稳健性。现代深度学习的关键难题之一，是解释为什么高容量模型在插值（interpolation）甚至记忆训练集时仍能保持较强测试性能。

## 3. 三条主线

### 3.1 优化主线

深度学习训练可被分解为：

- 参数初始化；
- 小批量随机梯度；
- 学习率调度；
- 正则化与归一化；
- 梯度裁剪、混合精度和分布式并行。

核心现象包括：

- SGD 噪声具有隐式正则化（implicit regularization）作用；
- 批大小影响噪声尺度与收敛路径；
- 学习率 warmup 与 decay 改变优化稳定性；
- BatchNorm、LayerNorm 不只影响数值稳定，也影响可优化性。

### 3.2 尺度扩展主线

现代大模型训练通常关注经验尺度律（scaling laws）：

$$
L(N,D,C) \approx A N^{-\alpha} + B D^{-\beta} + E C^{-\gamma} + L_\infty
$$

其中：

- $N$ 表示模型规模；
- $D$ 表示数据规模；
- $C$ 表示训练计算；
- $L$ 表示损失。

这类经验关系不等于普适定理，但在工程上非常重要，因为它决定：

- 是该继续加参数，还是继续加数据；
- 是该做更长训练，还是改数据配方；
- 何处会出现边际收益递减；
- 何处需要转向后训练而不是继续预训练。

### 3.3 泛化主线

泛化不能只靠 VC 维或参数量上界来解释。现代更有用的解释框架包括：

- margin 视角；
- flatness / sharpness 视角；
- compression 视角；
- PAC-Bayes 视角；
- 算法稳定性（algorithmic stability）视角；
- 数据流形（data manifold）与表示学习视角。

## 4. 系统结构视角

从系统工程看，训练是否成功通常不是“优化器好不好”的单因变量，而是以下链条共同决定：

`数据配方 -> 初始化与架构 -> 优化器与调度 -> 分布式实现 -> 监控与故障恢复 -> 验证协议`

其中任何一环失衡，都会让理论上可训练的模型在工程上不可训练。

## 5. 常见失败模式

### 5.1 优化层失败

- 梯度爆炸或消失；
- 学习率过高导致发散；
- 大批量训练的泛化退化；
- 不合适的 weight decay 与参数分组。

### 5.2 扩展层失败

- 模型参数增加但数据质量未同步提升；
- 训练 token 很多，但有效信息密度低；
- 系统吞吐提高后，训练稳定性下降；
- 为追求规模而牺牲验证与回滚能力。

### 5.3 泛化层失败

- benchmark overfitting；
- 数据泄漏；
- 分布漂移；
- 训练目标与部署目标不一致。

## 6. 评测指标

### 6.1 优化指标

- training loss / validation loss；
- gradient norm；
- update norm；
- learning rate；
- throughput 与 hardware efficiency。

### 6.2 泛化指标

- in-domain accuracy / loss；
- out-of-distribution robustness；
- calibration；
- worst-group performance；
- sample efficiency。

### 6.3 扩展指标

- 每单位计算带来的损失下降；
- compute-optimality；
- data efficiency；
- post-training lift。

## 8. 研究切口

### 8.1 理论方向

- 过参数化条件下的可优化性解释；
- 泛化与平坦极小值之间的关系；
- 训练动力学与表示形成的耦合机理。

### 8.2 工程方向

- 大规模训练的故障鲁棒性；
- 数据配方与 curriculum 的耦合优化；
- 大批量分布式训练的稳定性控制。

### 8.3 面向博士研究的可用问题

- 如何构造兼顾 compute-optimality 与 downstream transfer 的训练配方；
- 如何用可验证指标而不是单一 benchmark 评价扩展收益；
- 如何将优化几何、数据质量与部署稳健性连成统一分析框架。
