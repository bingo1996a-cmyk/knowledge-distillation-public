# 不确定性量化、校准与可验证推断

## 位置

这一页补在“期望、估计、不确定性与推断”之后，更强调现代 AI 系统中的 uncertainty quantification、calibration 与 verifiable inference。

## 为什么单列这一页

很多模型给出的是分数，不是可信概率；很多系统看起来置信度很高，但其实并没有校准；很多“推理成功”也只是表面连贯，而非可验证正确。

## 三个层次

### 1. uncertainty quantification

关注模型到底有多不确定。通常要区分：

- aleatoric uncertainty：来自数据噪声与环境随机性；
- epistemic uncertainty：来自模型知识不足；
- distributional uncertainty：来自分布偏移或 OOD。

### 2. calibration

校准关注“预测概率是否与真实频率一致”。高准确率不等于高校准。

### 3. verifiable inference

可验证推断强调：输出不仅要给分数，还要能被约束、被检查、被追溯。

## 常见方法族

- 温度缩放（temperature scaling）
- conformal prediction
- ensemble / deep ensemble
- 贝叶斯近似与 MC dropout
- selective prediction / abstention
- constraint checking / tool-based verification

## failure mode

1. 置信度虚高；
2. OOD 样本被当成常规样本；
3. 校准只在验证集上好，部署后失效；
4. 生成模型给出连贯但不可验证的解释；
5. 风险阈值与业务阈值不一致。

## 评测指标

- ECE / MCE
- Brier score
- NLL
- risk-coverage curve
- abstention utility
- verification pass rate
