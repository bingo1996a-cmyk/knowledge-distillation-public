# 问题空间入口页（V37）

## 为什么需要这一层

模型层告诉你"有什么模型"，系统层告诉你"如何把它们跑起来"，应用层告诉你"落在哪些行业"。但工程实践中最先要回答的通常是：**这个任务到底属于什么问题空间**。若问题空间判断错误，后续模型、数据、评测和安全策略都会跑偏。
