# 人工智能在学术研究、学术写作与科学知识工作中的应用（AI in Academic Research, Scholarship, and Scientific Knowledge Work）

## 1. 定位

本页讨论人工智能在学术界的公开、研究导向应用，重点关注：

- 文献发现与综述组织；
- 学术写作与知识整编；
- 科学数据分析；
- 假设生成与实验自动化；
- 同行评审辅助、研究管理与科研基础设施。

不把它写成“科研万能助手”宣传页，而是强调：能力边界、证据链、可重复性和学术规范。

## 2. AI 在学术界的发展脉络

### 2.1 早期：信息检索与计量分析

最早进入学术工作的 AI 主要是：

- 文献检索；
- 主题建模；
- 引文网络分析；
- 学术推荐。

### 2.2 中期：机器学习用于科学数据

随着机器学习普及，AI 开始更深入进入：

- 生物信息学；
- 材料发现；
- 遥感分析；
- 天体物理与实验数据处理。

### 2.3 近期：大模型与 scientific agent

大模型（Large Models）和 scientific agent 把 AI 从“分析工具”推进到“研究流程参与者”：

- 文献总结与问题分解；
- 代码生成与实验脚本草拟；
- 仪器调用与实验调度；
- 证据包整理与审计记录。

## 3. 学术工作的五类应用

### 3.1 文献与综述

- 检索与去重；
- 主题聚类；
- 研究脉络整理；
- 证据等级标注；
- 综述大纲生成。

### 3.2 学术写作与知识组织

- 摘要与提纲草拟；
- 术语统一；
- 图表说明；
- 研究笔记整编；
- 交叉索引构建。

### 3.3 科学数据分析

- 回归、分类、聚类、降维；
- 不确定性估计；
- 实验结果可视化；
- 异常检测与故障分析。

### 3.4 假设生成与实验自动化

- 候选假设提出；
- 参数空间筛选；
- 仪器调用与实验计划；
- 实验结果回写与再验证。

### 3.5 研究治理与科研基础设施

- 数据管理计划；
- 版本管理与可复现性；
- 审计轨迹；
- 伦理审批材料支持；
- 研究组知识库建设。

## 4. 学术应用的关键约束

- 不能虚构参考文献；
- 不能替代原始阅读与核验；
- 不能跳过实验与数据质量控制；
- 需要保留来源、时间戳与修改记录；
- 涉及高风险领域时，需要更强的人类监督。

## 5. 与本知识库其他页面的关系

本页是以下主线的汇聚页：

- 统计学习与概率统计基础；
- scientific agent 与实验自动化；
- 大模型与工具使用型智能体；
- 证据包、审计轨迹与发布门禁；
- AI for Science。
