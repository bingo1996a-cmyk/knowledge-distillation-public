# 总览层入口页

## 定位

00-overview 层是整个知识库的"第一道门"。它不深入任何具体技术，而是提供知识库的阅读地图、使用说明和全局索引。

## 包含页面

| 文件名 | 用途 |
|--------|------|
| [知识库说明](./knowledge-base-guide.md) | 知识库的目标、组织方式、读者定位、文档类型说明 |
| [阅读路径](./reading-path.md) | 五条推荐阅读路径（整体骨架、概率统计、大模型/生成式/智能体、深度学习/网络结构、强化学习） |
| [人工智能科学总地图](./map-of-ai-science.md) | 全树结构总览，从基础理论到应用与治理 |
| [表示法与术语](./notation-and-terminology.md) | 全库统一符号说明 |
| [人工智能科学历史路线](./ai-history-route.md) | 思想史分区的阅读指引 |
| [远景规划路线图](./vision-roadmap.md) | V37—V40 版本路线与完全态目标 |
| [元数据规范](./metadata-specification.md) | YAML 前置元数据定义、受控词表、文件分类范本 |
