# 知识图谱与神经符号系统

## 定位

这篇笔记不再把知识图谱（knowledge graph, KG）看成孤立的数据结构，也不把神经符号（neural-symbolic）看成抽象口号，而是把它们放回同一条主线：

- 如何把结构化知识、规则、约束与统计学习连接起来；
- 如何在可学习性、泛化性与可解释性之间做系统折中；
- 如何让大模型、图模型与符号推理共同工作。

## 一、概念边界

### 1. 知识图谱不是“有三元组就算 KG”

更严格地说，知识图谱至少包含：

- 实体（entity）；
- 关系（relation）；
- 类型系统或模式层；
- 可追溯来源；
- 可被查询或推理的结构。

### 2. 神经符号不是简单拼接

把 LLM 放前面、规则引擎放后面，不自动构成有效的神经符号系统。真正的神经符号系统至少要回答：

- 符号知识在哪里表示；
- 神经模型如何吸收或调用它；
- 推理链在哪一层执行；
- 冲突、缺失和不确定性如何处理。

### 3. 这条线的核心张力

- 符号方法强在约束、逻辑和解释；
- 神经方法强在表示、鲁棒性和数据拟合；
- 神经符号系统的目标，是在两者之间获得更好的组合，而不是机械相加。

## 二、问题空间

### 1. 表示问题

如何把世界知识、领域规则和任务约束编码为：

- 图结构；
- 逻辑规则；
- 本体（ontology）；
- 可学习嵌入；
- 可调用工具。

### 2. 推理问题

典型任务包括：

- 链接预测；
- 实体对齐；
- 多跳推理；
- 规则归纳；
- 复杂查询回答；
- 约束满足与规划支持。

### 3. 系统问题

如何把 KG 与：

- 检索增强生成（retrieval-augmented generation, RAG）；
- agent 记忆；
- 多智能体通信；
- 科学知识库；
- 高风险治理日志；

连接成统一系统。

## 三、一个统一分类框架

可把这条线粗分为三类。

### 1. Symbol for Neural

用符号知识增强神经模型：

- 用 KG 作为检索源；
- 用规则做解码约束；
- 用本体指导标签或结构设计；
- 用图结构辅助可解释性。

### 2. Neural for Symbol

用神经方法补强符号系统：

- KG 嵌入；
- 神经链接预测；
- 规则学习；
- 噪声补全；
- 对不完全知识图进行近似推断。

### 3. Hybrid Neural-Symbolic

在系统内部显式结合两类机制：

- 神经表征负责感知和相似性；
- 符号层负责规则、约束与可验证推理；
- 两层通过共享中间表示或显式调用交互。

## 四、系统结构

### 1. KG 作为外部记忆

这是当前最容易落地的形态：

- 模型负责意图理解与查询构造；
- 图数据库负责结构化检索；
- 结果经格式化后反馈给模型。

优点是工程清晰；缺点是推理链往往分散在多个模块中。

### 2. KG 作为训练先验

常见方式：

- 图嵌入预训练；
- 关系约束损失；
- 规则正则项；
- 图结构蒸馏。

### 3. KG 作为执行期推理层

模型不直接给终结答案，而是：

- 生成候选查询；
- 调用图推理器；
- 验证约束；
- 回填结论和证据。

这种结构更适合高可靠场景。

## 五、与大模型的接口

### 1. KG-enhanced RAG

相比纯文本检索，KG 的优势在于：

- 关系显式；
- 多跳路径清晰；
- 证据更易结构化；
- 冲突更容易定位。

### 2. tool-using LLM with graph backends

LLM 可以把图数据库、规则引擎、SPARQL/图查询接口视作工具。

### 3. agent memory 与 world model

在持续交互系统里，KG 还可以承担：

- 长期记忆；
- 实体状态表；
- 关系更新；
- 任务约束图。

## 六、常见失败模式

### 1. 只做嵌入，不保留可解释结构

这样往往会退化成普通表示学习，丢失神经符号的核心价值。

### 2. 规则太硬，系统难以扩展

规则库若缺少版本化、优先级与冲突管理，很快会变得脆弱。

### 3. 把 KG 当静态真理库

真实知识通常存在：

- 不完整；
- 时效变化；
- 来源冲突；
- 语境依赖。

### 4. 图推理链与文本生成脱节

模型生成的结论若无法回链到图上的实体、关系和证据路径，系统可信度仍然有限。

### 5. 规模化困难

图结构一旦进入跨域、多源、长时间跨度，更新、对齐和查询效率都会成为瓶颈。

## 七、评测指标

### 1. 表示层

- 链接预测准确率；
- 实体对齐质量；
- 嵌入质量；
- 冷启动鲁棒性。

### 2. 推理层

- 多跳推理正确率；
- 规则满足率；
- 复杂查询回答精度；
- 证据路径完整率。

### 3. 系统层

- 检索时延；
- 图查询成本；
- 在线更新延迟；
- 冲突检测成功率。

### 4. 治理层

- 来源可追溯率；
- 时效标签完备率；
- 冲突解释率；
- 审计重放成功率。

## 八、研究切口

### 1. LLM + KG + tool routing

如何根据问题类型自动决定走文本检索、图检索、规则推理还是混合路径。

### 2. verifiable reasoning over graphs

如何让模型的结论可被图路径和规则链验证，而非只给出流畅文本。

### 3. temporal / dynamic KGs

如何处理动态世界中的时间、事件和状态演化。

### 4. scientific knowledge graphs

如何把论文、实验、参数、仪器、样品与结果组织为科研可用的图知识系统。

### 5. multi-agent shared graph memory

多智能体系统中，如何以共享图记忆支撑协同、信用分配和冲突消解。

## 九、结论

知识图谱与神经符号系统的真正价值，不在于“回到旧式规则系统”，而在于为现代 AI 提供一个更强的结构化知识与可验证推理层。

在 agent、scientific AI、治理审计和高风险系统中，这条线的重要性会继续上升。
