# 自监督学习：对比学习、掩码建模与迁移接口

## 定位

这是一页模型族/训练机制之间的桥接页。它讨论自监督学习（self-supervised learning）如何从“标签不足时的替代方案”演化为 foundation model 时代的核心训练机制。

## 一、概念边界

自监督学习的核心不是“没有标签”，而是**训练信号由数据本身结构构造出来**。  
常见目标包括：

- 对比学习：让同一对象的不同视图靠近，不同对象远离；
- 掩码建模：让模型根据上下文恢复被遮蔽的部分；
- 自回归建模：预测下一 token / 下一帧 / 下一状态；
- 多模态对齐：让图像、文本、音频、动作等进入同一语义空间。

## 二、主线结构

### 1. 对比学习（contrastive learning）

典型问题是：如何定义“正样本”和“负样本”。  
它的关键收益在于：

- 学到判别性表征；
- 在少标签场景下提升迁移性能；
- 通过数据增强显式编码不变性。

常见挑战包括：

- 假负例问题；
- 批量规模需求高；
- 数据增强策略强依赖任务结构；
- 对生成式能力支持有限。

### 2. 掩码建模（masked modeling）

掩码建模通过隐藏局部信息，让模型恢复上下文中的缺失部分。  
典型变体包括：

- masked language modeling；
- masked image modeling；
- masked autoencoding；
- 时空掩码建模。

它的优势在于：

- 与重建式预训练兼容；
- 支持大规模无标注数据；
- 便于扩展到多模态。

局限是：

- 学到的表征不一定天然适合判别任务；
- 重建目标可能过度关注低层统计而非高层语义。

### 3. 自回归建模（autoregressive modeling）

自回归建模在语言模型、时序建模和 world model 中极其重要。  
其优点是：

- 训练目标统一；
- 与生成任务天然对齐；
- 易于扩展到 tokenized action / video / multimodal sequences。

局限是：

- 长程依赖训练成本高；
- 生成式目标不一定最适合表征学习；
- 容易把表面统计规律当作深层结构。

## 三、迁移接口

自监督学习真正重要之处在于它是迁移学习和 foundation model 的接口层。  
它影响下游的四个关键问题：

1. 预训练表征是否可线性探针；
2. 下游微调需要多少样本；
3. domain shift 时是否稳健；
4. 多任务/多模态共享表示是否成立。

## 四、系统视角

从系统工程角度，自监督学习设计要同时回答：

- 数据如何组织；
- 增强与掩码如何定义；
- 预训练目标是否和下游接口一致；
- 训练计算是否可承受；
- 评测是看重 reconstruction 还是 transfer；
- 后训练是否需要补齐安全、指令和工具能力。

## 五、常见失败模式

- 数据增强定义不当，导致错误不变性；
- 对比目标学习到 shortcuts；
- 掩码比例设置不当，训练退化为低层填空；
- 预训练与下游任务严重脱节；
- 迁移评测只看平均准确率，不看 calibration 与 robust transfer。

## 六、评测指标

- linear probing performance；
- full fine-tuning performance；
- few-shot / low-shot transfer；
- out-of-domain robustness；
- representation similarity / collapse diagnosis；
- compute-to-transfer efficiency。

## 七、研究切口

- 对比学习与生成式预训练能否统一；
- 哪些预训练目标更利于控制、规划和具身动作表示；
- 多模态掩码建模是否能学到共享世界表征；
- 自监督表示与不确定性估计、校准之间是什么关系。
