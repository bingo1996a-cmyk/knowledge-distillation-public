# 知识图谱

## 定位

知识图谱把知识表示为实体、关系与约束构成的图结构。它不是简单的数据表，而是显式编码“谁与谁有什么关系、这些关系如何约束推理”。

## 一、基本思想

- 知识不是孤立事实，而是结构化关系网络；
- 推理不只靠统计共现，也可以借助图结构、路径和约束；
- provenance 与 schema 对知识可信度很重要。

## 二、为什么它仍然重要

即使在大模型时代，知识图谱仍然有价值，因为它提供：

- 显式结构；
- 可审计关系链；
- 实体去重与对齐；
- 约束检查与规则注入；
- 对高风险系统更友好的证据组织方式。

## 三、与大模型、agent 的关系

知识图谱不一定替代大模型，更常见的是与 LLM、RAG、tool use、scientific knowledge base 组合，作为 graph memory 与 verifiable reasoning 的结构底座。
