# 联邦学习、个性化与分布式优化

## 1. 定位

联邦学习（Federated Learning, FL）研究在数据不集中汇聚的条件下，如何通过分布式优化训练共享模型。它连接机器学习、隐私保护、系统优化与跨组织协作。

## 2. 基本思想

典型联邦学习流程：

1. 服务器下发全局模型；
2. 客户端在本地数据上训练；
3. 上传参数或梯度更新；
4. 服务端聚合，形成新全局模型。

最经典的聚合方式是 FedAvg。

## 3. 联邦学习为何重要

- 数据受隐私或合规约束难以集中；
- 多组织协作需要保留本地控制权；
- 边缘设备与端侧智能需要分布式更新；
- 跨机构证据共享与 assurance 需要模型而非原始数据流动。

## 4. 核心难点

- non-IID 数据
- 通信成本
- 客户端掉线与异步更新
- 隐私泄露与攻击
- 个性化需求

## 5. 个性化联邦学习

全局统一模型未必对所有客户端最优，因此需要：

- local fine-tuning
- cluster federation
- meta-learning style personalization
- shared trunk + local head

## 6. 与大模型及高约束协作场景的关系

联邦学习为跨组织数据合作提供一条非集中式路径，因此与：

- medical / scientific collaboration
- cross-organizational evidence sharing
- edge AI

都有直接联系。
