# Naming and Linking Conventions

## 文件命名
- 使用小写英文 slug
- 以主题语义为主，不以日期命名主干文件
- 避免同层多个几乎同义的标题

## 内部链接
- README 用于目录入口
- overview 文件用于总论与跳转
- 新文件至少被一个 README 或 reading-path 引用

## 版本说明
- 版本级目录索引使用 `Vxx-structure-index.md`
- 变更记录统一写入根目录 `CHANGELOG.md`

## 归档命名
- `archive/updates/<date-range>/`
- `archive/maintenance/`
- `archive/changelogs/`
- `archive/legacy-root-notes/`
