# 史学类材料的证据等级说明

## 这页解决什么问题

本知识库的 08 层（思想史文化层）涉及大量史学类材料——论文、技术报告、新闻报道、回忆录、政策文件、专利等。不同类型的史学材料具有不同的可信度和偏差特征。本页提供一个结构化的证据等级框架，帮助编写者在引用和历史叙述中进行合理的来源权衡，避免将弱证据与强证据等量齐观。

## 基本思想

在技术史叙述中，证据可靠性不取决于材料的权威性标签，而取决于以下维度：与原始事件的时距（越近越可靠）、信息来源的动机（是否具有披露或隐瞒的倾向）、可验证性（是否有独立来源佐证）、以及细节粒度（是否包含可核验的具体数据）。

## 证据等级金字塔

### 第一级（最高可信度）：原始工程文档与同行评审文献

- 原始研究论文（conference / journal）——尤其是发表在有同行评审机制的顶级会议上的论文。这是技术史最可靠的来源，因为它们包含了方法细节、实验数据和可复现条件。
- 开源代码仓库和系统文档——当声称某个系统实现了某项能力时，开源代码本身是最强的物证。
- 经审计的官方技术报告——如国家标准与技术研究院（NIST）报告、政府问责署审计、NASA 的技术备忘录。这类报告有机构背书和质询流程。

### 第二级（高可信度）：独立报道与多方验证的第二手资料

- 多源一致的新闻报道——当多个独立媒体从不同信源报道同一事件且事实一致时，可信度较高。优先选择有调查传统的媒体（如 Reuters、AP）而非观点性媒体。
- 业界综述文章——发表在 ACM Communications、IEEE Spectrum、Nature Reviews 等刊物上的技术回顾。通常经过同行评议或编辑审查。
- 回忆录与第一人称叙述——但需注意时间偏差（回忆往往会美化或简化当时的情境）。若多个参与者的回忆在核心事实上一致，可信度较高。

### 第三级（中可信度）：公司公告与官方新闻稿

- 公司博客、产品发布公告——通常准确但带有营销性表述。提及的"里程碑""首次""突破"等需要独立验证。
- 国家项目公告——如关于某个大科学计划的政府文件。政治动机可能影响其对挑战的披露程度。
- 投资人与分析师报告——如 ARK Invest、Sequoia Capital 的分析。通常有数据支持，但视角以增长和投资回报为主。

### 第四级（低可信度）：个人博客、社交媒体与传闻

- GitHub Issue 讨论、Twitter/X 帖子、Reddit 讨论——可能包含未公开的内部信息，但无法进行来源验证。可作为"提示线索"引用，但不能作为唯一证据。
- 匿名来源或"据知情人士透露"——若没有独立印证，只能视为线索，不能作为事实陈述的依据。
- 维基百科——适合作为起始导航点，但不直接引用为权威来源。可通过其尾注追溯到原始材料。

### 第五级（最低可信度）：商业营销与模糊引用

- 空洞的"根据市场报告"引用而没有具体出处。
- 夸大功能的商业演示视频或宣传册。
- 缺乏具体数据的"据预测"式断言。

## 本库的引用实践

- 优先使用第一级和第二级来源作为核心事实的支撑。
- 使用第三级来源时，注明来源主体（如"据 Amazon Robotics 官方博客称"），让读者能自行判断可能的营销偏差。
- 使用第四级来源时，仅作为补充线索，不单独支持关键论断。
- 对于存在单一权威来源且无法交叉验证的事实，在正文中明确标注信息源（如"据该公司的公开披露"）。
