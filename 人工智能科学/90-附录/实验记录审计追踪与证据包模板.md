# 实验记录本、审计轨迹与 evidence pack 模板

## 用途

这一页给出可直接用于 scientific agent、实验自动化和高风险系统复核的工件模板，目标是把“实验过程”“系统事件”“证据包”组织成可追溯对象。

## 模板一：实验记录本最小字段

- 实验编号
- 任务目标
- 样品 ID / 批次
- 设备 ID / 版本
- 校准状态
- 协议版本
- 关键参数
- 异常事件
- 审批人 / 操作人
- 结果摘要
- 关联 evidence pack 编号

## 模板二：审计轨迹最小字段

- 时间戳
- actor（人 / agent / service）
- action
- object
- input hash / output hash
- model/tool version
- approval state
- rollback marker
- provenance pointer

## 模板三：evidence pack 目录建议

1. 任务说明
2. 输入快照
3. 配置快照
4. 协议与 schema
5. 执行日志
6. 审批记录
7. 输出结果
8. 异常与回滚
9. 复核结论

## 使用建议

- 不要把 evidence pack 当作事故后临时拼接文件夹；
- 在系统设计阶段就定义命名规则、保留期和索引方式；
- 把 evidence pack 与 re-verification checklist、release gate 直接关联。
