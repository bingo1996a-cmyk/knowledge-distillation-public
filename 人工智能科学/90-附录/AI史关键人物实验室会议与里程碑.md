# 人工智能历史中的关键人物、实验室、会议与里程碑

## 这页怎么用

这页不是完整人物志，而是给思想史层提供一个“查表式附录”：  
当你在历史主线中看到某个年份、某个实验室或某篇论文时，可以回到这里迅速定位它的角色。

## 一、关键人物（按主要历史作用归类）

| 人物 | 关键年份 | 代表来源 | 历史作用 |
|---|---|---|---|
| Alan Turing | 1950 | *Computing Machinery and Intelligence* | 把“机器能否思考”转化为可讨论判据 |
| Norbert Wiener | 1948 | *Cybernetics* | 把反馈、控制、通信组织成统一思想框架 |
| John McCarthy | 1955/1956 | Dartmouth proposal；LISP | AI 命名者之一，符号主义关键人物 |
| Marvin Minsky | 1956；1969 | Dartmouth；*Perceptrons* | 早期 AI 核心组织者之一 |
| Frank Rosenblatt | 1957/1958 | Perceptron | 连接主义早期代表 |
| Edward Feigenbaum | 1960s—1980s | DENDRAL、知识工程 | 专家系统与知识工程代表人物 |
| Judea Pearl | 1988 | *Probabilistic Reasoning in Intelligent Systems* | 概率图模型与贝叶斯网络主线代表 |
| Geoffrey Hinton | 1986；2006；2012 | Backprop；深度学习复兴相关工作 | 连接主义复兴关键人物 |
| Yann LeCun | 1989/1998；2010s | LeNet；卷积网络 | 视觉深度学习主线代表 |
| Yoshua Bengio | 2000s—2010s | 表示学习、深度学习 | 深度学习共同推进者 |
| Richard Sutton | 1988；1998 | TD learning；RL 教材 | RL 理论主线代表 |
| Andrew Barto | 1980s—1998 | RL 共同奠基 | RL 教学与理论体系共同奠基 |
| Demis Hassabis | 2010s—2020s | DeepMind, AlphaGo, AlphaFold | 现代高影响应用与系统集成代表 |

## 二、关键实验室与机构

| 实验室/机构 | 关键时期 | 代表作用 |
|---|---|---|
| Dartmouth 早期共同体 | 1950 年代中期 | AI 作为独立研究议题被正式提出 |
| MIT AI Lab | 1960s—1980s | 早期符号主义、机器人、认知研究重镇 |
| Stanford AI Lab（及相关团队） | 1960s—1980s | DENDRAL、MYCIN、知识工程等重要来源 |
| CMU 相关研究群体 | 长期 | 问题求解、规划、机器人、机器学习等重要中心 |
| Bell Labs / AT&T Research | 1980s—2000s | 统计学习、语音、信息论与工程研究重地 |
| DeepMind | 2010s—2020s | AlphaGo、AlphaFold 等高影响项目 |
| OpenAI | 2010s—2020s | GPT、ChatGPT 等基础模型与消费级产品影响者 |
| Google Brain / Google DeepMind | 2010s—2020s | 深度学习与基础模型重要推动者 |
| FAIR / Meta AI | 2010s—2020s | 开源模型与视觉/语言研究重要力量 |
| Anthropic | 2020s | 大模型安全、对齐与产品化的重要参与者 |

## 三、关键会议

| 会议 | 主要意义 |
|---|---|
| AAAI / IJCAI | 早期综合性 AI 共同体的重要平台 |
| NeurIPS / ICML / ICLR | 机器学习与深度学习主线会议 |
| CVPR / ICCV / ECCV | 视觉主线 |
| ACL / EMNLP / NAACL | 自然语言处理主线 |
| RSS / CoRL / ICRA / IROS | 机器人、决策与具身系统 |
| UAI | 概率、因果与不确定性建模 |

## 四、关键里程碑（年份—来源—意义）

| 年份 | 里程碑 | 来源 | 意义 |
|---|---|---|---|
| 1943 | 形式神经元模型 | McCulloch & Pitts | 神经网络思想早期源头 |
| 1948 | 控制论框架 | Wiener | 反馈与控制视角成形 |
| 1950 | 图灵测试思想 | Turing | “机器智能”问题被重新组织 |
| 1956 | Dartmouth 项目 | McCarthy 等 | AI 名称与共同体成形 |
| 1957/1958 | 感知机 | Rosenblatt | 连接主义早期高潮 |
| 1965 | DENDRAL | Stanford 团队 | AI 进入科学推理任务 |
| 1969 | *Perceptrons* | Minsky & Papert | 连接主义遭遇重挫 |
| 1972 | MYCIN | Stanford 团队 | 医疗专家系统代表 |
| 1980 | XCON | DEC | 企业级专家系统代表 |
| 1986 | 反向传播 | Rumelhart, Hinton, Williams | 深度学习训练主骨架 |
| 1988 | 概率图模型系统化 | Pearl | 不确定性推理进入中心 |
| 1997 | Deep Blue | IBM | AI 公共象征性胜利 |
| 2012 | AlexNet | Hinton 团队 | 深度学习主流化 |
| 2016 | AlphaGo | DeepMind | 深度学习 + 搜索 + RL 的象征性胜利 |
| 2017 | Transformer | Vaswani 等 | 预训练与大模型骨架重置 |
| 2021 | AlphaFold2 | DeepMind | AI for Science 代表性突破 |
| 2022 | ChatGPT | OpenAI | 大模型消费级破圈节点 |
