# 官方技术文档索引

## 说明

本文件用于收集人工智能系统工程和前沿模型相关的官方技术文档入口。

## 当前主题入口

- 深度学习框架文档
- 训练与部署框架文档
- 模型 API 与平台文档
- 推理服务与系统框架文档
- 智能体框架与工具文档
- 航天机构公开 AI / EO / autonomy 文档
- 高风险治理、TEVV 与 assurance 文档

## 当前原则

- 优先官方站点和官方仓库文档
- 对高时效文档，优先同时在更新时间层建立对应更新页
- 对高风险应用，优先写系统结构、评测、互操作与责任链，不写操作性执行细节

## 建议优先跟踪的官方文档入口（按主题）

### 通用模型与智能体平台

- OpenAI API 文档：关注 Responses API、Tools、Agents 与推理/工具统一接口。
- Anthropic 官方文档：关注 MCP（Model Context Protocol）与工具接入。
- Google AI / Gemini API 文档：关注 grounding、tool use、实时搜索接入。
- Meta Llama 官方文档：关注开放模型的部署、微调与集成范式。

### 推理与服务框架

- vLLM 官方文档
- TensorRT-LLM 官方文档
- Ray Serve 官方文档
- Kubernetes 与服务网格相关文档

### 科学计算与训练框架

- PyTorch 官方文档
- JAX 官方文档
- Hugging Face 官方文档
- DeepSpeed / Megatron / FSDP 相关官方说明

### 航天、地球观测与在轨自治

- NASA Artificial Intelligence 主页：关注 mission planning、exploration、weather、autonomous systems。
- NASA Earthdata：关注 Earth Observation Data and AI、Prithvi 等 geospatial foundation model 入口。
- NASA DSA / Starling / HPSC：关注 distributed spacecraft autonomy、onboard computing、fault tolerance。
- ESA SPAICE / EO / onboard AI 公开会议与项目页：关注 AI for space、EO foundation model、space safety、data-driven mission operations。
- NASA NTRS 与 ESA 技术资料库：关注公开论文、任务规划、故障管理、在轨自治与验证。

### 高约束系统与安全治理公开文档

- NIST AI TEVV / deployed monitoring 文档：关注高风险系统监测、事件、证据与 assurance。

## 使用建议

- 更新层引用现实能力时，优先回到官方文档核对，而不是二手解读。
- 对新闻稿中的性能表述，不直接写入稳定知识层。
- 对 API 变化、弃用公告、工具协议变化，单独在 `archive/updates` 中维护时间戳页。
- 对航空航天和大型工程系统公开资料，优先吸收系统结构、约束、评测和治理信号，而不是个别宣传式案例。
