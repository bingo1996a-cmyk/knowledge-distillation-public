# 优化、正则化、curriculum 与 data mixture design

## 定位

这一页讨论深度学习训练链中的四个高负载环节：

1. **优化（optimization）**
2. **正则化（regularization）**
3. **课程学习（curriculum learning）**
4. **数据配比 / 数据配方（data mixture design）**

它们共同决定训练是否稳定、是否高效、是否可迁移，以及是否能为 foundation model、RL 或 scientific agent 提供可靠中间能力。

## 一、核心问题

现代训练并不是“给定模型和数据，然后跑优化器”这么简单。真实训练系统至少要回答：

- 学习率、批大小、权重衰减如何协同；
- 正则化是为了防过拟合、稳训练，还是隐式塑造表征；
- 样本顺序、难度和任务配比是否影响最终能力；
- 多来源数据如何配比，才能兼顾迁移、稳健性与成本。

## 二、优化主线

### 1. 优化器的角色

SGD、Momentum、Adam、AdamW 等优化器不只改变收敛速度，也会改变：

- 有效噪声尺度；
- 解的几何性质；
- 大批量训练稳定性；
- 不同参数子模块的学习节奏。

### 2. 学习率调度

常见机制包括：

- warmup；
- cosine decay；
- step decay；
- one-cycle；
- adaptive schedule。

其作用不是形式化装饰，而是直接影响：

- 早期不稳定；
- 中期收敛效率；
- 后期微调平衡；
- 大规模分布式训练的数值安全性。

## 三、正则化主线

### 1. 显式正则化

- weight decay；
- dropout；
- label smoothing；
- data augmentation；
- stochastic depth。

### 2. 隐式正则化

- SGD 噪声；
- 早停（early stopping）；
- batch size 选择；
- 参数共享；
- 架构归纳偏置。

### 3. 正则化不是永远“越强越好”

过强正则化可能损害：

- 高容量模型的表示形成；
- 长上下文记忆；
- 精细控制任务；
- 稀有模式学习。

## 四、curriculum learning 主线

课程学习讨论样本以什么顺序进入训练。  
典型策略包括：

- 从易到难；
- 从短上下文到长上下文；
- 从高置信高质量数据到混合数据；
- 按任务阶段或能力阶段切换训练目标。

它对下列问题尤其重要：

- 训练稳定性；
- 稀疏奖励 RL；
- 多任务训练中的干扰；
- scientific agent 的协议学习与执行恢复。

## 五、data mixture design 主线

### 1. 为什么数据配方重要

现代基础模型经常使用多来源数据混合训练。核心难点包括：

- 通用语料与高质量语料如何平衡；
- 代码、数学、科学文本、对话、工具轨迹如何配比；
- 过度重复某类数据是否会形成偏置；
- mixture 是静态的还是动态调度的。

### 2. data mixture 的系统后果

数据配方不仅影响训练损失，也影响：

- 指令跟随；
- 工具使用；
- reasoning；
- domain transfer；
- 安全边界与错误模式。

## 六、常见失败模式

- 学习率与 batch size 不匹配，训练发散；
- 为追求吞吐盲目增大 batch，导致泛化退化；
- 只依赖固定混合比例，忽视阶段性能力需要；
- curriculum 设计与真实部署任务脱节；
- 把所有数据都视为可互换 token，忽视信息密度与 provenance 差异。

## 七、评测指标

- train/val loss；
- gradient norm 与 update norm；
- stability incidents；
- sample efficiency；
- downstream transfer lift；
- data efficiency；
- mixture ablation；
- safety / calibration drift after post-training。

## 八、研究切口

- curriculum 与 data mixture 能否联合作为控制变量优化；
- foundation model 的最佳 mixture 是否随训练阶段动态变化；
- RLHF/RLAIF/工具轨迹是否应被纳入统一数据配方；
- 在高风险领域中，数据 provenance 与 mixture design 如何影响可验证性。
