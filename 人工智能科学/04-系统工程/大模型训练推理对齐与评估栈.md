# 大模型训练、推理、对齐与评测栈

## 1. 全栈视角

大模型技术不应只写“预训练 + 微调”，更完整的系统栈包括：

- 数据治理；
- 预训练；
- 适配与蒸馏；
- 后训练与对齐；
- 推理服务；
- 工具与 agent 编排；
- 评测与监测；
- 运行时策略与发布门禁。

## 2. 训练层

- tokenizer / corpus / filtering；
- objective；
- scaling law；
- optimizer / batch / distributed training；
- checkpoint / ablation / eval during training。

## 3. 对齐层

- instruction tuning；
- preference optimization；
- RLHF / RLAIF；
- safety tuning；
- verifier / critique / self-refinement。

## 4. 推理层

- KV cache；
- batching；
- routing；
- tool use；
- retrieval；
- reasoning budget。

## 5. 评测层

- task eval；
- capability eval；
- safety eval；
- agent eval；
- real-world rollout / human review。

## 6. 系统层

- policy registry；
- runtime governance；
- observability；
- incident taxonomy；
- release gate。
