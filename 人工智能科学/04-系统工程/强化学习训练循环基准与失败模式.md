# 强化学习训练循环、基准、评估指标与失败模式

## 1. 训练循环

强化学习训练不是单次拟合，而是交互—更新—评估闭环：

1. rollout collecting；
2. replay / trajectory storage；
3. target / return / advantage computation；
4. policy/value/model update；
5. periodic evaluation；
6. safety / stability / reproducibility check。

## 2. 评估指标

至少应区分：

- episodic return；
- sample efficiency；
- stability across seeds；
- constraint violation；
- robustness；
- sim2real gap；
- calibration of value / uncertainty estimate。

## 3. 常见 benchmark

- classic control；
- Atari；
- MuJoCo；
- DM Control；
- Procgen；
- multi-agent benchmark；
- robotics / sim2real suites。

## 4. 失败模式

- reward hacking；
- overestimation；
- catastrophic forgetting；
- distribution shift in offline RL；
- unsafe exploration；
- seed sensitivity；
- simulator overfitting。
