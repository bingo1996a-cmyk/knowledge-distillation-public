# 统计学习工作流：数据切分、估计、检验与模型选择

## 1. 为什么系统工程层需要这页

统计学习不只是理论层问题。在真实工作流中，数据如何切分、指标如何计算、显著性如何判断、模型如何选择，决定了整个实验是否可信。

## 2. 数据切分

典型切分：

- train / validation / test
- cross-validation
- time-based split
- group-based split

错误切分会导致信息泄漏（data leakage）。

## 3. 估计与不确定性

在系统工程层，估计不仅是参数估计，还包括：

- 指标区间估计；
- bootstrap；
- calibration curve；
- OPE（off-policy evaluation）；
- ablation 结果稳定性。

## 4. 假设检验与比较

当比较两个模型时，需要回答：

- 差异是否稳定；
- 差异是否显著；
- 差异是否具有工程意义。

因此应同时报告：

- 平均性能；
- 方差 / 置信区间；
- 显著性检验；
- 资源代价。

## 5. 模型选择与再验证

模型选择不应只基于单次最优结果，而应纳入：

- hyperparameter search trace
- reproducibility
- robustness under shift
- deployment constraints

## 6. 与 ML / DL / RL / LLM 的关系

- ML：交叉验证、特征选择、基线比较
- DL：seed variance、训练稳定性、数据配比
- RL：environment randomness、sample efficiency、OPE
- LLM：benchmark contamination、prompt variance、tool-use evaluation
