# 反向传播、优化器、归一化与训练栈

## 1. 这页讨论什么

本页讨论“训练一个深度模型或大模型时，真正的工程栈由什么组成”。

## 2. 基本训练栈

一个现代训练栈通常包括：

- 数据管线；
- 前向图；
- 损失计算；
- 反向传播；
- 优化器更新；
- 归一化与稳定化机制；
- 调度器；
- checkpoint 与评测。

## 3. 优化器

### SGD

基础、稳定、隐式正则化强，但在大模型中常被 Adam 系列取代。

### Adam / AdamW

适合稀疏梯度与大规模预训练。

### Adafactor / Lion 等

更关注大模型显存、通信与训练成本。

## 4. 归一化

常见类型：

- BatchNorm；
- LayerNorm；
- RMSNorm；
- WeightNorm。

它们的目标不完全相同，但都与训练稳定性、梯度尺度、优化地形有关。

## 5. 调度与配方

- warmup；
- cosine decay；
- curriculum；
- data mixture；
- gradient clipping；
- EMA；
- mixed precision；
- gradient accumulation。

## 6. 常见失败模式

- loss 爆炸；
- norm 漂移；
- 表征塌缩；
- train/eval mismatch；
- distributed desync；
- data contamination。
