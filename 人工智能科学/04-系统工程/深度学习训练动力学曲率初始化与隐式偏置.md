# 深度学习训练动力学：曲率、初始化与隐式偏置

## 1. 这一页关注什么

深度学习训练成败不只由“模型够不够大”决定，还受训练动力学支配：

- 初始化决定进入哪类区域；
- 曲率决定优化难度；
- 学习率与 batch size 决定噪声尺度；
- 优化过程本身施加隐式偏置。

## 2. 曲率与优化地形

Hessian 及其谱反映局部曲率。高曲率方向容易导致训练不稳定，低曲率方向影响收敛速度。现代训练中常关注：

- sharp minima vs flat minima
- conditioning
- gradient noise scale

## 3. 初始化

合理初始化的目标是控制激活与梯度在层间传播时不爆炸也不消失。Xavier、He 初始化等都服务于这一点。

## 4. 学习率与 batch size

学习率影响更新步长，batch size 影响梯度噪声。二者共同决定：

- 收敛速度；
- 逃离坏局部区域的能力；
- 泛化倾向。

## 5. 归一化与残差结构

BatchNorm、LayerNorm、残差连接等，不只是“训练技巧”，而是对优化几何的改造。

## 6. 隐式偏置

SGD 与其变体不只是求解器，也在选择某类解。其偏向与：

- 范数大小
- 平坦性
- 低复杂度表示

等性质相关。
