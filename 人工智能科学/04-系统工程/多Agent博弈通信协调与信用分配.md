# 多智能体系统中的博弈、通信、协调与信用分配

## 定位

这篇笔记是“多智能体系统”专题的深挖版，重点讨论多智能体研究最难但最核心的四个问题：

- 博弈（game）
- 通信（communication）
- 协调（coordination）
- 信用分配（credit assignment）

它更接近博士阶段真正的研究入口，而不是概念总览。

## 一、概念边界

### 1. 多智能体不等于多个模型并行

只要不同个体之间存在策略耦合、资源竞争、观测依赖或任务协作，多智能体问题就不再能被简单分解为若干个独立单体问题。

### 2. 为什么难

多智能体系统至少同时面临：

- 环境非平稳性；
- 联合动作空间爆炸；
- 局部观测导致的信息不完备；
- 个体收益与全局收益冲突；
- 通信受限；
- 责任难以追溯。

## 二、博弈论视角

### 1. 三类基本结构

- **合作博弈（cooperative game）**：目标以团队收益为主；
- **非合作博弈（non-cooperative game）**：个体独立优化自身收益；
- **混合博弈（mixed-motive game）**：合作与竞争同时存在。

### 2. 关键对象

- Nash equilibrium
- correlated equilibrium
- Stackelberg game
- potential game
- mean-field game

这些对象提供的是分析结构，不自动给出可计算算法。

## 三、通信问题

### 1. 为什么通信是核心瓶颈

在局部观测下，若无通信，个体难以估计全局态势；但通信本身有代价：

- 带宽消耗；
- 时延；
- 丢包；
- 对抗场景中的窃听与欺骗；
- 过度共享导致的信息冗余。

### 2. 通信设计维度

- 何时通信；
- 与谁通信；
- 发什么；
- 用何种编码；
- 是否可信；
- 谁来融合。

### 3. 常见机制

- 显式消息传递；
- 图神经网络通信；
- 黑板系统（blackboard system）；
- learned communication protocol；
- 事件触发式通信。

## 四、协调问题

### 1. 协调不只是“动作一致”

协调至少包括：

- 时间协调；
- 空间协调；
- 角色协调；
- 资源协调；
- 目标协调。

### 2. 常见结构

- 集中训练、分散执行（Centralized Training, Decentralized Execution, CTDE）
- 分层多智能体（hierarchical MARL）
- 任务分配 + 局部控制
- 图结构协同
- 领导者—跟随者（leader-follower）

## 五、信用分配问题

### 1. 为什么是难点

在群体任务中，最终奖励往往是全局的，但行动是局部的。于是问题变成：

**团队成败应归因到哪个体、哪个时刻、哪个动作？**

### 2. 典型困难

- 延迟奖励；
- 多个个体动作相互耦合；
- 同一结果可能由多条路径造成；
- 局部贡献与全局价值不一致。

### 3. 常见思路

- difference reward
- counterfactual baseline
- value decomposition
- Shapley value 近似
- trajectory attribution

## 六、形式化表达

设联合策略为 \(\pi(a_1,\dots,a_n \mid o_1,\dots,o_n)\)，全局回报为：

$$
J(\pi) = \mathbb{E}\Big[\sum_{t=0}^{T} \gamma^t r_t^{\text{team}}\Big]
$$


问题不在于如何定义团队回报，而在于如何构造个体更新信号 \(g_i\)，使其既有局部可学习性，又尽可能不偏离全局目标。

## 七、失败模式

### 1. 协调退化为同质化

所有体学成相似行为，缺少角色分工。

### 2. 通信学成噪声通道

消息看似存在，但对任务贡献极低。

### 3. 奖励投机

个体利用全局奖励漏洞，学出对团队长期无益的行为。

### 4. 非平稳性导致训练震荡

每个体都在更新，导致其他体观察到的环境分布不断变化。

### 5. 仿真中有效，部署时失效

通信理想化、同步假设过强、观测噪声过低时，现实落地会迅速崩塌。

## 八、评测指标

- 团队收益与任务完成率
- 个体贡献分布
- 通信效率：消息量、延迟、有效载荷比
- 协调质量：冲突率、重复率、时间窗重合度
- 角色稳定性与切换成本
- 对个体故障与通信受损的鲁棒性
- 分布外对手或扰动下的性能保持率

## 九、研究切口

1. **受限通信下的协同策略学习**：面向带宽、时延、对抗干扰约束。
2. **信用分配与因果归因结合**：把反事实分析引入多智能体奖励设计。
3. **世界模型辅助多智能体协调**：用共享预测器降低通信负担。
4. **图结构与群体动态耦合建模**：把任务图、通信图、物理图联合起来。
5. **作战/群体控制场景的分层协同优化**：将任务协同、时空协同、控制协同统一建模。
