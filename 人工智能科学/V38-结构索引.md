# V38 Structure Index — 元数据化

## 1. 总体说明

V38 是 V37—V40 远景路线的第二阶段"元数据化"，目标是为全库所有 `.md` 文件添加 YAML 前置元数据并提供机器可读索引。V38 依赖 V37 完成（消灭存根后 status 字段才有稳定值）。

## 2. 工作分解

### V38.1 — 元数据规范文档 + 工具脚本

| 文件 | 说明 |
|------|------|
| `00-overview/metadata-specification.md` | 元数据规范，定义七个核心字段、受控词表、文件分类范例、维护规则 |
| `scripts/add-metadata.py` | 批量添加脚本，支持逐层处理、干跑预览、强制覆盖 |
| `scripts/metadata-check.py` | 完整性检查脚本，统计覆盖率、字段缺失、状态分布 |
| `scripts/generate-index.py` | JSON 索引生成脚本，从 YAML 元数据输出结构化索引 |

### V38.2 — 全库 YAML 元数据添加

批量处理全部目录（含根级文件），自动推断以下字段：

- `title`：从一级标题提取
- `layer`：从目录路径映射
- `tags`：按层分配默认标签
- `status`：全部设为 `stable`
- `prerequisites`、`see-also`、`last-updated`：留空或使用当前日期
