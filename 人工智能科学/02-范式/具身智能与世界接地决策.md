# 具身智能与世界约束下的决策范式

## 1. 为什么具身智能是一条独立路线

具身智能（embodied intelligence）不是“把大模型装到机器人里”，而是研究：

- 智能如何在物理世界中感知、行动、校正和学习；
- 决策如何同时受几何、动力学、接触、时延、能耗与安全约束影响；
- 世界模型、规划、控制与表征学习如何共同工作。

## 2. 与传统 AI 范式的差异

### 2.1 与符号主义相比

具身系统不能只在离散符号空间里操作，因为它必须面对连续状态、感知噪声与执行误差。

### 2.2 与纯监督学习相比

具身系统的样本来自交互，不是静态数据集；动作会改变未来观测分布。

### 2.3 与经典控制相比

具身智能吸收控制理论，但不止于稳定性分析，还要处理高维感知、复杂环境和开放任务。

## 3. 具身智能的四个基本模块

1. 感知：视觉、触觉、语言、地图与状态估计；
2. 世界模型：对环境动态与任务后果的内部表示；
3. 决策：规划、RL、MPC、层级策略；
4. 控制执行：低层控制、约束处理、安全壳与恢复机制。

## 4. 基本思想

具身智能的核心思想可以概括为：

> 智能不是脱离世界的纯推理，而是在可观测性有限、动力学受限、执行有噪声的物理环境中，通过感知—预测—决策—控制闭环逐步实现任务。

## 5. 为什么 world model 很关键

world model 提供：

- imagined rollout；
- 反事实评估；
- 长时规划；
- 跨任务泛化；
- 数据效率提升。

## 6. 与大模型路线的交叉

今天的具身智能越来越与：

- vision-language-action model；
- tool-using agent；
- reasoning + planning；
- world-grounded memory

结合。

但不能忽略一个事实：物理执行中的失败代价比纯文本任务高得多，因此 runtime governance、safe degradation、shielded control 必须进入主干。
