# 统计机器学习：从 ERM 到贝叶斯与结构化预测

## 1. 定位

这页补在"统计学习"与"机器学习"之间，强调统计机器学习不是若干经典算法的堆积，而是一条从经验风险最小化（ERM）出发、经过泛化理论、核方法、概率图模型、贝叶斯推断，最终通向现代深度学习的连续演化主轴。

## 2. 从 ERM 出发

经验风险最小化是最基础的学习框架：在训练集上最小化预测误差的均值。ERM 的优点是简单直接，核心困难是泛化——训练误差小不等于测试误差小。围绕这一困难，统计学习理论给出了正式的收敛条件和样本复杂度界（Vapnik-Chervonenkis 维、Rademacher 复杂度），在实践中则通过正则化（L1、L2、数据增强、早停）来控制有效模型复杂度。

## 3. 判别式与生成式

- **判别式方法**：直接建模 \(p(y \mid x)\) 或学习决策边界。逻辑回归、SVM、神经网络属于此类。通常在有足够标注数据时表现更好。
- **生成式方法**：建模联合分布 \(p(x, y)\) 并从中推导 \(p(y \mid x)\)。朴素贝叶斯、隐马尔可夫模型、高斯混合模型属于此类。在小样本、缺失数据、结构化标注任务中更有优势。

两者在不同数据规模和先验知识条件下各有适用场景，不构成绝对的高低。

## 4. 核方法于间隔最大化

核方法将线性模型通过核技巧隐式映射到高维特征空间中，使其能处理非线性模式。SVM 是典型代表——通过最大化间隔提升泛化性，通过核函数处理非线性，通过与支持向量对应的稀疏解获得计算效率。核方法在 1990s-2000s 统治了机器学习，直到深度网络在大规模数据上展示出更强的表示学习能力。

## 5. 结构化预测

当输出不是单个标签而是一组相互依赖的结构（序列、树、图、对齐）时，需要结构化预测。条件随机场（CRF）、结构化 SVM、基于能量的模型属于此类。结构化预测的核心是解码——在指数级大的输出空间中搜索最优结构。维特比算法、柱搜索、整数线性规划等是常用的解码工具。结构化预测在自然语言处理（序列标注、句法分析）、计算生物学（蛋白质结构预测）、机器视觉（语义分割）中有广泛应用。

## 6. 贝叶斯学习

贝叶斯方法为学习提供了完全的概率框架：指定先验分布 \(p(\theta)\)，观测数据后计算后验 \(p(\theta \mid D)\)，预测时在参数空间上积分。最大后验估计（MAP）是点估计版的贝叶斯推断，而完全贝叶斯预测需要对整个后验做积分——这在高维参数空间中通常需要用 MCMC 或变分推断来近似。

## 7. 向深度模型的连续谱

统计机器学习的这些核心理念并没有被深度学习抛弃，而是在深度框架中发生了形态变化：ERM 依然是训练目标；正则化以 dropout、weight decay 和 attention dropout 等新形式存在；判别式-生成式的二分在 VAE/GAN/扩散模型中以更适合深度网络的方式再现；核方法的影响体现在注意力机制（Neural Tangent Kernel 提供了深层网络与核方法的理论连接）。了解统计机器学习的主线有助于深度学习实践者理解许多被默认继承的假设和边界条件。
