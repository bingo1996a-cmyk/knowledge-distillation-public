# 从表征学习到基础模型：深度学习主线总论

## 定位

这一页不是替代“深度学习（Deep Learning）”范式入口，而是把现代深度学习重新组织成一条更适合博士阶段阅读的主线：

`表征学习 -> 自监督学习 -> 迁移学习 -> 预训练 -> 基础模型（foundation model） -> 后训练与部署`

它试图回答三个问题：

1. 为什么“表征（representation）”是理解深度学习的更好入口；
2. 为什么现代基础模型不是孤立出现，而是训练范式长期演化的结果；
3. 理论解释、工程实现与能力边界如何被放在同一条链上理解。

## 一、概念边界

### 1. 深度学习不只是“大网络拟合函数”

更有解释力的看法是：深度学习是在高维数据中学习一组可组合、可迁移、可压缩的表征。  
模型的价值不只体现在任务头（task head）上，更体现在：

- 是否学到了有用表征；
- 是否能跨任务迁移；
- 是否能通过预训练吸收大规模先验；
- 是否能在有限监督下快速适配。

### 2. 基础模型不是单一架构概念

“基础模型”更接近一种训练与使用方式，而不是某一个固定模型族。它通常具有：

- 大规模数据预训练；
- 跨任务迁移能力；
- 后训练或对齐阶段；
- 可被工具、检索、记忆和推理系统调用；
- 在多个应用域形成通用中间层。

### 3. 范式转换的关键不是参数量，而是数据与任务组织方式

从 AlexNet 时代到 foundation model 时代，真正变化的不只是参数量，而是：

- 监督信号从人工标签转向自监督目标；
- 任务从单任务分类转向多任务迁移；
- 模型从任务专用转向预训练 + 适配；
- 优化目标从“单一 benchmark 最优”转向“广泛迁移与可扩展性”。

## 二、主线结构

### 1. 表征学习（representation learning）

早期深度学习的重要突破之一，是不再手工设计全部特征，而是通过多层非线性变换自动学习表征。  
这一层的核心问题包括：

- 表征是否压缩了无关噪声；
- 表征是否保留了任务所需不变量；
- 表征是否具有迁移性；
- 表征是否与下游控制、推理和决策兼容。

### 2. 自监督学习（self-supervised learning）

自监督学习使模型能从未标注数据中构造训练信号，例如：

- 对比学习（contrastive learning）；
- 掩码建模（masked modeling）；
- 自回归建模（autoregressive modeling）；
- 预测未来片段、重建缺失信息或对齐多模态数据。

它的重要性在于：  
**监督标签不再是能力来源的唯一入口，数据结构本身成为信号来源。**

### 3. 迁移学习（transfer learning）

迁移学习回答的是：

- 一个任务学到的表征能否服务另一个任务；
- 预训练是否能降低下游样本复杂度；
- 微调、适配器、LoRA、prompt tuning 等技术如何改变迁移成本。

从工程角度看，迁移学习把“训练一个模型”变成了“维护一个可复用能力层”。

### 4. 预训练与基础模型

基础模型通常依赖大规模预训练，将模型训练为一个通用表示与生成平台。  
其能力往往取决于四个耦合变量：

- 模型规模；
- 数据规模与质量；
- 训练计算；
- 后训练与部署策略。

### 5. 后训练与系统化使用

模型在预训练后并不能直接进入高风险真实系统。后训练阶段通常需要：

- 指令跟随；
- 偏好优化；
- 安全对齐；
- 工具使用；
- 检索增强；
- 长上下文与记忆管理；
- 评测与发布门禁。

## 三、核心问题

### 1. 为什么表征是主线而不是附属概念

很多现代现象——泛化、迁移、自监督预训练、多模态对齐、工具调用前的语义抽象——都更容易用表征来解释，而不是只用“拟合能力”解释。

### 2. 为什么基础模型时代强调“尺度扩展 + 数据配方 + 后训练”

现代基础模型的能力上限，不是单一优化器决定的，而是由一整条训练链共同决定：

`数据配方 -> 架构 -> 预训练目标 -> 优化与并行 -> 后训练 -> 评测与部署`

### 3. 为什么失败模式越来越系统化

当模型进入 foundation model 阶段，失败模式不再只是“欠拟合/过拟合”，而包括：

- 预训练数据污染；
- 表征坍塌或偏置积累；
- 迁移不稳定；
- 分布外脆弱性；
- 指令对齐与真实目标不一致；
- 部署阶段工具误用与系统级幻觉。

## 四、系统视角

从系统工程看，深度学习主线至少包含四层：

1. **理论层**：优化、泛化、表征、自监督、尺度律；
2. **模型层**：CNN、Transformer、GNN、VLM、LLM、VLA；
3. **系统层**：数据、训练、后训练、部署、评测；
4. **应用层**：科学发现、控制、具身智能、航天、公开高风险治理场景。

## 五、常见失败模式

### 1. 范式误读

- 把“基础模型”理解成“大参数模型”；
- 把“表征学习”缩减成下游分类特征；
- 把“自监督”误解为完全不需要人为结构设计。

### 2. 工程误配

- 数据量增加但质量与覆盖不足；
- 迁移目标与预训练目标严重脱节；
- 过度追求 benchmark 指标而牺牲系统稳定性；
- 把后训练阶段当成补丁，而不是系统目标重写阶段。

### 3. 研究误区

- 只比较模型大小，不比较训练条件；
- 只看平均指标，不看校准、分布漂移和稳健性；
- 忽视跨任务迁移成本、维护成本和上线成本。

## 六、评测指标

可从四组指标理解这条主线：

1. **表征质量**：线性探针、迁移性能、聚类结构、跨域稳健性；
2. **训练效率**：损失下降速度、数据效率、计算效率；
3. **迁移性能**：few-shot、domain adaptation、下游样本需求；
4. **系统适用性**：校准、可解释性、对齐质量、错误恢复能力。

## 七、研究切口

### 1. 理论向

- 表征形成与泛化之间的因果关系；
- 自监督目标与下游能力之间的匹配关系；
- 基础模型的能力边界与失败模式解释。

### 2. 工程向

- 数据配方、curriculum 与 scaling 的联合优化；
- 低资源迁移、参数高效适配与连续学习；
- foundation model 在真实系统中的部署约束。

### 3. 面向博士研究的可用问题

- 如何构造既支持迁移又支持控制/推理接口的中间表征；
- 自监督目标设计如何影响高风险场景下的可靠性；
- 基础模型在多模态、时空与具身任务中的统一表征能否成立。
