# 从监督学习到自监督与多模态预训练：学习范式迁移图

## 1. 定位

这一页不是介绍某一个模型家族，而是回答：

- 学习信号从哪里来；
- 为什么 AI 的主流训练范式会从监督学习逐步转向自监督与多模态预训练；
- 这些变化如何改变研究问题、工程组织与能力边界。

## 2. 三种主导范式

### 2.1 监督学习范式

核心假设是：

- 有相对清晰的输入—标签对；
- 任务目标定义明确；
- 模型通过经验风险最小化拟合映射。

优势：

- 问题定义清楚；
- 评价指标稳定；
- 在封闭任务中性能很强。

局限：

- 标签昂贵；
- 对任务定义高度依赖；
- 难以自然扩展到开放世界知识吸收。

### 2.2 自监督学习范式

核心思想是：从数据自身构造训练信号。典型目标包括：

- 对比学习；
- 掩码预测；
- 自回归下一 token / 下一片段预测；
- 多视角一致性；
- 多模态对齐。

意义在于：

- 未标注数据成为主要资源；
- 表征质量成为中心问题；
- 迁移与预训练开始压过单任务最优。

### 2.3 多模态预训练范式

当文本、图像、音频、视频、轨迹、动作、传感器流被统一纳入预训练后，问题变成：

- 如何建立跨模态共享表示；
- 如何处理模态缺失、时间对齐与语义不一致；
- 如何把生成能力、感知能力与决策能力放入同一系统。

## 3. 范式迁移的根本原因

### 3.1 数据经济学变化

互联网和平台化系统使未标注数据激增，标签不再是最丰富资源。

### 3.2 目标变化

AI 研究从“任务专用预测器”转向“通用能力层”。

### 3.3 系统变化

模型越来越像平台：

- 可被不同任务复用；
- 可通过后训练调整；
- 可被工具、检索和执行环境调用。

## 4. 典型范式之间的关系

### 4.1 监督学习没有消失

在高质量标注任务、闭环控制和高风险验证中，监督学习仍然关键。

### 4.2 自监督学习不是监督学习的替代，而是前置能力层

更实用的工程组织是：

`自监督预训练 -> 少量监督适配 -> 评测与治理`

### 4.3 多模态预训练不是简单拼接数据

它要求：

- 模态接口设计；
- 对齐损失设计；
- 缺失模态鲁棒性；
- 系统级评测与故障诊断。

## 5. 对深度学习和 RL 的影响

- 深度学习的核心焦点从“架构微调”转向“预训练信号与数据组织”；
- RL 与 sequence modeling、world model、trajectory pretraining 的边界变得更模糊；
- agent 系统越来越依赖预训练能力层，而不是从零学习全部能力。

## 6. 常见失败模式

1. 预训练目标与下游目标错位；
2. 自监督学到的表示对任务不敏感；
3. 多模态对齐只在 benchmark 上成立，部署后失效；
4. 标签稀缺任务中误以为“只靠大规模预训练就够了”；
5. 评测仍停留在单任务指标，无法反映迁移与组合能力。

## 7. 研究切口

1. **自监督表示与可解释性**；
2. **多模态预训练中的对齐与校准**；
3. **监督 / 自监督 / 强化学习之间的统一框架**；
4. **高风险系统中的预训练能力审计**；
5. **科学、航天和机器人中的多模态预训练范式**。
