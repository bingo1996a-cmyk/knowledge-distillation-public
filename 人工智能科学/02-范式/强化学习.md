# 强化学习

## 1. 基本思想

强化学习（reinforcement learning, RL）研究的是：智能体在与环境的持续交互中，如何通过试错学习一个策略，使长期累积回报最大。

与监督学习不同，强化学习中的目标并不是“对每个样本给出正确标签”，而是：

- 行动会影响未来数据分布；
- 回报常是延迟的；
- 当前最优动作取决于长期后果；
- 数据通常不是独立同分布的。

## 2. 三个基本对象

- 状态 $s$；
- 动作 $a$；
- 奖励 $r$。

策略 $\pi(a\mid s)$ 描述在状态下如何选动作，价值函数描述某状态或状态—动作对的长期收益。

## 3. RL 最根本的五个难点

1. **探索与利用**：不知道哪条路最好时，既要试新动作，又要利用当前最好动作；
2. **信用分配**：某个长期成功应归功于哪一步动作；
3. **估计偏差与方差**：MC 方差高，TD 有偏，如何权衡；
4. **分布漂移**：策略一变，数据分布也变；
5. **安全约束**：真实系统不能随便试错。

## 4. RL 的方法族

- 动态规划（DP）；
- Monte Carlo；
- 时序差分（TD）；
- 值函数法；
- 策略梯度；
- actor-critic；
- 模型化 RL；
- 离线 RL；
- 多智能体 RL。

## 5. 为什么 RL 与控制、agent、具身智能强相关

因为只要问题包含：

- 序列决策；
- 长期收益；
- 环境反馈；
- 动作影响未来观测；

它就天然接近 RL。控制中的轨迹优化、机器人中的闭环动作选择、agent 中的工具调用计划、推荐系统中的交互优化，都可以映射到 RL 视角。
