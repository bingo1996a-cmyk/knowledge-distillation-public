# 思想史与文化入口页（V36）

## 定位

这一层不是"背景材料"，而是整个知识库的历史骨架。它回答三个问题：

1. 今天的模型、算法和系统是怎样一步步长出来的；
2. 为什么某些路线在某个时期突然占上风，另一些路线却退潮；
3. 哪些成果只是学术论文，哪些成果真正改写了产业和社会的应用格局。

## 这一层的写作规则
- 重要成果尽量标注年份；
- 重要应用尽量标注首次形成社会影响的时间节点；
- 尽量说明提出者、论文、系统或机构来源；
- 叙述可以有节奏，但不能脱离可核查史实。
