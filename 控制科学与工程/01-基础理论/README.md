# 基础理论

## 定位

本模块是控制科学与工程知识库的学科底座。没有这些概念，后续所有模块都无法顺利阅读。它回答动态系统、反馈、稳定性和状态空间等最底层问题，为经典控制、现代控制和高级控制方法提供共同语言。

## 这个模块回答什么核心问题

- 系统如何随时间演化，状态、输入、输出之间的关系是什么？
- 反馈为什么能改变系统行为，它有什么代价和风险？
- 稳定性如何定义、如何判断，为什么它是控制系统的硬底线？
- 状态空间（state space）是什么，它为什么是现代控制的共同语言？
- 在不完整观测、不精确模型和输入受限时，系统还能否被有效控制？

## 已建页面清单

- **控制基础理论概览.md**：基础理论概览，宏观介绍动态系统、反馈、稳定性、状态空间、估计辨识和工程约束六大主题。
- **动态系统.md**：动态系统的基本概念，包括连续/离散时间系统、线性/非线性系统分类，以及控制视角下的关键性和常见误区。
- **反馈.md**：反馈的核心思想，负反馈与正反馈的区别，反馈的价值（抗扰、修正误差）与代价（振荡、噪声放大）。
- **稳定性.md**：稳定性的定义与分类（BIBO 稳定、Lyapunov 稳定、渐近稳定、指数稳定、输入到状态稳定），Lyapunov 思想及工程检查方法。
- **状态空间系统.md**：状态空间模型的基本形式，可控性、可观性、状态反馈和状态估计四个核心问题，与传递函数的关系。
- **平衡点与线性化.md**：平衡点与线性化，将非线性系统在平衡点附近近似为线性系统。
- **可控性与可观性基础.md**：可控性与可观性的基础概念解析，Gramian 视角。
- **采样与离散化.md**：采样与离散化，连续系统到离散系统的转换。
- **不确定性扰动与噪声.md**：不确定性、扰动与噪声的建模与分类。
- **性能约束与权衡.md**：性能约束与权衡，如带宽-噪声权衡、快速性-鲁棒性矛盾。

## 与相邻模块的关系

- **前置依赖**：建议先阅读 `00-概述` 模块的总地图和阅读路径，建立整体框架后再进入本模块。

- **毗邻关系**：本模块提供概念底座，与所有后续模块都有基础连接。与 `00-概述` 的关系是"导航与内容"；与 `02`、`03` 的关系是"基础与应用"——本模块只讲概念定义和分类，不讲具体设计方法。

## 适合的读者

- 自动化、电子、机械、航天等刚接触控制理论的本科生或跨专业研究生。
- 来自人工智能或计算机科学领域、需要理解系统观和闭环思维的研究者。
- 从事嵌入式或系统工程实践、希望夯实控制系统理论基础的工程师。
