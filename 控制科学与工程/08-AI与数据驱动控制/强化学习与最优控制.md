# 强化学习与最优控制 (Reinforcement Learning and Optimal Control)

## 定位

强化学习（RL）与最优控制之间存在深刻的数学等价性——两者都求解"在动态系统中找到最优决策序列"的问题。最优控制假设已知系统模型 $x_{k+1} = f(x_k, u_k)$ 并利用该模型显式求解值函数或控制律；RL 则在不假设模型已知的情况下通过与系统交互（trial-and-error）学习最优策略。两者构成了"基于模型的最优控制"与"无模型的最优控制"连续谱的两端。

在知识体系中，RL 是控制理论向数据驱动方向的自然延伸。价值网络的贡献不仅仅在于"无模型"，更在于它提供了一种处理任意复杂奖励函数和非经典控制目标（如长期回报、稀疏奖励、多目标权衡）的框架——这些是传统最优控制难以直接处理的问题。理解 RL 与最优控制的关系有助于避免将两者视为对抗范式，而是根据问题特点选择最适合的方法。

## 核心问题

**探索-利用困境（Exploration-Exploitation Dilemma）**：RL 智能体必须在"尝试未知动作以获取更多知识"和"使用已知最佳动作以最大化回报"之间权衡。过多的探索降低回报，过少的探索导致学到次优解。在控制问题中，探索可能使系统进入不安全状态——这是 RL 在安全关键控制中面临的根本障碍。

**信用分配（Credit Assignment）**：当智能体在一系列动作后才能获得奖励（延迟奖励）时，需要确定哪些动作对最终结果有贡献。在控制问题中，延迟奖励常见于——施加一个控制动作后需要较长时间才能观察到其对系统稳定性的影响。时间差分学习（TD）通过值函数估计解决了信用分配问题。

**样本效率**：无模型 RL 算法通常需要数百万步的交互才能学到有效的控制策略，这在物理控制系统中是不可接受的（设备磨损、能源消耗、安全风险）。样本效率是将 RL 从仿真世界带到物理世界的核心瓶颈。

## 基本模型

**马尔可夫决策过程 (MDP)**：RL 和最优控制的公共数学基础。MDP 由五元组 $(\mathcal{S}, \mathcal{A}, P, r, \gamma)$ 定义——状态空间 $\mathcal{S}$、动作空间 $\mathcal{A}$、转移概率 $P(s'|s,a)$（对应控制中 $x_{k+1} = f(x_k, u_k)$ 的概率扩展）、奖励函数 $r(s,a)$（对应控制的负代价函数 $-l(x,u)$）、折扣因子 $\gamma \in [0,1)$。最优控制的 MDP 扩展将确定性转移替换为随机转移，将二次代价替换为任意形式的奖励。

**值函数与 Q 函数**：值函数 $V^\pi(s) = \mathbb{E}^\pi[\sum_{t=0}^\infty \gamma^t r(s_t, a_t) | s_0 = s]$ 度量从状态 $s$ 出发遵循策略 $\pi$ 的期望回报。Q 函数 $Q^\pi(s,a) = \mathbb{E}^\pi[\sum_{t=0}^\infty \gamma^t r(s_t, a_t) | s_0 = s, a_0 = a]$ 度量在状态 $s$ 下采取动作 $a$ 再遵循策略 $\pi$ 的期望回报。最优值函数 $V^*$ 和最优 Q 函数 $Q^*$ 满足 Bellman 最优方程：

$$
Q^*(s,a) = r(s,a) + \gamma \mathbb{E}_{s' \sim P(\cdot|s,a)}[\max_{a'} Q^*(s', a')]
$$

在连续状态-动作空间中，$V$ 和 $Q$ 通过函数逼近器（神经网络）近似——这对应控制中的 ADP（近似动态规划）。

**策略梯度 (Policy Gradient)**：直接参数化策略 $\pi_\theta(a|s)$（如确定性策略 $u = \pi_\theta(x)$ 对应状态反馈控制律），通过梯度上升最大化期望回报 $\nabla_\theta J(\theta) = \mathbb{E}[\nabla_\theta \log \pi_\theta(a|s) Q^\pi(s,a)]$。策略梯度方法在处理高维/连续动作空间时具有优势，因为其直接优化策略而不需要求解值函数最大值。深度确定性策略梯度（DDPG）及其后续改进（TD3、SAC）是连续控制中 RL 最常用的方法。

## 关键概念

**LQR 与线性二次型调节器的 RL 视角**：LQR 对应一种特殊的 MDP——线性转移 $x_{k+1} = Ax_k + Bu_k$、二次成本 $l(x,u) = x^TQx + u^TRu$、无折扣（$\gamma=1$）。LQR 的值函数恰好是二次型 $V(x) = x^T P x$，其中 $P$ 为代数 Riccati 方程的解。RL 可以从数据中直接学习最优值函数和策略——Q-learning for LQR 从系统交互数据中直接学习最优 Riccati 矩阵 $P$。理论结果：当噪声为全状态可观测的高斯噪声时，基于模型的方法（先辨识 $A,B$ 再求解 Riccati 方程）和无模型方法（直接从数据学习 $P$）在渐近意义下的收敛速度相同——均为 $O(1/\sqrt{N})$ 的均方误差收敛率。

**SAC (Soft Actor-Critic) 与熵正则化**：SAC 在标准 RL 目标中引入策略熵 $H(\pi(\cdot|s))$ 作为正则化项：

$$
J(\pi) = \sum_t \mathbb{E}[r(s_t, a_t) + \alpha H(\pi(\cdot|s_t))]
$$

熵正则化虽然是一个统计学习概念，但其效果在控制中有着清晰的物理解释——鼓励策略在多个近似等价的动作之间保持随机性，避免确定性策略中常见的"快速切换到次优动作"现象。SAC 的温度参数 $\alpha$ 控制着探索程度——$\alpha$ 越大，动作越随机。SAC 在连续控制任务中（机器人操作、运动控制）的稳定性和样本效率优于 DDPG 和 TD3。

**模型预测控制 (MPC) 与 RL 的融合**：MPC 和 RL 的最本质区别是"何时做优化"——MPC 在线每步重新求解（基于模型），RL 离线学习策略（无模型在线查找）。融合方式包括：（1）MPC 作为策略的提升算子——在策略迭代中使用 MPC 计算更优的动作，然后通过监督学习拟合策略网络；（2）RL 作为 MPC 的热启动和学习提高——用 RL 策略网络生成 MPC 的初始解以加速求解；（3）MPC 提供安全约束，RL 提供高性能——在 MPC 约束下用 RL 滚动优化的动作。

## 工程判断

**开环与闭环指标的差异**：RL 的评估指标通常分为训练期指标（累计奖励、平均回报、成功率——开环仿真中的累积指标）和部署期指标（收敛时间、稳态误差、约束违反率——闭环物理系统中的运行指标）。两者的根本区别在于分布偏移——训练时智能体探索产生的状态分布与部署时策略确定性执行产生的状态分布不同。工程上需要部署前对 RL 策略进行闭环仿真验证，在训练环境中对部署时可能遇到的状态分布进行鲁棒性测试。

**奖励函数工程（Reward Shaping）**：奖励函数设计是 RL 在控制应用中最关键的工程环节。好的奖励函数应该满足——（1）提供密集而非稀疏的反馈（每个时间步都有奖励信号，而非仅任务结束时）；（2）引导智能体逐步趋近期望行为（从粗到细的奖励层次）；（3）避免"奖励黑客"（reward hacking）——智能体发现了最大化奖励但物理上无意义的行为。对于控制问题，推荐的奖励函数结构：$r(x,u) = -[x^T Q x + u^T R u + \alpha \cdot \text{constraint\_violation}]$——与 LQR 成本对应，额外加入约束违反惩罚。

**从仿真到实物的策略迁移**：RL 在仿真中训练的策略直接部署到物理系统通常失效——仿真环境与真实环境之间的差异（sim-to-real gap）导致策略在未见过的状态上做出错误的决策。工程实践中采用的缓解方法包括——域随机化（Domain Randomization，在训练中随机化环境参数如摩擦系数、质量、延迟）、渐进式迁移（先在仿真中完全训练，再在真实系统中用更低的探索率微调）、以及系统辨识（将真实系统的参数辨识到仿真模型中）。

## 常见误区

**误区一："RL 可以替代最优控制做所有控制问题"**。RL 在需要强理论保证（稳定性、可行性、安全约束）的控制问题中目前仍然无法替代最优控制方法。RL 策略（特别是深度策略网络）不具备显式的约束保证能力，可能在学习过程中或部署后做出违反约束的动作。RL 更适合那些控制目标复杂、约束相对宽松、或者精确模型难以获得的控制问题——如游戏 AI、推荐系统、机器人技能学习等。对于安全关键系统（航空航天、汽车、医疗），RL 需要与保守的约束验证框架结合使用。

**误区二："无模型 RL 不需要系统模型，所以更通用"**。无模型 RL 确实不需要显式模型，但它的"隐式模型"是通过大量交互数据来构建的（存储在值函数或策略网络中）。无模型 RL 的样本效率比基于模型的方法低 1-2 个数量级——在物理系统上训练一个简单的倒立摆 RL 控制需要约 10^4-10^5 步交互，而基于模型的 MPC 或 LQR 只需要数十步到数百步的开环辨识实验。更通用的评价是"哪种形式的先验知识更容易获得"——如果是已知物理定律但难以建模非线性细节（如流体效应），基于模型的方法更好；如果是已知行为目标但系统动态完全未知（如任意模拟器），无模型 RL 有优势。

**误区三："RL 训练时用越多探索越好"**。在训练初期，探索确实有助于发现更优策略。但在训练的后期，过度探索会导致策略性能的剧烈波动——刚刚学到的策略在过度探索后可能被"冲淡"（策略参数的随机更新抹去了之前的好策略）。实践中的做法是使用"退火探索"（exploration annealing）——在训练初期设置较高的探索率，随着训练推进线性或指数地降低探索率。SAC 通过自动调整的温度参数 $\alpha$ 实现了自适应的探索水平。
