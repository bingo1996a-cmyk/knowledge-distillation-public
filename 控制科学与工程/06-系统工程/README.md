# 系统工程：实时、嵌入式与信息物理系统

## 定位

本模块是控制科学与工程知识库的工程实施层，负责回答一个关键问题：控制理论如何可靠地部署到真实物理系统中？控制律不只是在论文中写出的数学公式，而是由传感器、执行器、计算硬件、通信网络、实时软件、故障处理和运维流程共同构成的闭环系统——即信息物理系统（cyber-physical system, CPS）。

本模块位于知识库中后部，向上承接各方法模块（02-05）的控制算法设计，向下连接应用领域（07-应用领域），是理论与实践的转换层。

## 核心问题

- 控制算法在嵌入式硬件上实现时，离散化、量化、时延和抖动如何影响闭环性能？
- 实时系统中的采样周期、任务调度和超时策略如何设计？
- 传感器和执行器的非理想特性（噪声、漂移、饱和、死区）如何纳入控制设计？
- 控制器失败时，系统的安全退化和故障应对机制是什么？
- 控制理论保证的性质（稳定性、性能）如何在真实硬件上得到保留和验证？

## 与相邻模块关系

- **前置依赖**：需要理解经典控制（02）和现代控制（03）的基本设计方法，需要状态估计（05）和最优/鲁棒控制（04）算法输入。
- **后继出口**：系统工程为应用领域（07-应用领域）提供部署方案；AI 控制系统的安全壳和运行时监测（08）需要本模块的实时和故障处理基础。
- **毗邻边界**：不写成通用软件工程——所有讨论必须回到闭环系统。只要讨论部署、实现和验证，就优先考虑本模块。纯粹算法推导和理论证明归各方法模块。
