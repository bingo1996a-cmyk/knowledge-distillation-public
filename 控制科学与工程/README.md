# 控制科学与工程知识库

本子库位于 `知识蒸馏计划/控制科学与工程/` 之下，作为整个多主题知识工程中的一个独立主题分支。

控制科学与工程研究的是：如何描述动态系统，如何通过反馈改变系统行为，如何在不确定性、约束、扰动和工程代价下实现稳定、可靠、可验证的闭环运行。

当前版本完成全部 7 个阶段（Batch A-F）的骨架建设：总览层、基础理论层、经典控制层、现代控制层、高级控制层、估计与辨识层、系统工程层、应用层、AI 与数据驱动控制层、思想史层和附录层均已建立。应用层（07）9 个文件、AI 与数据驱动控制层（08）9 个文件、思想史层（09）6 个文件、附录层（90）4 个补充文件均已到齐。

本阶段的重点是战略总览和施工规则，而不是细节铺陈。已有专题页只作为后续扩写的种子样例，具体算法、教材推导和应用细节应交给后续智能体按任务单实施。

## 当前结构

- `00-概述`：知识库说明、阅读路径、总地图、符号与术语约定
- `01-基础理论`：动态系统、反馈、稳定性、状态空间等基础概念
- `02-经典控制`：传递函数、频域法、根轨迹、校正与工程直觉
- `03-现代控制`：状态空间、可控性、可观性、状态反馈与观测器
- `04-最优鲁棒自适应控制`：最优控制、MPC、鲁棒控制、自适应控制
- `05-估计与辨识`：状态估计、滤波、系统辨识与模型校准
- `06-系统工程`：实时系统、传感执行、嵌入式控制、CPS 工程
- `07-应用领域`：机器人、过程控制、航天航空、能源、交通与智能制造
- `08-AI与数据驱动控制`：学习增强控制、强化学习、安全 AI 控制
- `09-思想历史与文化`：控制思想史、学派、工程文化与方法论
- `90-附录`：参考教材、模板、待办清单与后续结构材料

## 当前原则

- 先建立学科骨架，再逐步深化专题；
- 先讲闭环、稳定性和系统观，再展开算法细节；
- 每个条目都尽量回答“系统是什么、反馈在哪里、稳定性如何保证、工程约束是什么”；
- 与数学、人工智能科学子库保持连接，但不把控制科学简化成数学分支或 AI 应用场。
