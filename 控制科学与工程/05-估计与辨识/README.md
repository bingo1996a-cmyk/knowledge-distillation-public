# 估计、滤波与系统辨识

## 定位

本模块回答控制工程中的关键前提问题：状态从哪里来？模型从哪里来？控制系统不能假设一切状态都可测、一切模型都准确。估计与辨识层填补了理论与现实之间的信息缺口，为高级控制（04）和系统工程（06）提供可用的状态信息和模型描述。

本模块位于知识库中部，向上承接状态空间基础（01-基础理论）和现代控制中的可观性概念（03-现代控制），向下为最优控制（04）和系统工程（06）提供必要的估计和模型输入，同时与 AI 与数据驱动控制（08）有深度的交叉。

## 核心问题

- 当系统状态不可直接测量时，如何从有噪声的传感器观测中恢复状态？
- 如何设计滤波器，在模型预测和传感器测量之间做出最优权衡？
- 从数据中建立或校准动态系统模型的方法和流程是什么？
- 系统辨识与机器学习有何本质区别？
- 估计误差如何进入控制闭环并影响系统性能？
