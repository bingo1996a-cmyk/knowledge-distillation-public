# 估计与辨识概览

## 定位

控制系统不能假设一切状态都可测、模型都准确。

估计与辨识层负责回答两个问题：

- 当前系统状态、参数和扰动是什么；
- 系统模型是否可信，是否需要从数据中辨识或校准。

## 为什么估计在控制中不可回避

估计问题在工程实践中无处不在，其根本原因在于理想化的"全状态可测、模型精确"假设在现实中几乎无法成立：

- **传感器成本限制**：高精度传感器（如激光雷达、六维力传感器、高精度编码器）价格昂贵，实际系统中只能布置有限数量的传感器。例如，工业机械臂的关节力矩通常通过电流估算而非直接测量。
- **物理不可测变量**：某些关键变量从根本上无法通过传感器直接测量，如电池荷电状态（SOC）、化学反应中间产物浓度、飞行器迎角、电机转子温度等，必须通过可测信号间接估计。
- **传感器噪声与失效**：所有传感器测量值都包含噪声，且传感器本身可能发生漂移、偏移甚至完全失效。需要借助多传感器融合与滤波技术提升测量可靠性。
- **模型不确定性**：即使系统有标称模型，运行过程中参数也会随时间漂移——摩擦系数因磨损变化、电阻因温升改变、气动参数因飞行状态不同而偏离标称值，这些不确定性必须通过在线估计来补偿。

## 状态估计

状态估计处理"状态不可直接测量"的问题。

典型工具包括：

- Luenberger 观测器；
- Kalman 滤波；
- 扩展 Kalman 滤波；
- 无迹 Kalman 滤波；
- 粒子滤波；
- moving horizon estimation。

### 估计器的选择指南

不同的系统和应用场景对估计器的要求不同，选择时需综合考虑系统线性度、噪声特性、计算资源约束和实时性要求：

| 场景 | 推荐方法 | 备注 |
|------|----------|------|
| **线性高斯系统** | Kalman 滤波 | 理论上是最小方差最优估计，工程中最成熟的选择 |
| **轻度非线性** | 扩展 Kalman 滤波（EKF） | 工程标配，通过一阶泰勒展开线性化，实现简单，但在强非线性下可能发散 |
| **强非线性** | 无迹 Kalman 滤波（UKF）或粒子滤波（PF） | UKF 用 Sigma 点传播均值与协方差，精度高于 EKF 且无需计算雅可比；PF 适用于非高斯噪声，但计算量随粒子数线性增长 |
| **确定性系统，需快速收敛** | Luenberger 观测器（极点配置型） | 通过极点配置任意调整收敛速度，适用于无噪声或噪声可忽略的场合 |
| **状态约束需显式处理** | Moving Horizon Estimation（MHE） | 将估计转化为带约束优化问题，能处理输入/状态约束，但计算量大，适用于采样周期较长的场景 |
| **高维非线性/复杂系统** | 神经网络观测器或数据驱动方法 | 近年来发展迅速，适用于模型难以解析描述的系统，但可解释性和泛化性仍需审慎评估 |

简言之：**能用 Kalman 就别用 EKF，能用 EKF 就别用 UKF/粒子滤波，约束关键时考虑 MHE，追求极简快速则用 Luenberger。**

## 系统辨识

系统辨识处理"模型未知或模型不准"的问题。

典型任务包括：

- 参数估计；
- 传递函数辨识；
- 状态空间模型辨识；
- 非线性模型辨识；
- 频域辨识；
- 数据驱动代理模型。

### 辨识的基本流程

系统辨识不是一次性的"黑箱拟合"，而是一套有章可循的工程流程：

**（1）实验设计**：选择输入激励信号的类型和参数。常用信号包括：
- **PRBS（伪随机二进制序列）**：在两个幅值之间随机切换，频谱近似白噪声，能在宽频带内充分激励系统动态，且幅值可控，不会对系统产生过大扰动，是系统辨识中最广泛使用的输入信号。
- **阶跃信号**：简单直观，适合初步获取系统响应特性（稳态增益、时间常数）。
- **正弦扫频（chirp 信号）**：频率随时间连续变化，适合频域辨识。

同时需确定采样频率（遵循 Nyquist 定理，通常取系统最高关注频率的 5-10 倍）和数据长度（至少包含系统主导时间常数的 5-10 倍时长的数据）。

**（2）数据采集与预处理**：
- 去除均值/去趋势：消除直流分量和低频漂移的影响；
- 滤波：滤除高频噪声，防止混叠；
- 去除异常值：剔除传感器尖峰、丢包等异常数据点；
- 数据集划分：划分为辨识数据集和验证数据集。

**（3）模型结构选择**：选择模型阶次和类型：
- 阶次选择：通过 AIC（Akaike Information Criterion）或 BIC（Bayesian Information Criterion）在模型复杂度和拟合精度之间做权衡；
- 模型类型：ARX、ARMAX、OE（输出误差）、Box-Jenkins、状态空间模型等，选择取决于噪声特性与模型用途。

**（4）参数估计**：根据模型结构和辨识准则，选择相应算法：
- **最小二乘法**：最基础、最常用，对 ARX 模型有解析解；
- **极大似然估计**：在已知噪声统计特性时统计最优；
- **子空间方法（如 N4SID、MOESP）**：适用于多变量状态空间模型，无需非线性优化；
- **递推算法（RLS）**：适用于在线/自适应辨识。

**（5）模型验证**：辨识出的模型必须经过严格验证方可投入使用：
- **残差分析**：检验预测残差是否为白噪声（若残差仍有自相关，说明模型未充分捕捉系统动态）；
- **交叉验证**：用独立的验证数据集评估模型预测性能，防止过拟合；
- **频域匹配度**：比较模型与实验数据的 Bode 图或功率谱密度，检查关键频段的匹配程度。

以上流程通常需要多次迭代——验证不通过则返回调整模型结构或重新设计实验，直至模型满足精度要求。

## 估计与控制的耦合

估计不是控制前的独立预处理。

估计误差会进入控制律，并可能被闭环放大。因此控制设计需要考虑：

- 估计收敛速度；
- 噪声敏感性；
- 传感器失效；
- 观测延迟；
- 模型失配；
- 故障检测与隔离。

### 估计误差的闭环效应

估计误差在控制闭环中并非"小扰动"那么简单——它们不会被平均掉，反而可能被控制律显著放大：

- **误差注入控制信号**：如果控制器依赖估计状态的反馈（而非真实状态），则估计误差将直接注入控制信号，形成额外的驱动项。若控制器增益较高，这一注入效应会被放大。
- **收敛速度与噪声灵敏度的权衡**：在观测器设计中，极点配置越远（收敛越快），观测器增益越大，测量噪声也越容易被放大。这是经典的设计权衡——Luenberger 和 Kalman 滤波器都面临这一取舍。
- **确定性等价原理的局限**：LQG（线性二次高斯）控制中的**确定性等价原理**（Certainty Equivalence）指出，当系统为线性且噪声为高斯时，可将估计与控制分离设计：先用 Kalman 滤波得到最优估计，再将其视为真实状态进行反馈控制即可保证整体最优。然而，实际系统往往不完美满足这些假设——模型失配、非线性、非高斯噪声、约束条件等都会导致确定性等价不再成立，此时需要更细致的联合设计（如鲁棒控制、自适应控制、或输出反馈 MPC 中显式考虑估计误差）。

因此，现代控制理论的一条核心共识是：**估计与控制必须统一设计，而非各自为政。**
