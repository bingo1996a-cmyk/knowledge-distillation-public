# 开发计划

## 定位

本页定义控制科学与工程知识库的分阶段开发计划。

开发计划的目标不是让单个智能体一次写完全部内容，而是让多个智能体可以围绕同一架构分工实施。

## 总原则

- 先战略，后细节；
- 先主干，后分支；
- 先边界，后扩写；
- 先概览，后推导；
- 先稳定结构，后美化导航；
- 后续智能体按任务单施工。

## Phase 0：奠基层

### 目标

完成知识库施工所需的总设计。

### 交付物

- 顶层目录骨架；
- 总入口 README；
- 总地图；
- 阅读路径；
- 模块划分范围；
- 边界与写作规则；
- 完全态目录远景；
- 开发计划；
- 智能体任务单模板。

### 当前状态

已基本完成。

### 验收标准

- 后续智能体能根据模块边界判断页面归属；
- 用户能从 README 进入所有战略文档；
- 完全态目录能指导后续扩写；
- 开发计划能拆解出下一批任务。

## Phase 1：模块入口层

### 目标

让每个顶层模块都有自己的入口页和施工范围。

### 任务

- 为 `01-09` 和 `90` 补齐 `README.md`；
- 每个 README 写清：模块定位、已建页面、待建页面、与其他模块关系；
- 更新总地图；
- 更新待办清单。

### 适合派给智能体的任务

- “请为 `02-经典控制` 写模块 README，不扩写具体专题。”
- “请根据完全态规划，为 `05-估计与辨识` 做模块内页面清单。”

### 验收标准

- 每个模块可独立打开；
- 每个模块都能指导后续专题智能体；
- 不出现多个模块争抢同一主题的混乱。

## Phase 2：核心概念主干

### 目标

把控制科学最基础的概念补齐到可读状态。

### 优先页面

- 平衡点与线性化；
- 采样与离散化；
- 可控性与可观性基础；
- 不确定性、扰动与噪声；
- 性能、约束与权衡；
- PID；
- 根轨迹；
- Bode 图；
- Nyquist 判据。

### 写作深度

只要求：

- 概念；
- 为什么重要；
- 基本模型；
- 工程直觉；
- 常见误区；
- 回链。

不要求完整教材推导。

## Phase 3：方法体系主干

### 目标

建立控制方法谱系。

### 优先页面

- LQR；
- LQG 与分离原则；
- 观测器；
- MPC；
- $H_\infty$ 控制；
- 自适应控制；
- 非线性控制概览；
- 控制 Lyapunov 函数；
- 控制屏障函数；
- 分布式控制。

### 验收标准

每页必须回答：

- 解决什么问题；
- 依赖什么假设；
- 与稳定性、约束和鲁棒性有什么关系；
- 工程部署的主要困难是什么。

## Phase 4：估计、辨识与系统工程层

### 目标

补齐控制系统落地所需的模型、状态和部署链路。

### 优先页面

- EKF / UKF；
- 粒子滤波；
- moving horizon estimation；
- 传感器融合；
- 频域辨识；
- 非线性系统辨识；
- 故障检测、隔离与诊断；
- 实时调度；
- 嵌入式控制软件；
- HIL；
- runtime monitor；
- assurance case。

### 验收标准

页面必须把理论对象连接到工程约束：

- 采样；
- 延迟；
- 噪声；
- 硬件限制；
- 故障恢复；
- 日志和验证。

## Phase 5：应用层

### 目标

让控制科学进入真实领域，但保持控制问题表达。

### 优先页面

- 机器人控制；
- 航天飞行与姿态控制；
- 过程控制；
- 电力与能源系统控制；
- 车辆与交通控制；
- 智能制造控制；
- 生物医学控制。

### 应用页验收模板

每个应用页必须包含：

- 被控对象；
- 状态；
- 输入；
- 输出；
- 扰动；
- 约束；
- 控制目标；
- 常用方法；
- 失效模式；
- 验证方式。

## Phase 6：AI 与数据驱动控制层

### 目标

建立 AI 与控制结合的研究入口，同时保持控制学科边界。

### 优先页面

- 学习增强 MPC；
- 神经状态空间模型；
- 强化学习与最优控制；
- 安全强化学习；
- 模仿学习与控制；
- world model for control；
- sim2real 与闭环验证；
- 多智能体学习与协同控制；
- learning-enabled control systems 的验证。

### 强制规则

AI 交叉页必须说明：

- AI 模块位置；
- 闭环影响；
- 稳定性和约束风险；
- 开环指标与闭环指标差异；
- 安全监测和 fallback 机制。

## Phase 7：导航、索引与课程化

### 目标

把知识库从文件集合变成可导航、可教学、可研究的系统。

### 任务

- 建立术语表；
- 建立研究问题地图；
- 建立课程路线；
- 建立论文阅读路线；
- 建立 HTML 导航；
- 建立跨子库链接图。

### 验收标准

- 新读者可以从总地图快速进入；
- 专题研究者可以按问题链路阅读；
- 后续智能体可以自动发现缺口。

## 智能体施工批次建议

### 批次 A：模块 README

目标：补齐所有模块入口，不写细节。

### 批次 B：基础概念

目标：补齐 `01-基础理论` 和 `02-经典控制` 的核心概念。

### 批次 C：现代与高级方法

目标：补齐 `03` 和 `04` 的方法主干。

### 批次 D：估计与工程

目标：补齐 `05` 和 `06`。

### 批次 E：应用与 AI 交叉

目标：补齐 `07` 和 `08`。

### 批次 F：导航与课程化

目标：补齐 `09`、`20-更新日志` 和 `90`。

## 每批任务的通用验收

- 不破坏顶层目录；
- 不重复已有页面；
- 新页有回链；
- 总地图或模块 README 已更新；
- 写作深度符合任务单；
- 没有把应用页写成行业百科；
- 没有把 AI 页写成泛 AI 介绍；
- 没有把高风险应用写成操作化方案。
