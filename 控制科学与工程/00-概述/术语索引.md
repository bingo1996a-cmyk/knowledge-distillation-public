# 控制科学与工程术语表

## 使用说明

本术语表涵盖知识库核心术语。每个条目给出中文名、英文名、简要定义和所在模块。用于快速查找与跨页面导航。

---

## A

- **Assurance Case / 保证案例**：系统化论证系统安全性的结构化框架。 [06]

## B

- **Bandwidth / 带宽**：闭环幅频响应衰减-3dB时的频率。 [02]
- **Bode图 / Bode Plot**：系统频率响应的对数幅频和相频曲线。 [02]
- **Bellman方程 / Bellman Equation**：动态规划的核心递推关系。 [04]

## C

- **CLF / 控制Lyapunov函数**：Lyapunov函数在控制中的推广，用于设计保证稳定性的控制律。 [04]
- **CBF / 控制屏障函数**：将安全集不变性表达为输入不等式约束的方法。 [04]
- **Certainty Equivalence / 确定性等价**：将估计值当作真实状态使用的分离设计原则。 [03, 05]
- **闭环 / Closed-Loop**：控制器输出依赖实时反馈的系统结构。 [01]
- **Controllability / 可控性**：能否通过输入将状态引导到目标的结构性条件。 [01, 03]

## D

- **动态规划 / DP**：多阶段决策的递推求解方法。 [04]
- **Detectability / 可检测**：不可观模式本身稳定的条件。比可观性弱。 [03]

## E

- **EKF / 扩展Kalman滤波**：通过一阶线性化处理非线性的Kalman滤波扩展。 [05]

## F

- **反馈 / Feedback**：输出回送与参考比较产生控制信号的机制。 [01]
- **前馈 / Feedforward**：直接基于参考或扰动测量生成控制输入。 [01]

## G

- **增益裕度 / Gain Margin**：闭环稳定前提下环路增益可容忍的倍数。通常要求大于6dB。 [02]
- **增益调度 / Gain Scheduling**：多工作点预设计控制器、运行时切换的方法。 [04]

## H

- **H-infinity控制**：最小化扰动到输出的无穷范数的鲁棒控制方法。 [04]
- **混杂系统 / Hybrid System**：连续动态与离散跳变共存的系统。 [01]

## I

- **ISS / 输入-状态稳定性**：刻画状态对输入扰动有界响应的Lyapunov推广。 [01]

## K

- **Kalman滤波**：高斯噪声下最优递推状态估计器。预测-更新两步结构。 [05]
- **Kalman对偶性**：LQR与Kalman滤波共享Riccati方程结构。 [03, 05]

## L

- **LQR / 线性二次型调节器**：无限时域线性系统最优控制器，闭式解K=R^{-1}B^T P。 [03]
- **LQG**：线性二次型高斯控制，LQR与Kalman滤波的组合框架。 [03]
- **Laplace变换**：将时域函数映射到复频域的变换，传递函数的数学基础。 [02]
- **Lyapunov方程**：A^T P + P A = -Q，线性系统稳定性分析。 [01]
- **LMI / 线性矩阵不等式**：将控制设计表示为矩阵不等式约束的凸优化方法。 [03, 04]

## M

- **MPC / 模型预测控制**：滚动时域求解约束优化问题的控制方法。 [04]
- **最小实现 / Minimal Realization**：可控可观子系统，Kalman分解的输入输出等价表示。 [01]

## N

- **Nyquist判据**：基于开环Nyquist图包围(-1,0)点圈数的稳定判据。 [02]
- **Neural Lyapunov**：用神经网络参数化并验证Lyapunov函数的方法。 [01, 08]

## O

- **Observability / 可观性**：能否通过输出推断系统内部状态的结构性条件。 [01, 03]
- **观测器 / Observer**：依据模型和IO数据重建状态的动态系统。 [03]
- **开环 / Open-Loop**：控制输入不依赖反馈的系统结构。 [01]

## P

- **PID控制**：比例-积分-微分控制，工业标准反馈律。 [02]
- **相位裕度 / Phase Margin**：穿越频率处相位与-180度的距离。推荐45-60度。 [02]
- **Pontryagin最大值原理**：最优控制必要条件——最优控制使Hamiltonian取极值。 [04]
- **PRBS / 伪随机二进制序列**：辨识最常用激励信号，宽频谱均匀能量。 [05]

## R

- **Riccati方程**：LQR和Kalman滤波共用的核心代数方程。 [03, 05]
- **鲁棒控制 / Robust Control**：不确定性存在时仍保证稳定和性能的控制方法。 [04]
- **根轨迹 / Root Locus**：闭环极点随增益移动的轨迹图。 [02]

## S

- **分离原理 / Separation Principle**：LQG框架中估计器与控制器可独立设计。 [03]
- **Stabilizability / 可镇定**：不可控模式本身稳定。比可控性弱。 [03]
- **状态空间 / State-Space**：一阶微分方程组描述的内部动态模型。 [01]
- **系统辨识 / System Identification**：从数据建立动态系统模型的方法。 [05]
- **Sim2Real**：仿真训练策略后迁移到物理系统的技术。 [08]
- **小增益定理 / Small-Gain Theorem**：互联子系统增益积<1则闭环稳定。 [04]

## T

- **传递函数 / Transfer Function**：系统输出与输入Laplace变换之比。 [02]

## U

- **UKF / 无迹Kalman滤波**：用sigma点传播非线性均值和协方差的估计方法。 [05]

## Z

- **ZOH / 零阶保持器**：离散信号保持为常值到下一采样时刻的接口器件。 [01]
