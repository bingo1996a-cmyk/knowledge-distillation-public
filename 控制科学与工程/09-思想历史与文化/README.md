# 思想史与文化

## 定位

本模块是控制科学与工程知识库的元认知层。它不讲授具体的控制器设计或算法推导，而是追问"控制科学的核心观念如何形成"——反馈、稳定、自动调节、系统、信息和优化这些概念如何在历史中逐步浮现、相互交织并塑造了今天的学科形态。该模块也关注工程文化：为什么控制工程师如此重视稳定裕度？安全文化与激进创新之间的张力如何影响技术路线？

## 核心问题

- 反馈观念是如何从机械调速器发展到今天的广义闭环思想的？
- 控制科学从经典控制（频域）到现代控制（状态空间）的范式转变背后的驱动力是什么？
- 控制论（cybernetics）、系统论、信息论与控制科学之间是什么关系？
- 航天工程、工业过程等重大工程需求如何推动了控制理论的发展？
- 控制工程文化中的保守性、安全裕度和验证伦理是如何形成的？

## 与相邻模块关系

- **前置依赖**：本模块是通识层，阅读不严格依赖前面的技术模块，但若读者已有 01-06 的知识基础，对思想史的理解会更深。
- **后继出口**：本模块为所有其他模块提供观念背景和学科文化语境。各方法模块（如 PID 的起源、状态空间方法的诞生）都可以回链到本模块。
- **毗邻边界**：不做无结构的人物年表和日期堆砌。历史叙述必须服务于理解学科结构。工程文化的讨论需要结合实践，避免空洞的哲学评论。

## 适合读者

- 想理解"控制科学为什么长成今天这样"的师生和研究者。
- 在工科教育中希望补充学科史和方法论视角的学习者。
- 跨学科研究者（系统科学、信息科学、科学史）寻找控制科学思想资源。
- 任何对反馈、自动化和系统思维的文化和哲学维度感兴趣的读者。
