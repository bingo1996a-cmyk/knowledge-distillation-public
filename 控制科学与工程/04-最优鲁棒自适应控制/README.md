# 最优控制、鲁棒控制与自适应控制

## 定位

本模块是控制科学与工程知识库的第四层，位于基础方法（01-03）之上，处理经典反馈和状态反馈无法充分覆盖的复杂控制问题。当系统中同时出现性能指标优化、显式约束、模型不确定性、参数变化和环境扰动时，需要本模块提供的方法论支撑。

本模块向上承接基础理论（01-基础理论）和现代控制（03-现代控制），向外连接估计与辨识（05-估计与辨识）提供模型，同时为 AI 与数据驱动控制（08-AI与数据驱动控制）提供安全和鲁棒性底座。

## 核心问题

- 如何在满足系统动力学和约束的条件下，使某个性能指标达到最优？
- 模型不准确时，如何保证闭环系统仍然稳定且性能可接受？
- 系统参数未知或随时间变化时，控制器能否在线调整自身参数？
- MPC 的滚动优化机制如何与状态估计、系统辨识形成闭环？
- 鲁棒控制和自适应控制的思想如何为安全学习控制提供理论支撑？
