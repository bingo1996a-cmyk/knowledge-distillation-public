# 线性系统理论路线图 (Roadmap of Linear Systems Theory)

## 定位

线性系统理论是现代控制模块（03）的理论脊梁。从状态空间模型到 Lyapunov 稳定性，从可控可观性到 Kalman 滤波，从极点配置到 LQR/LQG——所有这些方法都扎根于同一个数学框架。

本路线图的目标是将现代控制模块中涉及的所有线性系统概念和工具串联成一个连贯的路线图，揭示每个概念和方法的位置、前驱关系以及工程角色。

## 核心主线：四层递进

线性系统理论的全部内容可以概括为一条四层递进的主线：

```
模型 (Modeling) → 分析 (Analysis) → 综合 (Synthesis) → 实现 (Implementation)
```

| 阶段 | 核心问题 | 主要工具 |
|:---|:---|:---|
| 第一层：系统表示 | 如何描述一个线性系统？ | 状态空间 $(A,B,C,D)$，传递函数 $G(s)$ |
| 第二层：结构分析 | 系统有什么内在性质？ | 可控性、可观性、稳定性 |
| 第三层：综合设计 | 如何设计控制器？ | 极点配置、LQR、观测器、Kalman 滤波、LQG |
| 第四层：实现问题 | 如何在计算机上实现？ | 离散化、采样效应、数值算法 |

### 第一层：系统表示

**状态空间模型**（时域，1960s, Kalman）：

$$
\dot{x} = A x + B u,\quad y = C x + D u
$$

**传递函数模型**（频域，经典方法）：

$$
G(s) = C(sI - A)^{-1}B + D
$$

**两者的关系**：
- 传递函数是外部描述（输入-输出行为），状态空间是内部描述（状态变量动态）；
- 一个传递函数对应无穷多种状态空间实现（通过相似变换 $T$）；
- **最小实现（Minimal Realization）**：可控且可观的实现，其阶数等于 McMillan 度。

### 第二层：结构性质

**可控性**：系统 $(A, B)$ 可控 $\iff$ $\operatorname{rank}([B, AB, A^2B, \ldots, A^{n-1}B]) = n$。

可控 $\iff$ 可以通过状态反馈任意配置闭环极点。不可控模态完全不受控制输入影响——这是系统的固有限制。

**可观性**：系统 $(A, C)$ 可观 $\iff$ $\operatorname{rank}([C^T, A^T C^T, \ldots, (A^T)^{n-1}C^T]^T) = n$。

可观 $\iff$ 可以从输出重构状态。不可观的状态无法从测量中估计。

**对偶性（Duality）**——线性系统理论最深刻的概念之一：

$$
\text{系统 }(A, B, C) \text{ 可控 } \iff \text{系统 }(A^T, C^T, B^T) \text{ 可观}
$$

这意味着极点配置与观测器设计可以共享同一套求解代码。

**稳定性**：
- 连续系统渐近稳定 $\iff$ $\operatorname{Re}(\lambda_i(A)) < 0$
- 离散系统渐近稳定 $\iff$ $|\lambda_i(A_d)| < 1$
- Lyapunov 方程 $A^T P + P A = -Q$ 的正定解存在性验证

### 第三层：设计方法

**极点配置 $\to$ LQR**：
- 极点配置需要指定全部 $n$ 个极点位置，没有考虑控制能量；
- LQR 通过 Q/R 权重隐式确定最优极点位置，同时考虑控制代价；
- ARE 将这两者统一在 Riccati 方程框架内。

**观测器 $\to$ Kalman 滤波**：
- Luenberger 观测器确定性极点配置；
- Kalman 滤波器通过滤波 Riccati 方程给出最小方差估计；
- 对偶：控制 Riccati $\leftrightarrow$ 滤波 Riccati。

**分离原则 $\to$ LQG**：
- 独立设计 LQR 和 Kalman 滤波器，组合成 LQG 控制器；
- 闭环极点 = 控制极点 $\cup$ 观测器极点；
- LTR 恢复鲁棒性。

## 关键概念的内在联系

| 概念 | 连接关系 |
|:---|:---|
| 可控性 $\leftrightarrow$ 极点配置 | 可控性是极点配置可解的充要条件 |
| 可观性 $\leftrightarrow$ 观测器设计 | 可观性是观测器可解的充要条件 |
| 对偶原理 | 控制问题 $\leftrightarrow$ 滤波问题（$A \leftrightarrow A^T$, $B \leftrightarrow C^T$） |
| 分离原则 | 状态反馈 + 观测器 = LQG 控制器 |
| 确定性等价 | 最优控制律 $u^* = -K\hat{x}$ 用估计替代真实状态 |
| Riccati 方程的统一性 | ARE（控制）$\leftrightarrow$ DARE（滤波）完全对称 |

## 工程判断

### 理论假设的工程满足程度

线性时不变（LTI）假设在实际系统中的满足程度：
- 多数系统在小范围工作点附近可近似为 LTI；
- 工况大幅变化时需使用增益调度或 LPV；
- 线性理论为非线性控制提供起点和基准。

### 最有工程影响力的线性理论结果

- **极点配置和 LQR**：工程中应用最广泛（电机驱动、飞行控制、过程控制）；
- **Kalman 滤波**：导航、定位、跟踪领域无处不在（GPS/INS 组合导航）；
- **分离原则**：更多是概念框架，实际系统中不能简单套用；
- **可控性/可观性**：分析和诊断工具，验证系统设计的基本可行性。

### 线性理论的价值边界

- 线性方法不能处理硬约束（需 MPC）；
- 线性方法在强非线性（摩擦、饱和、迟滞）下需配合非线性补偿。
- 线性理论的真正价值在于：提供解析性洞察，这是仿真无法替代的。

## 常见误区

### "学了所有线性方法就能处理任何系统"
实际系统的非线性、不确定性和约束才是真正的困难。线性理论提供的是起点和工具，不是终点。

### "线性时不变假设总是成立"
所有实际系统都有非线性，只是程度不同。不注意线性化适用范围可能导致灾难性后果。

### "控制理论的发展使线性方法过时了"
MPC、非线性控制、学习控制都建立在线性系统理论基础之上。线性方法是控制理论的必修基础。
