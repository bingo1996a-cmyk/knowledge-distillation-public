# 现代控制

## 定位

现代控制以状态空间（state space）为核心语言，强调系统内部状态结构、多变量耦合、可控性（controllability）、可观性（observability）、状态反馈和观测器设计。它将控制问题从"输入输出曲线调节"推进到"系统结构分析与综合设计"。

## 这个模块回答什么核心问题

- 系统是否可控？输入能否驱动系统到达任意状态？
- 系统是否可观？输出是否包含足够信息重建内部状态？
- 如何通过状态反馈（state feedback）配置闭环极点、改变动态响应？
- 当状态不可直接测量时，如何设计观测器（observer）估计状态？
- 分离原则（separation principle）为什么允许将状态估计和状态反馈分开设计？

## 已建页面清单

- **现代控制概览.md**：现代控制概览，介绍关键问题（可控性、可观性、状态反馈、观测器、LQR、LQG）、典型方法和相比经典控制的变化。
- **可控性可观性与状态反馈.md**：可控性与可观性的定义与判据（可控性矩阵、可观性矩阵），状态反馈的极点配置原理，观测器的基本结构和工程判断。

## 与相邻模块的关系

- **前置依赖**：必须先阅读 `01-基础理论` 模块，特别是状态空间系统页面。反馈和稳定性页面也是重要的前置知识。
- **后继出口**：读完现代控制后，可进入 `04-最优鲁棒自适应控制`（最优/鲁棒/自适应控制），或进入 `05-估计与辨识`（估计与辨识）深入了解状态估计和滤波技术。
- **毗邻关系**：与 `02-经典控制` 的划分逻辑：经典控制偏输入输出和频域，适合 SISO 系统和工程直觉；现代控制偏状态和矩阵结构，适合 MIMO 系统和理论综合。与 `04-最优鲁棒自适应控制` 的边界：LQR 基础可放在本模块，约束型滚动优化（MPC）和鲁棒保证归入 04。

## 适合的读者

- 已掌握经典控制、希望学习状态空间方法的本科生或研究生。
- 从事航天航空、机器人、过程控制等需要处理多变量和状态估计的工程师。
- 来自应用数学或强化学习背景、希望理解系统结构和可控可观性限制的研究者。
