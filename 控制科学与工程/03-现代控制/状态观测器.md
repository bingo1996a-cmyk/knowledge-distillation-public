# 状态观测器 (State Observer / State Estimator)

## 定位

状态反馈控制律 $u = -Kx$ 假设所有状态 $x$ 可直接测量——但工程现实中这一假设几乎从不成立。受限于传感器成本、安装空间和物理可达性，多数系统的状态只能通过有限的输出 $y$ 间接推断。

状态观测器（state observer）利用系统模型和可测输入输出数据，在数字计算机中实时重构系统的内部状态。如果说状态反馈是理论设计的核心，那么观测器就是工程可行的关键桥梁——没有观测器，状态空间方法将停留在纸面。

Luenberger 观测器（1964）是确定性框架下的标准构造，Kalman 滤波器是其随机性扩展。本专题聚焦 Luenberger 观测器。

## 核心问题

**问题一：如何利用可测输入 $u$ 和输出 $y$ 来估计不可测的状态 $x$？**

基本思路是构造一个与真实系统平行的"模拟系统"，用模型预测状态演化，并用输出误差 $(y - \hat{y})$ 做反馈修正。观测器增益 $L$ 决定修正力度。

**问题二：观测误差能否收敛到零？条件是什么？**

需满足可观性（observability）条件：若 $(A, C)$ 可观，则存在观测器增益 $L$ 使 $A - LC$ 的特征值可任意配置，观测误差 $e$ 以任意指定的速率收敛到零。

**问题三：分离原理（Separation Principle）**

对于线性时不变系统，状态反馈控制器与观测器可独立设计——先设计状态反馈增益 $K$，再设计观测器增益 $L$，两者组合后的闭环系统极点 = 状态反馈极点 $\cup$ 观测器极点。

## 基本模型

考虑 LTI 系统：

$$
\dot{x} = A x + B u,\qquad y = C x
$$

Luenberger 观测器（全阶观测器）的构造为：

$$
\dot{\hat{x}} = A \hat{x} + B u + L (y - C \hat{x})
$$

其中 $L \in \mathbb{R}^{n \times p}$ 为观测器增益矩阵。定义观测误差 $e = x - \hat{x}$，其动态为：

$$
\dot{e} = (A - LC)e
$$

若 $A - LC$ 的所有特征值具有负实部，则 $\hat{x}(t) \to x(t)$ 以指数速率收敛。

观测器极点配置与状态反馈极点配置呈对偶关系：
- 状态反馈可控性条件：$(A, B)$ 可控
- 观测器可观性条件：$(A, C)$ 可观
- **对偶原理**：$(A, B)$ 可控 $\iff$ $(A^T, B^T)$ 可观

## 降阶观测器 (Reduced-Order Observer)

当部分状态可以直接测量时，降阶观测器只估计不可测量的 $n-p$ 个状态分量。设计思路：将状态分为可测部分 $x_1 = y$ 和不可测部分 $x_2$，利用 $x_1$ 的测量值直接构造 $x_2$ 的观测器。

降阶观测器的收敛速度通常比全阶观测器更快，但对测量噪声更敏感。实践中全阶观测器（含 Kalman 滤波器）因其结构统一、实现简便而被更广泛采用。

## 关键概念

### 观测器极点配置与对偶性

 | 控制器问题 | 观测器问题 |
 |:---|:---|
 | $\dot{x} = Ax + Bu$ | $\dot{x} = A^T x + C^T u$ |
 | 反馈增益 $K$ | 对偶增益 $L^T$ |
 | 闭环矩阵 $A - BK$ | 误差矩阵 $A - LC$ |
 | 可控性：$(A, B)$ | 可观性：$(A, C)$ |

### 观测误差收敛速度与噪声灵敏度

观测器极点的位置决定了两个关键性能：
1. **收敛速度**：极点距虚轴越远，误差收敛越快；
2. **噪声灵敏度**：$L$ 越大，观测器对测量噪声的增益也越大。

核心权衡：观测器设计本质上是在估计速度和噪声抑制之间做取舍。

### 观测器带宽

观测器带宽 $\omega_{\text{obs}}$ 应大于控制器带宽（通常快 3~10 倍），但过高会放大传感器噪声。数字实现中须远低于采样 Nyquist 频率。

## 工程判断

### 观测器增益的选取原则

- 较小增益：噪声抑制好、数值稳定，但收敛慢；
- 较大增益：收敛快、扰动恢复快，但噪声放大；
- 经验法则：观测器极点应比控制器极点快约 3~5 倍。

### 模型误差对观测器性能的影响

观测器依赖模型 $(A, B, C)$。模型误差会导致有偏估计。鲁棒观测器（如滑模观测器、$H_\infty$ 观测器）可缓解模型依赖性。工程建议：模型越差，观测器越不可靠。

### 非线性与时变系统的扩展

- 扩展状态观测器（ESO）：将总扰动作为扩展状态估计，是自抗扰控制（ADRC）的核心；
- 滑模观测器：对模型不确定性具有内在鲁棒性；
- 高增益观测器：迫使估计误差快速收敛，但噪声放大更严重；
- 扩展 Kalman 滤波（EKF）：局部线性化后应用标准框架。

### Luenberger 观测器 vs. Kalman 滤波器

 | 对比维度 | Luenberger 观测器 | Kalman 滤波器 |
 |:---|:---|:---|
 | 噪声假设 | 确定性 | 随机性（高斯噪声） |
 | 增益设计 | 极点位置指定 | Riccati 方程解 |
 | 最优性 | 无 | 最小方差估计 |
 | 适用场景 | 噪声可忽略 | 传感器噪声明显 |

## 常见误区

### "观测器设计完成后不影响控制器"
分离原理严格成立的条件是线性时不变且无模型不确定性。工程实际中：观测器动态在过渡过程中影响控制器输入，观测器引入的相位滞后可能降低闭环稳定裕度。

### "观测器增益越大越好"
大增益放大传感器高频噪声，经控制器反馈到执行器导致无谓的机械磨损和能耗；大增益使观测器动态变为刚性方程，数字求解需要极小步长。

### "观测器可以完全替代传感器"
观测器只能估计模型已知的动态。传感器失效时，观测器短期内可提供虚拟传感器功能，但长期会因模型误差漂移发散。
