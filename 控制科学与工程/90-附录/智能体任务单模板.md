# 智能体任务单模板

## 用途

本模板用于把控制科学与工程知识库的后续扩写任务派给其他智能体。

任务单应尽量具体，避免让智能体自由发挥导致结构漂移。

## 标准任务单

```text
任务标题：

目标页面：

所属模块：

任务类型：
- 模块 README
- 主干概览页
- 专题页
- 应用页
- AI 交叉页
- 附录/索引页

写作深度：
- 战略总览
- 概念骨架
- 教材式展开
- 研究综述
- 工程验证框架

必须包含：
- 定位
- 核心问题
- 基本模型或结构
- 工程判断
- 常见误区
- 与其他页面连接
- 后续可补

必须回链：
-
-
-

不要做：

-
-

边界规则：
- 遵守 `00-概述/边界与写作规则.md`
- 遵守 `00-概述/模块划分范围.md`

验收标准：
-
-
-
```

## 应用页任务单补充

应用页必须额外要求：

```text
必须写清：
- 被控对象
- 状态
- 输入
- 输出
- 扰动
- 约束
- 控制目标
- 常用方法
- 失效模式
- 验证方式
```

## AI 交叉页任务单补充

AI 交叉页必须额外要求：

```text
必须写清：
- AI 模块进入闭环的位置
- 使用开环指标还是闭环指标
- 是否影响稳定性
- 是否影响约束满足
- 是否需要安全壳或 fallback controller
- 与人工智能科学子库的回链
```

## 模块 README 任务单补充

模块 README 必须额外要求：

```text
必须写清：
- 模块定位
- 已有页面
- 待建页面
- 与上游模块关系
- 与下游模块关系
- 后续施工优先级
```

## 示例任务单

```text
任务标题：
为经典控制模块补写 README

目标页面：
控制科学与工程/02-经典控制/README.md

所属模块：
02-经典控制

任务类型：
模块 README

写作深度：
战略总览

必须包含：
- 模块定位
- 经典控制负责的范围
- 与基础理论、现代控制、高级控制的边界
- 已有页面列表
- 待建页面列表
- 后续优先级

必须回链：
- ../00-概述/模块划分范围.md
- ./经典控制概览.md
- ../01-基础理论/反馈.md

不要做：
- 不写 PID 细节
- 不写 Bode 图推导
- 不新增专题页

验收标准：
- README 可作为后续专题智能体的施工入口
- 与模块边界文档一致
- 链接可读
```
