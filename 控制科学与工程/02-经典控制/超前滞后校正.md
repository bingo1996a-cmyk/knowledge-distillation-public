# 超前滞后校正

## 定位

超前-滞后校正（lead-lag compensation）是经典控制中通过串联校正器（compensator）来改善系统性能的频率域设计方法。校正器的本质是在原系统传递函数中嵌入零极点，以重塑开环 Bode 图的形状，使系统同时满足稳态精度、动态响应和稳定性要求。

## 核心问题

单一增益调节只能在稳定性和性能之间做折中，无法同时满足全部设计指标。超前校正改善动态响应（增大带宽、增加相位裕度），滞后校正改善稳态精度（增大低频增益），超前-滞后校正综合两者的优势。核心问题是：如何通过系统化的 Bode 图整形来满足设计规范？

## 基本模型

### 超前校正

传递函数：$C_{\text{lead}}(s) = \frac{1 + \alpha\tau s}{1 + \tau s}$，$\alpha > 1$。零点 $-\frac{1}{\alpha\tau}$ 在极点 $-\frac{1}{\tau}$ 右侧。

最大超前角出现在 $\omega_m = \frac{1}{\tau\sqrt{\alpha}}$ 处：

$$
\phi_m = \arcsin\frac{\alpha - 1}{\alpha + 1}, \quad \text{幅值提升} = 10\log_{10}\alpha\ \text{dB}
$$

**设计步骤**：确定开环增益 -> 读取未校正 PM -> 计算所需附加超前角 -> 确定 $\alpha$ 和 $\omega_m$ -> 验证校正后 PM。

| 优点 | 缺点 |
|------|------|
| 增加 PM，提高稳定性 | 放大高频噪声 |
| 增大带宽，加快响应 | 需要额外的放大器增益 |

### 滞后校正

传递函数：$C_{\text{lag}}(s) = \frac{1 + \beta\tau s}{1 + \tau s}$，$\beta < 1$。极点在零点右侧。

滞后校正的核心思想是压低高频增益但不改变相位特性。将零极点设置在远离穿越频率的低频段，使校正器在穿越频率附近引入约 $-20\log_{10}\beta$ dB 的衰减。

| 优点 | 缺点 |
|------|------|
| 改善稳态精度（增大低频增益） | 降低穿越频率，减小带宽 |
| 抑制高频噪声 | 响应变慢，上升时间增加 |

### 超前-滞后校正

传递函数：$C_{\text{lead-lag}}(s) = \frac{(1 + \alpha\tau_1 s)(1 + \beta\tau_2 s)}{(1 + \tau_1 s)(1 + \tau_2 s)}$，$\alpha > 1$，$\beta < 1$。

**设计方法**：先设计滞后部分（确定 $\beta$ 和 $\tau_2$）压低中高频增益，再设计超前部分（在穿越频率附近增加 PM），最后验证整体性能。

## 工程判断

- 校正器设计本质是 **Bode 图形状工程**：在哪里提升幅值、在哪里压低、在哪里加相位。
- 超前校正的极限：最大相位超前不超过 $90^\circ$，实际中超过 $60^\circ$ 已不现实，需多级串联。
- 滞后校正不要"打扰"穿越频率附近的相位——极点零点应至少远离 10 倍频程。
- 数字实现时注意离散化误差对零极点位置的偏移。

## 常见误区

1. **过度追求超前角**：单一超前校正能提供的最大相位有限，超过 $60^\circ$ 需多级串联。
2. **滞后校正放在高频处**：若零极点接近穿越频率，会严重降低 PM。
3. **忽略校正器的高频增益**：超前校正放大噪声，需考虑前置滤波器。
4. **只看 PM 不看 GM**：有的设计 PM 足够但 GM 不足，系统仍可能不稳定。
