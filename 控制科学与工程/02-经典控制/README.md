# 经典控制

## 定位

经典控制围绕输入输出关系、传递函数（transfer function）和频域分析展开，是理解单输入单输出（SISO）系统响应速度、超调、稳态误差和稳定裕度的主要工具，也是工程控制直觉的重要来源。

## 这个模块回答什么核心问题

- 传递函数如何描述线性时不变（LTI）系统，极点和零点分别决定什么？
- Bode 图、Nyquist 图和根轨迹（root locus）分别用来解决什么问题？
- PID 控制器为什么是工业中最广泛使用的控制器，如何整定参数？
- 相位裕度（phase margin）和增益裕度（gain margin）如何判断闭环稳定性？
- 超前-滞后校正（lead-lag compensation）如何改善系统响应和抗扰能力？

## 与相邻模块的关系

- **前置依赖**：建议先阅读 `01-基础理论` 模块的反馈、稳定性和动态系统页面，理解闭环的基本概念和稳定性底线。
- **后继出口**：读完经典控制后可进入 `03-现代控制`（现代控制），从输入输出视角切换到状态空间视角，处理多变量问题。也可进入 `04-最优鲁棒自适应控制` 学习更高级的控制方法。
- **毗邻关系**：与 `01-基础理论` 的关系是"概念底座 vs 工程工具"——基础理论定义反馈和稳定性，经典控制则教如何用频域工具分析它们。与 `03-现代控制` 的划分逻辑是：若问题主要依靠传递函数和频域直觉，归入本模块；若需要多变量状态空间综合，归入 `03-现代控制`。

## 适合的读者

- 自动化、电气、机械等专业的本科生或刚接触频域方法的初学者。
- 需要在实际工程中快速判断系统带宽、裕度和校正策略的实践工程师。
- 希望建立频域直觉和调参经验的机器人、过程控制和嵌入式系统从业者。
