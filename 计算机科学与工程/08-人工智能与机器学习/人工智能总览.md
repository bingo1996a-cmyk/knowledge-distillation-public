# 人工智能与机器学习

## 1. 一句话定义

人工智能研究如何让计算系统感知、推理、学习和行动，机器学习作为其核心方法通过数据驱动而非显式编程实现智能行为。

## 2. 核心问题

- 如何从数据中学习模式和规律？
- 如何在不确定环境中做出最优决策？
- 如何构建能理解、生成和交互的智能系统？

## 3. 知识框架

| 子领域 | 核心内容 | 代表性模型/方法 |
|--------|----------|-----------------|
| 机器学习 | 监督学习、无监督学习、模型评估 | SVM、决策树、聚类 |
| 深度学习 | 神经网络、反向传播、表示学习 | CNN、RNN、Transformer |
| 强化学习 | 马尔可夫决策过程、策略梯度、Q 学习 | DQN、PPO、AlphaGo |
| 图机器学习 | 图神经网络、节点嵌入 | GCN、GAT、GraphSAGE |
| 大语言模型 | 预训练、扩展律、指令微调、对齐 | GPT、Claude、LLaMA |
| 智能体系统 | 规划、工具使用、记忆、多智能体 | AutoGPT、多智能体协作 |

## 4. 关键概念

- **监督学习 vs 无监督学习 vs 强化学习**：三种主要学习范式
- **偏差-方差权衡**：模型复杂度与泛化能力的基本矛盾
- **梯度下降与反向传播**：神经网络训练的核心算法
- **注意力机制**：Transformer 的基础，解决长距离依赖问题
- **预训练-微调范式**：大规模预训练 + 特定任务微调，当前主导范式
- **缩放定律（Scaling Law）**：模型性能与计算量、数据量、参数量的关系

## 5. 典型方法和系统

### 5.1 神经网络架构演进

```
感知机 → 多层感知机(MLP) → CNN(图像) / RNN(序列) → LSTM/GRU → Transformer → GPT/LLM
```

### 5.2 强化学习框架

```
智能体(Agent)  →  动作(Action)  →  环境(Environment)
     ↑                                      ↓
  奖励(Reward)  ←  ←  ←  ←  ←  ←  状态(State)
```

## 6. 经典问题

- 过拟合与欠拟合的识别与处理
- 梯度消失与梯度爆炸
- 探索-利用困境（Exploration-Exploitation Tradeoff）
- 灾难性遗忘（Catastrophic Forgetting）
- 幻觉（Hallucination）问题

## 7. 工程实践

- 使用 PyTorch 搭建和训练简单神经网络
- 用 scikit-learn 完成数据预处理、模型训练和评估的完整流程
- 使用预训练模型（如 LLaMA）进行微调
- 构建简易 RAG（检索增强生成）系统
