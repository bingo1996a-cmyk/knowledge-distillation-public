# 图神经网络详解

## 1. 一句话定义

图神经网络（Graph Neural Network, GNN）将深度学习扩展到非欧几里得结构的图数据上，通过消息传递（Message Passing）框架使每个节点聚合邻居信息来学习节点、边和图级别的表示。

## 2. 核心问题

- 卷积如何定义在图结构上（没有固定的网格结构）？
- 消息传递层数增加时信息如何传播（过平滑、邻居爆炸）？
- 如何让 GNN 规模化到工业级的大图（数十亿节点）？

## 3. 知识框架

| 主题 | 核心内容 |
|------|----------|
| 消息传递框架 | AGGREGATE + UPDATE 的迭代范式 |
| 谱域方法 | 图拉普拉斯矩阵、图卷积（GCN）|
| 空域方法 | 邻居采样与聚合（GraphSAGE、GAT）|
| 表达能力 | WL 测试与 GNN 的区分能力 |
| 可扩展性 | 采样策略、分布式 GNN |
| 应用 | 节点分类、链接预测、图分类、分子性质 |

## 4. 关键概念

- **消息传递（Message Passing）**：第 k 层，节点 v 聚合邻居们的表示（AGGREGATE），然后与自己的表示合并更新（UPDATE）——这是所有空域 GNN 的统一定义
- **邻接矩阵归一化**：Â = D^(-1/2)ÃD^(-1/2)（GCN）或 Â = D^(-1)Ã（GraphSAGE mean）——不同的归一化方式带来不同的归纳偏置
- **注意力机制（GAT）**：学习每个邻居的权重——α_ij = softmax(LeakyReLU(a^T [Wh_i || Wh_j]))——让模型自动决定哪些邻居重要
- **WL 测试**：Weisfeiler-Lehman 图同构测试——GIN 证明 GNN 的表达能力上限为 WL 测试
- **过平滑（Over-Smoothing）**：层数增加时所有节点的表示趋于相同——GNN 的有效深度通常只有 2-5 层

## 5. 典型方法

### 5.1 主要 GNN 架构对比

| 模型 | 聚合函数 | 特点 |
|------|----------|------|
| GCN | 对称归一化+求和 | 简单有效，需全图结构 |
| GraphSAGE | 采样+Mean/LSTM/Pool | 归纳式，适合大图 |
| GAT | 注意力加权求和 | 学习邻居重要性 |
| GIN | SUM + MLP | 表达能力最强（=WL）|
| GCNII | 初始残差 + 恒等映射 | 缓解过平滑，可堆深层 |

### 5.2 消息传递的统一公式

```
h_v^(k+1) = UPDATE(h_v^k, AGGREGATE({h_u^k : u ∈ N(v)}))

GCN:    h_v^(k+1) = ReLU(W · MEAN(h_u^k, u ∈ N(v)∪{v}))
GAT:    h_v^(k+1) = Σ α_vu · W · h_u^k   (α 由 Attention 计算)
GIN:    h_v^(k+1) = MLP((1+ε)·h_v^k + Σ_{u∈N(v)} h_u^k)
```

## 6. 经典问题

- 邻居采样不是无偏的——过大（计算开销）vs 过小（噪声）
- 异配图（连接节点不相似）——传统 GNN 退化至 MLP
- 图结构变化——如何处理不断有新节点/边加入的动态图
- 大规模图的 GPU 内存限制——mini-batch 采样的图往往不规则
