# 计算机视觉

## 1. 一句话定义

计算机视觉（Computer Vision, CV）研究如何让计算机从图像和视频中理解视觉世界——包括识别物体、检测位置、分割区域和生成新图像。

## 2. 核心问题

- 图像中有哪些物体，在哪里？（分类、检测、分割）
- 如何理解三维场景？（深度估计、3D 重建）
- 如何生成逼真的图像？（图像生成、风格迁移）

## 3. 知识框架

| 任务 | 输入→输出 | 代表性方法 |
|------|-----------|------------|
| 图像分类 | 图像 → 类别标签 | ResNet、ViT、ConvNeXt |
| 目标检测 | 图像 → 边界框 + 类别 | YOLO、Faster R-CNN、DETR |
| 语义分割 | 图像 → 像素级类别 | U-Net、DeepLab、Mask2Former |
| 实例分割 | 图像 → 每个实例的掩码 | Mask R-CNN、SAM |
| 图像生成 | 噪声/文本 → 图像 | GAN、扩散模型、DALL-E |

## 4. 关键概念

- **卷积神经网络（CNN）**：局部感受野 + 权重共享 + 池化——CV 的基础架构（2012-2020 主导）
- **Vision Transformer（ViT）**：将图像切分为 Patch，像处理词一样用 Transformer 处理——正逐渐替代 CNN
- **特征金字塔（FPN）**：多尺度特征融合——检测和分割任务的关键技术
- **数据增强**：翻转、旋转、颜色扰动、CutMix——CV 训练的核心技巧
- **SAM（Segment Anything Model）**：Meta 的通用分割基础模型——Promptable（可通过点击/框/文本提示）

## 5. 典型方法

### 5.1 架构演进

```
AlexNet (2012) → VGG/GoogLeNet (2014) → ResNet (2015)
→ DenseNet/EfficientNet (2017-2019)
→ ViT (2020) → Swin Transformer (2021) → ConvNeXt (2022)
→ 当前: ViT 和 CNN 融合，自监督预训练
```

### 5.2 检测算法两大家族

| 家族 | 思想 | 代表 | 速度 | 精度 |
|------|------|------|------|------|
| 两阶段 | 区域提议 → 分类 | Faster R-CNN | 慢 | 高 |
| 单阶段 | 直接回归边界框和类别 | YOLO、SSD | 快 | 中高 |
| Transformer | 端到端集预测 | DETR | 中 | 高 |

## 6. 经典问题

- 小目标检测——低分辨率目标信息有限
- 遮挡与重叠——部分可见物体的检测和分割
- 领域偏移——训练和测试数据分布不一致
- 计算资源与精度权衡——移动端部署 vs 服务器

## 7. 工程实践

- 用 torchvision 加载预训练模型进行迁移学习
- 用 YOLOv8/Ultralytics 训练自定义目标检测器
- 用 SAM 进行零样本图像分割
- 部署 CV 模型到 ONNX/TensorRT 进行推理优化
