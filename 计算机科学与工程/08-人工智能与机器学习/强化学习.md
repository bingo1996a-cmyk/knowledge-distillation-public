# 强化学习

## 1. 一句话定义

强化学习（Reinforcement Learning, RL）研究智能体如何在与环境的交互中通过试错学习最优策略——在每一步根据当前状态选择动作，以最大化长期累积奖励。

## 2. 核心问题

- 如何在行动后果延迟的情况下分配功劳/过失（信用分配问题）？
- 如何在探索未知和利用已知之间取得平衡？
- 如何从稀疏奖励信号中学习？

## 3. 知识框架

| 方法类别 | 核心思想 | 代表性算法 |
|----------|----------|------------|
| 基于价值 | 学习状态/动作的价值函数 | Q-Learning、DQN |
| 基于策略 | 直接优化策略函数 | REINFORCE、PPO |
| Actor-Critic | 价值+策略结合 | A3C、SAC |
| 基于模型 | 先学环境模型再规划 | AlphaZero、Dreamer |
| 离线 RL | 从固定数据集中学习 | CQL、IQL |

## 4. 关键概念

- **马尔可夫决策过程（MDP）**：RL 的数学框架——(S, A, P, R, γ)：状态、动作、转移概率、奖励、折扣因子
- **价值函数**：V(s)（状态价值）和 Q(s,a)（动作价值）——预测从当前开始能获得的期望累积奖励
- **贝尔曼方程**：V(s) = max_a [R(s,a) + γ Σ P(s'|s,a) V(s')]——价值函数的递归关系
- **探索-利用困境**：Exploration（尝试新动作获取信息） vs Exploitation（选已知最优动作）
- **信用分配**：如何将最终奖励归因到历史上各步的决策

## 5. 典型方法

### 5.1 DQN 的核心创新

```
1. 使用神经网络近似 Q 函数（而非表格）
2. 经验回放（Experience Replay）：存储经验，随机采样打破时间相关性
3. 目标网络（Target Network）：固定目标减少训练不稳定
```

### 5.2 代表性算法对比

| 算法 | 类型 | 关键特点 |
|------|------|----------|
| DQN | 基于价值 | 适合离散动作空间 |
| PPO | 基于策略 | 简单稳定，OpenAI 默认选择 |
| SAC | Actor-Critic | 最大熵框架，样本效率高 |
| AlphaZero | 基于模型 | 蒙特卡洛树搜索 + 自对弈 |

## 6. 经典问题

- 稀疏奖励——如何在没有中间反馈时学习
- 样本效率——现实环境中采集数据成本高
- 泛化——训练环境和部署环境的差异
- 奖励设计——错误的奖励函数导致意外行为
