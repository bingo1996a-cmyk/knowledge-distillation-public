# 机器学习

## 1. 一句话定义

机器学习通过数据而非显式编程让计算机系统改进性能——算法从经验中自动发现模式并做出预测或决策。

## 2. 核心问题

- 如何从数据中泛化出对未见样本有效的规律？
- 如何在欠拟合和过拟合之间找到平衡？
- 如何选择和评估合适的模型？

## 3. 知识框架

| 范式 | 数据形式 | 典型算法 |
|------|----------|----------|
| 监督学习 | 有标签 (X, y) | 线性回归、SVM、决策树、神经网络 |
| 无监督学习 | 无标签 (X) | K-means、PCA、DBSCAN、自编码器 |
| 半监督学习 | 少量标签 + 大量无标签 | 自训练、协同训练 |
| 自监督学习 | 从数据自身构造监督信号 | 对比学习、掩码预测 |

## 4. 关键概念

- **泛化**：在训练数据之外的新样本上表现良好的能力——机器学习的终极目标
- **偏差-方差权衡**：高偏差（欠拟合）→ 加复杂度；高方差（过拟合）→ 正则化
- **交叉验证**：K 折划分，多次训练/验证取平均，更可靠地评估泛化性能
- **正则化**：L1（产生稀疏解）、L2（限制权重幅度）——控制模型复杂度的主要手段
- **特征工程**：将原始数据转化为模型可利用的有效表示——深度学习的出现部分替代了此步骤

## 5. 典型方法

### 5.1 核心算法分类

| 类别 | 算法 | 核心思想 |
|------|------|----------|
| 线性模型 | 线性回归、逻辑回归 | 特征线性组合 |
| 树模型 | 决策树、随机森林、XGBoost | 分而治之 |
| 核方法 | SVM | 最大间隔 + 核技巧 |
| 集成方法 | Bagging、Boosting、Stacking | 多个弱学习器组合 |
| 聚类 | K-means、DBSCAN | 基于距离或密度 |
| 降维 | PCA、t-SNE | 保持结构降维 |

### 5.2 模型评估要点

- 分类：准确率、精确率、召回率、F1、ROC-AUC
- 回归：MSE、MAE、R²
- 不要只看单一指标，需结合业务场景选择

## 6. 经典问题

- 类别不平衡——少数类的召回率极低
- 数据泄露——训练数据中混入了不应在预测时可用的信息
- 特征选择——高维特征中哪些真正有用
- 模型可解释性——复杂模型如何解释决策

## 7. 工程实践

- 用 scikit-learn 完成从数据预处理到模型评估的完整流程
- 构建 feature pipeline（预处理 + 特征工程 + 模型训练）
- 使用 MLflow 或 Weights & Biases 跟踪实验
- 部署模型为简单的 REST API

## 8. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 深度学习 | DL 是 ML 的子集，用深层神经网络做表示学习 |
| 概率论 | 贝叶斯方法、概率图模型是 ML 的重要分支 |
| 大数据系统 | Spark MLlib 用于大规模 ML |
