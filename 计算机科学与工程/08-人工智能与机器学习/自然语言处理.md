# 自然语言处理

## 1. 一句话定义

自然语言处理（Natural Language Processing, NLP）研究如何让计算机理解、生成和处理人类语言，涵盖从文本分类到机器翻译再到对话系统的全谱任务。

## 2. 核心问题

- 如何表示词、句子和文档的语义？
- 如何解决语言的歧义性和复杂性？
- 大语言模型对 NLP 领域意味着什么？

## 3. 知识框架

| 任务类别 | 典型任务 | 代表性方法 |
|----------|----------|------------|
| 词级别 | 分词、词性标注、命名实体识别 | CRF、BiLSTM-CRF |
| 句子级别 | 文本分类、情感分析 | BERT、RoBERTa |
| 序列到序列 | 机器翻译、摘要生成 | Transformer、BART、T5 |
| 语言理解 | 问答、自然语言推理 | BERT、GPT、LLaMA |
| 语言生成 | 文本生成、对话 | GPT 系列、Claude |
| 检索 | 语义搜索、开放域问答 | DPR、RAG |

## 4. 关键概念

- **词嵌入（Word Embedding）**：将词映射为稠密向量——Word2Vec → GloVe → 上下文嵌入（ELMo → BERT）
- **Transformer**：自注意力 + 位置编码——当前所有 SOTA NLP 模型的基础
- **预训练-微调范式**：在大语料上预训练语言模型，在下游任务上微调——BERT 开启的统治范式
- **提示学习（Prompt Learning）**：将下游任务转化为预训练任务的形式——GPT-3 开启了"少样本提示"时代
- **检索增强生成（RAG）**：先检索相关文档，再基于文档生成答案——减少幻觉、增加事实性

## 5. 典型方法

### 5.1 NLP 模型范式演进

```
统计 NLP（n-gram、HMM）
    ↓
神经网络 NLP（RNN/LSTM + 序列到序列）
    ↓
预训练 + 微调（BERT、RoBERTa）
    ↓
大规模预训练 + 少样本（GPT-3、LLaMA）
    ↓
指令对齐 + 人类反馈（ChatGPT、Claude）
```

### 5.2 文本表示方法对比

| 方法 | 上下文感知 | 表示粒度 | 代表 |
|------|------------|----------|------|
| Word2Vec/GloVe | 否 | 词 | 静态嵌入 |
| ELMo | 是 | 词 | 双向 LSTM |
| BERT | 是 | 词/句子 | 双向 Transformer |
| GPT | 是 | 自回归生成 | 单向 Transformer |

## 6. 经典问题

- 词义消歧（WSD）——"bank"是银行还是河岸？
- 指代消解——"他把书放在桌上，然后它掉了"——"它"指什么？
- 长距离依赖——距离很远的词之间的语法/语义关系
- 评估指标——BLEU 和 ROUGE 的局限性

## 7. 工程实践

- 用 HuggingFace Transformers 加载 BERT 做文本分类
- 用 Sentence-Transformers 生成句子向量做语义搜索
- 用 spaCy 进行命名实体识别和依存句法分析
- 构建简单的 RAG 问答系统
