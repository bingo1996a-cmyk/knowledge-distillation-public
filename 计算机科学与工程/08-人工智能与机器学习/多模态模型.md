# 多模态模型

## 1. 一句话定义

多模态模型（Multimodal Model）同时处理和理解文本、图像、音频、视频等多种数据模态，学习跨模态的关联和对齐，实现图文检索、文生图和视觉问答等任务。

## 2. 核心问题

- 如何将不同模态的数据映射到统一的语义空间？
- 如何让模型理解"这张图对应那段文字"？
- 如何生成与文本描述一致的图像或视频？

## 3. 知识框架

| 任务方向 | 输入 → 输出 | 代表性模型 |
|----------|-------------|------------|
| 图文对齐 | （图像,文本）→ 相似度 | CLIP、SigLIP |
| 图像描述 | 图像 → 文本 | BLIP-2、LLaVA |
| 文生图 | 文本 → 图像 | DALL-E、Stable Diffusion、Midjourney |
| 文生视频 | 文本 → 视频 | Sora、Runway Gen-2 |
| 视觉问答 | （图像,问题）→ 答案 | LLaVA、GPT-4V |

## 4. 关键概念

- **对比学习（Contrastive Learning）**：CLIP 的核心——拉近匹配图文对的嵌入，推远不匹配对——在海量图文对上训练
- **扩散模型（Diffusion Model）**：逐步加噪→去噪生成图像——当前最主流的高质量图像生成方法
- **自回归视觉生成**：像生成文本 Token 一样逐 Token 生成图像——DALL-E、Parti 的方法
- **视觉指令微调**：在图像-文本对上用类似指令微调的方式训练——LLaVA 的核心方法
- **世界模型**：从视频中学习物理世界的规律——Sora 展现了对三维空间和物理交互的理解

## 5. 典型方法

### 5.1 CLIP 双塔架构

```
文本: "a photo of a cat" → Text Encoder → 文本嵌入
                                           ↓ 对比损失
图像: [cat image]        → Image Encoder → 图像嵌入
```

### 5.2 扩散模型原理（Stable Diffusion）

```
1. 前向加噪：逐步向图像添加高斯噪声直到变成白噪声
2. 反向去噪：训练 U-Net 预测并去除噪声
3. 文本条件：通过 Cross-Attention 将文本嵌入注入去噪过程
4. 生成：从随机噪声开始，逐步去噪生成图像
```

## 6. 经典问题

- 模态对齐——不同模态的语义表示如何对应
- 幻觉——生成模型可能产生与文本描述不符的图像元素
- 偏见——训练数据中的偏见在不同模态间传递
- 计算资源——训练和推理多模态模型极其昂贵

## 7. 工程实践

- 用 CLIP 实现零样本图像分类和图文检索
- 使用 Stable Diffusion 或 DALL-E API 生成图像
- 用 LLaVA 实现简单的视觉问答
- 理解文本嵌入和图像嵌入在同一语义空间中的分布

## 8. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 计算机视觉 | 图像理解是多模态的基础 |

| 生成模型 | 扩散模型、VQ-VAE 是生成的核心 |
