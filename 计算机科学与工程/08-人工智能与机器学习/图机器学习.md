# 图机器学习

## 1. 一句话定义

图机器学习将机器学习方法扩展到图结构数据上，学习节点、边和图级别的表示，应用于社交网络分析、分子性质预测和推荐系统等场景。

## 2. 核心问题

- 如何在保持图结构的前提下学习节点的表示？
- 如何聚合邻居信息而不损失关键的拓扑特征？
- 如何扩展到百万级节点的大规模图？

## 3. 知识框架

| 方法类别 | 核心思想 | 代表性模型 |
|----------|----------|------------|
| 节点嵌入 | 将节点映射到低维向量 | DeepWalk、Node2Vec |
| 图神经网络（GNN）| 消息传递框架 | GCN、GAT、GraphSAGE |
| 知识图谱嵌入 | 学习实体和关系的表示 | TransE、RotatE |
| 图生成 | 生成具有特定性质的图 | GraphRNN、分子生成 |

## 4. 关键概念

- **消息传递框架**：每个节点从其邻居聚合信息，然后更新自身表示——GNN 的统一范式
- **邻接矩阵 vs 边列表**：图的两种主要表示方式，影响存储和计算效率
- **归纳式 vs 直推式**：GraphSAGE（可泛化到新节点）vs GCN（需全图结构）——工程上重要区分
- **同配性 vs 异配性**：连接节点是否倾向于相似——决定 GNN 是否有效
- **过平滑**：层数加深时所有节点表示趋同——GNN 的深度限制

## 5. 典型方法

### 5.1 GCN 核心公式

```
H^(l+1) = σ( D^(-1/2) Â D^(-1/2) H^(l) W^(l) )

Â = A + I（邻接矩阵加自环）
D  = 度矩阵（归一化）
σ  = 激活函数（ReLU）
```

### 5.2 主流 GNN 对比

| 模型 | 核心机制 | 适用场景 |
|------|----------|----------|
| GCN | 对称归一化邻居聚合 | 节点分类 |
| GAT | 注意力机制加权邻居 | 异构邻居重要度不同 |
| GraphSAGE | 采样 + 多种聚合函数 | 大规模图、归纳学习 |
| GIN | 表达能力接近 WL 测试 | 图分类 |

## 6. 经典问题

- 过平滑——GNN 层数超过 3-4 层后性能下降
- 大规模图的邻居爆炸——采样策略（邻居采样、图分区）
- 异构图的建模——节点和边有多种类型
- 动态图——图结构随时间变化

## 7. 工程实践

- 用 PyG（PyTorch Geometric）或 DGL 搭建 GNN
- 在 Cora/CiteSeer/PubMed 数据集上实现节点分类
- 用 OGB（Open Graph Benchmark）评测不同 GNN 的性能
- 将实际问题（推荐、社交关系预测）建模为图问题
