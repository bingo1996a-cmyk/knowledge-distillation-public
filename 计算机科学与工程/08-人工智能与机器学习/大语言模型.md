# 大语言模型

## 1. 一句话定义

大语言模型（Large Language Model, LLM）是以 Transformer 为基础、在超大规模文本语料上预训练的语言模型，通过扩展模型规模和数据量展现出少样本学习和推理能力。

## 2. 核心问题

- 语言模型的性能如何随模型大小、数据量和计算量变化（Scaling Law）？
- 如何让模型行为与人类意图对齐？
- 巨量参数下的高效训练和推理怎么做？

## 3. 知识框架

| 阶段 | 核心内容 | 关键方法 |
|------|----------|----------|
| 预训练 | 在海量文本上学习语言规律 | 自回归（GPT） 、掩码（BERT） |
| 指令微调 | 让模型理解并遵循指令 | 有监督微调（Supervised Fine-Tuning, SFT） |
| 对齐 | 对齐人类偏好和价值观 | RLHF、DPO |
| 推理优化 | 高效生成和部署 | KV 缓存、量化、投机解码 |
| 评估 | 衡量模型的各项能力 | 基准评测、人类评估 |

## 4. 关键概念

- **自回归语言模型**：逐 Token 预测下一个 Token——P(w_t | w_1, ..., w_{t-1})，GPT 系列的核心范式
- **Transformer 架构**：多头自注意力 + 前馈网络 + 层归一化 + 残差连接
- **缩放定律（Scaling Law）**：模型性能与参数量、训练数据量、计算量呈幂律关系
- **涌现能力（Emergent Abilities）**：当模型规模超过某个阈值时突然出现的新能力（如推理、代码生成）
- **幻觉（Hallucination）**：模型生成看似合理但事实错误的内容——LLM 最棘手的问题之一

## 5. 典型方法

### 5.1 从预训练到部署的完整流程

```
海量文本语料 → 预训练（数月、数千 GPU）
       ↓
基座模型（Base Model）—— 会续写但不懂指令
       ↓
指令微调（SFT）—— 学会遵循指令格式
       ↓
偏好对齐（RLHF/DPO）—— 符合人类期望
       ↓
安全评估（红队测试）→ 部署
       ↓
推理优化（量化、投机解码）→ 在线服务
```

### 5.2 主要开源模型家族

| 模型 | 特点 |
|------|------|
| LLaMA | Meta 开源，生态丰富 |
| Qwen | 通义千问，中文能力强 |
| DeepSeek | 高性价比开放模型 |
| Mistral | 高效架构设计 |

## 6. 经典问题

- 幻觉——如何让模型只输出可靠事实
- 上下文窗口——如何高效处理超长文本（百万 Token 级别）
- 推理能力——模型是否真正会推理还是只是模式匹配
- 评估困难——如何全面、可靠地衡量 LLM 的能力

## 7. 工程实践

- 用 vLLM 或 llama.cpp 部署开源模型（LLaMA/DeepSeek）
- 构建 RAG（检索增强生成）系统：检索器 + 重排序 + LLM 生成
- 使用 PEFT（LoRA/QLoRA）微调大模型
- 设计 Prompt 模板并系统化测试

## 8. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| Transformer/深度学习 | LLM 是 Transformer 的大规模实例 |
| 强化学习 | RLHF 用 RL 做人类偏好对齐 |
| 分布式系统 | 训练和推理依赖大规模分布式计算 |
| 数据库 | RAG 需要向量数据库存储和检索 |
