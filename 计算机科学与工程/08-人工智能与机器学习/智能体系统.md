# 智能体系统

## 1. 一句话定义

AI 智能体（Agent）是能自主感知环境、制定计划、使用工具并执行动作以完成目标的系统，大语言模型的推理能力使其成为新一代智能体的核心引擎。

## 2. 核心问题

- 如何让 AI 自主分解复杂任务为可执行的步骤？
- 如何让 AI 有效使用外部工具（搜索、计算、API）？
- 多个智能体如何协作完成超出单个智能体能力的任务？

## 3. 知识框架

| 能力维度 | 核心内容 | 实现方式 |
|----------|----------|----------|
| 规划 | 任务分解、步骤生成 | 思维链、思维树、ReAct |
| 工具使用 | API 调用、代码执行、搜索 | Function Calling |
| 记忆 | 短期/长期记忆管理 | 向量检索 + 摘要 |
| 反思 | 自我批评和纠错 | Reflexion、Self-Refine |
| 多智能体 | 角色分工、协作通信 | 多角色对话、辩论 |

## 4. 关键概念

- **ReAct 范式**：Reasoning + Acting 交替进行——思考 → 行动 → 观察 → 思考的循环
- **工具调用（Tool/Function Calling）**：模型输出结构化指令调用外部 API，而非只输出文本
- **思维链（Chain-of-Thought, CoT）**：让模型逐步推理而非直接输出答案——显著提升复杂推理性能
- **自主 vs 辅助**：全自主 Agent 自行决策执行 vs 辅助 Agent 在人类监督下执行
- **失败模式**：幻觉、重复循环、偏离目标——Agent 可靠性的核心挑战

## 5. 典型方法

### 5.1 Agent 循环架构

```
观察环境/接收输入
    ↓
感知与理解（解读输入）
    ↓
规划（分解目标，制定步骤）
    ↓
决策（选择下一步动作）
    ↓
执行（调用工具/生成输出）
    ↓
观察结果 → 反馈循环 → 回到感知
```

### 5.2 多智能体协作模式

| 模式 | 描述 | 适用场景 |
|------|------|----------|
| 顺序流水线 | A → B → C 串行处理 | 分阶段任务 |
| 辩论模式 | 多个 Agent 辩论达成共识 | 需要多角度验证 |
| 角色扮演 | 不同 Agent 扮演不同角色 | 模拟复杂场景 |
| 层级协作 | 管理 Agent + 执行 Agent | 复杂项目管理 |

## 6. 经典问题

- Agent 循环中的无限循环和偏离目标
- 工具调用的格式正确性和安全性
- 长时间任务中的上下文溢出
- 多 Agent 系统中的通信效率和信息冗余

## 7. 工程实践

- 用 LangChain 或 AutoGen 搭建简单的 Agent 系统
- 实现带有搜索工具和计算器工具的 ReAct Agent
- 构建 RAG + Agent 结合的智能问答系统
- 使用结构化输出确保工具调用的格式正确
