# 图灵奖成果索引

## 1. 一句话定义

图灵奖（ACM A.M. Turing Award）是计算机科学最高荣誉，历年获奖者的贡献构成了计算机科学发展的主线脉络。

## 2. 核心问题

- 计算机科学的哪些突破获得了最高认可？
- 图灵奖反映了学科演进的什么趋势？

## 3. 按主题梳理的部分获奖成果

### 3.1 编程语言与编译

| 年份 | 获奖者 | 贡献 |
|------|--------|------|
| 1966 | Alan Perlis | 高级编程语言和编译器 |
| 1971 | John McCarthy | Lisp 语言与 AI |
| 1977 | John Backus | Fortran 与形式化语言 |
| 1984 | Niklaus Wirth | Pascal 与结构化编程 |
| 2005 | Peter Naur | ALGOL 60 与 BNF |
| 2006 | Frances Allen | 编译优化 |
| 2018 | Bengio, Hinton, LeCun | 深度学习 |

### 3.2 算法与数据结构

| 年份 | 获奖者 | 贡献 |
|------|--------|------|
| 1974 | Donald Knuth | 算法分析（The Art of Computer Programming）|
| 1986 | Hopcroft & Tarjan | 图算法和数据结构 |
| 2000 | Andrew Yao | 计算复杂性（姚期智）|
| 2002 | Rivest, Shamir, Adleman | RSA 公钥密码 |

| 2009 | Charles Thacker | Alto 与以太网 |

| 2018 | Bengio, Hinton, LeCun | 深度学习 |

### 3.5 数据库

| 年份 | 获奖者 | 贡献 |
|------|--------|------|
| 1973 | Charles Bachman | 数据库管理系统 |
| 1981 | Edgar Codd | 关系数据库模型 |
| 1998 | Jim Gray | 数据库与事务处理 |
| 2014 | Michael Stonebraker | 数据库系统 |

## 4. 趋势观察

1. **早期（1960s-70s）**：编程语言、编译、操作系统等基础工具
2. **中期（1980s-90s）**：算法、数据库、网络、密码学等核心理论
3. **后期（2000s-10s）**：系统设计、分布式、AI 理论突破
4. **近期（2018-至今）**：深度学习（2018）、计算机图形学（2019, 2020）、复杂性理论（2023）、强化学习（2025）
