# 信息论

## 1. 一句话定义

信息论由 Claude Shannon 于 1948 年创立，研究信息的量化、存储和传输，为数据压缩、通信编码和机器学习中的信息度量提供理论基础。

## 2. 核心问题

- 如何量化"信息"和"不确定性"？
- 数据能被压缩到什么程度？
- 在噪声信道中可靠通信的极限速率是多少？

## 3. 知识框架

| 模块 | 核心内容 | 在计算机科学中的典型应用 |
|------|----------|--------------------------|
| 熵 | 信息熵、联合熵、条件熵 | 特征选择（信息增益）、决策树 |
| 互信息 | 相关性度量、信道容量 | 特征工程、表示学习 |
| 信源编码 | 无损压缩、霍夫曼编码、算术编码 | ZIP、PNG、视频编码 |
| 信道编码 | 纠错码、汉明距离、LDPC | 网络传输、存储系统、5G |
| KL 散度 | 相对熵、交叉熵 | 损失函数、变分推断、模型比较 |

## 4. 关键概念

- **信息熵 H(X)**：随机变量不确定性的度量，H(X) = -Σ p(x) log p(x)，单位比特
- **互信息 I(X;Y)**：一个随机变量包含另一个随机变量信息的多少
- **KL 散度 D(P||Q)**：两个概率分布 P 和 Q 的差异度量，非对称
- **交叉熵 H(P,Q) = H(P) + D(P||Q)**：用分布 Q 编码分布 P 需要的平均比特数
- **信道容量**：信道可靠传输的最大信息速率

## 5. 典型机制

### 5.1 霍夫曼编码

```
贪心构建最优前缀码：
1. 将符号按概率排序
2. 每次合并两个最低概率的符号
3. 给合并路径左0右1分配编码
结果：平均码长最短的无损编码方案
```

### 5.2 熵、交叉熵与 KL 散度关系

```
交叉熵(P,Q) = H(P) + D_KL(P||Q)

- H(P)：数据本身的熵（不可压缩的信息）
- D_KL(P||Q)：用模型 Q 近似真实分布 P 的额外信息代价
- 最小化交叉熵 ≡ 最小化 KL 散度
```

## 6. 经典问题

- 数据压缩的理论极限：H ≤ 平均码长 < H + 1
- 香农信道容量公式：C = B log(1 + S/N)
- 最优码的存在性与构造的差异
- 连续随机变量的微分熵
