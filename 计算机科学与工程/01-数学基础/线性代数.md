# 线性代数

## 1. 一句话定义

线性代数研究向量空间和线性变换，核心对象是向量、矩阵和它们之间的线性映射，是计算机图形学、机器学习和科学计算的数学语言。

## 2. 核心问题

- 如何用矩阵和向量表示多维数据？
- 线性变换如何改变空间但不破坏线性结构？
- 如何从矩阵中提取关键结构信息（特征值、奇异值）？

## 3. 知识框架

| 模块 | 核心内容 | 在计算机科学中的典型应用 |
|------|----------|--------------------------|
| 向量与空间 | 向量、线性组合、基、维数 | 数据表示、词嵌入 |
| 矩阵运算 | 乘法、逆、转置、迹、行列式 | 线性回归、图像变换 |
| 线性方程组 | 高斯消元、LU 分解、条件数 | 数值计算、优化 |
| 特征值与特征向量 | 特征分解、特征空间、对角化 | PCA、谱聚类、PageRank |
| 奇异值分解（SVD） | 左右奇异向量、奇异值 | 降维、推荐系统、压缩 |

## 4. 关键概念

- **向量空间**：满足加法和标量乘法封闭性的集合，是线性代数的基本舞台
- **线性变换**：保持向量加法和标量乘法结构的映射，可表示为矩阵
- **特征值**：线性变换在某方向上的缩放因子；特征向量是不改变方向的特殊向量
- **内积**：定义向量之间的角度和长度，是正交性和投影的基础
- **矩阵分解**：将矩阵分解为具有特定结构因子的乘积（LU、QR、EVD、SVD）

## 5. 典型机制

### 5.1 主成分分析（PCA）步骤

1. 数据中心化（减去均值）
2. 计算协方差矩阵
3. 对协方差矩阵做特征分解
4. 取前 k 个最大特征值对应的特征向量作为主成分
5. 将数据投影到主成分空间

### 5.2 SVD 三矩阵分解

```
A = U Σ V^T

U:  左奇异向量矩阵（列空间的正交基）
Σ:  奇异值对角矩阵（非负，递减排列）
V^T: 右奇异向量矩阵的转置（行空间的正交基）
```

## 6. 经典问题

- 线性方程组的数值稳定性（条件数问题）
- 高维数据的维数灾难
- 稀疏矩阵的高效存储与运算
- 特征值计算算法（幂迭代、QR 算法）

## 7. 工程实践

- 使用 NumPy 进行矩阵运算和线性方程组求解
- 实现 PCA 对高维数据进行降维可视化
- 用 SVD 做图像压缩实验
- 将实际问题建模为线性系统并求解
