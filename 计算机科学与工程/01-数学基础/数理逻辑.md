# 数理逻辑

## 1. 一句话定义

数理逻辑用形式化语言和严格推理规则研究命题的真假、证明的有效性和系统的可判定性，是程序验证和自动推理的理论基础。

## 2. 核心问题

- 如何形式化地表达"如果...那么..."、"所有"、"存在"等逻辑关系？
- 如何机械地判定一个命题是否为真？
- 形式化证明的边界在哪里？

## 3. 知识框架

| 模块 | 核心内容 | 在计算机科学中的典型应用 |
|------|----------|--------------------------|
| 命题逻辑 | 命题变量、逻辑连接词、真值表 | 布尔电路、条件判断 |
| 谓词逻辑 | 量词、谓词、一阶语言 | 数据库查询（关系演算）、AI 知识表示 |
| 证明系统 | 自然演绎、希尔伯特系统、序列演算 | 交互式定理证明 |
| 可满足性（SAT） | CNF、DPLL、CDCL 算法 | 硬件验证、调度、密码分析 |
| 高阶逻辑 | 类型论、λ 演算 | 程序语言形式语义、Coq/Lean |

## 4. 关键概念

- **命题逻辑**：研究由连接词（与、或、非、蕴含）组合的命题之间的推理关系
- **谓词逻辑（一阶逻辑）**：在命题逻辑基础上引入量词（∀、∃）和谓词，表达能力大幅增强
- **可满足性（Satisfiability）**：存在一组变量赋值使公式为真
- **可靠性（Soundness）**：可证明的命题一定是真的
- **完备性（Completeness）**：真命题一定可以被证明
- **哥德尔不完备定理**：任何包含算术的一致形式系统，存在不可判定命题

## 5. 典型机制

### 5.1 SAT 求解器核心思想

```
DPLL 算法：
1. 单位传播：如果某个子句只剩一个未赋值文字，强制赋值使其为真
2. 纯文字消除：如果某变量在所有子句中极性相同，赋对应值
3. 分支：选择一个未赋值变量，尝试真/假两个分支递归求解
4. 冲突分析与回跳：CDCL 算法通过冲突分析学习新子句并智能回溯
```

### 5.2 逻辑层级关系

```
命题逻辑 ⊂ 谓词逻辑（一阶）⊂ 高阶逻辑
   ↓           ↓              ↓
  可判定     半可判定       不可判定（一般情况）
```

## 6. 经典问题

- 一阶逻辑的不可判定性（Church-Turing）

- 罗素悖论与类型论

## 7. 工程实践

- 用 SAT 求解器（如 Z3 的 SAT 模式）解决约束满足问题
- 使用 SMT 求解器（如 Z3）验证程序的不变量
- 用 Prolog 体验逻辑编程范式
- 理解硬件描述语言中逻辑综合的基本原理
