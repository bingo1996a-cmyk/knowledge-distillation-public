# 算法博弈论

## 1. 一句话定义

算法博弈论（Algorithmic Game Theory）将博弈论与算法设计融合，研究自利参与者在策略性环境中的行为，以及如何设计规则使自利行为产生全局最优结果——是互联网经济（广告、拍卖、定价）的理论基础。

## 2. 核心问题

- 当参与者是理性的且自利时，系统会达到什么状态？
- 如何设计规则（机制）使参与者即使追求私利也能实现系统最优？
- 如何高效地计算博弈的均衡？

## 3. 知识框架

| 主题 | 核心内容 | 关键概念 |
|------|----------|----------|
| 非合作博弈 | 纳什均衡、混合策略 | 囚徒困境、协调博弈 |
| 机制设计 | 逆博弈论——先定规则再分析行为 | VCG 拍卖、匹配市场 |
| 社会选择 | 从个体偏好到群体决策 | 阿罗不可能定理 |
| 均衡计算 | 寻找博弈均衡的算法 | PPAD-完全性 |
| 在线博弈 | 与对手重复博弈 | 后悔最小化 |

## 4. 关键概念

- **纳什均衡（Nash Equilibrium）**：每个参与者单方面改变策略都不能改善自己的收益——预测自利行为的核心解概念
- **价格锚定（Price of Anarchy）**：纳什均衡下的社会成本 ÷ 最优社会成本——自利行为导致系统效率损失的量化指标
- **VCG 机制**：Vickrey-Clarke-Groves——使每个参与者如实报价是最优策略的拍卖机制——Google AdWords 的理论基础
- **稳定匹配**：Gale-Shapley 算法——双方偏好下不存在"私奔对"的匹配——NRMP 住院医匹配的实际使用算法
- **后悔最小化**：外部后悔 ≤ O(√(T log n))——无论环境如何，平均收益接近事后最优固定策略

## 5. 典型方法

### 5.1 经典博弈矩阵

```
囚徒困境：
        合作      背叛
合作   (-1,-1)   (-3, 0)
背叛   ( 0,-3)   (-2,-2)

纳什均衡：(背叛, 背叛) —— 尽管 (合作, 合作) 更好
```

### 5.2 机制设计原理

```
目标：设计规则使得自利行为产生理想的社会结果

关键原则：
1. 激励相容（Incentive Compatibility）：如实报告真实偏好为最优
2. 个体理性（Individual Rationality）：参与收益 ≥ 不参与
3. 预算平衡（Budget Balance）：支付/收入平衡

例子：第二价格拍卖（Vickrey 拍卖）
→ 出价最高者赢得，支付第二高出价
→ 每个参与者的最优策略就是出价 = 真实估值
```

## 6. 经典问题

- 纳什均衡的存在性——每个有限博弈都有混合策略纳斯均衡
- 纳什均衡的计算复杂性——PPAD-完全，可能很难找到
- 阿罗不可能定理——没有投票系统能同时满足所有合理条件
- 重复博弈的民间定理（Folk Theorem）
