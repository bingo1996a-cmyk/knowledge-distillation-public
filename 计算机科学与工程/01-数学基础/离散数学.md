# 数学基础

## 1. 一句话定义

数学基础是计算机科学的理论基石，涵盖离散数学、线性代数、概率论、数理逻辑和信息论五大支柱。

## 2. 核心问题

- 如何用数学语言精确描述计算对象和过程？
- 什么数学工具支撑算法分析、系统设计和机器学习？
- 不同数学分支在计算机科学中分别扮演什么角色？

## 3. 知识框架

| 分支 | 核心内容 | 在计算机科学中的主要应用 |
|------|----------|--------------------------|
| 离散数学 | 集合、关系、函数、图论、组合 | 算法设计、数据结构、网络分析 |
| 线性代数 | 向量、矩阵、线性变换、特征值 | 图形学、机器学习、优化 |
| 概率论与随机过程 | 概率空间、分布、随机过程 | 算法分析、机器学习、网络建模 |
| 数理逻辑 | 命题逻辑、谓词逻辑、证明系统 | 形式验证、程序分析、AI 推理 |
| 信息论 | 熵、互信息、编码理论 | 数据压缩、通信、机器学习 |

## 4. 关键概念

- **集合与关系**：组织对象的基础语言，贯穿计算机科学全部领域
- **图与树**：表达网络、层次、依赖关系的最通用结构
- **向量与矩阵**：数据表示和多维计算的基本工具
- **概率分布**：描述不确定性和随机性的核心语言
- **逻辑系统**：精确推理和形式化验证的基础

## 5. 典型应用

- 离散数学 → 数据库关系代数、编译器语法分析
- 线性代数 → 3D 图形变换、PCA 降维、神经网络前向传播
- 概率论 → 贝叶斯推断、随机算法分析、马尔可夫链蒙特卡洛（Markov Chain Monte Carlo, MCMC）
- 数理逻辑 → 模型检验、SAT 求解、程序验证
- 信息论 → 数据压缩算法、信道编码、KL 散度

## 6. 经典问题

- 图的连通性与最短路径
- 特征值与特征向量的计算稳定性
- 概率推理的贝叶斯框架 vs 频率学派框架
- 命题逻辑的可满足性问题（SAT）

## 7. 工程实践

- 使用 NumPy/SciPy 进行线性代数计算和矩阵运算
- 通过实际编码实现图遍历算法（BFS/DFS）理解离散结构
- 用概率模型分析和优化系统性能（如缓存命中率、负载均衡）

## 8. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 计算理论 | 数学基础是计算理论的形式化工具 |
| 算法与数据结构 | 算法分析依赖离散数学和概率论 |
| 人工智能与机器学习 | 线性代数和概率论是 ML 的核心数学语言 |
| 密码学 | 数论和代数结构是密码学的数学基础 |
| 计算机图形学 | 线性代数和几何变换是图形学的基础 |
