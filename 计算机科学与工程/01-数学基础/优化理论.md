# 优化理论

## 1. 一句话定义

优化理论（Optimization）研究在约束条件下找到目标函数最优解的方法，是机器学习训练、资源调度和工程设计背后的核心数学框架。

## 2. 核心问题

- 如何判断一个解是最优的？
- 凸问题为什么比非凸容易？
- 如何将现实问题建模为优化问题？

## 3. 知识框架

| 子领域 | 核心内容 | 代表性方法 |
|--------|----------|------------|
| 线性规划（LP）| 线性目标 + 线性约束 | 单纯形法、内点法 |
| 凸优化 | 凸目标 + 凸约束 | 梯度下降、牛顿法、对偶方法 |
| 整数规划 | 变量取整数 | 分支定界、割平面 |
| 非线性规划 | 一般非线性问题 | 拉格朗日乘子、KKT 条件 |
| 随机优化 | 含随机性 | SGD、Adam |

## 4. 关键概念

- **凸集与凸函数**：凸集（任意两点连线在集内）+ 凸函数（函数值在线段下方）——凸性是可全局优化的充分条件
- **对偶性**：原问题 → 对偶问题，弱对偶（对偶最优 ≤ 原最优），强对偶（相等，凸+约束规格下成立）
- **KKT 条件**：Karush-Kuhn-Tucker 条件——约束优化的必要条件，凸问题是充要条件
- **梯度下降**：w ← w - η∇f(w)，一阶方法——机器学习的核心训练算法
- **拉格朗日乘子**：将约束优化转化为无约束优化的经典方法——L(λ) = f(x) + λg(x)

## 5. 典型方法

### 5.1 梯度下降变体

| 方法 | 特点 | 适用 |
|------|------|------|
| SGD | 单样本/小批量更新，有噪声 | 大规模 ML 训练 |
| Momentum | 累积历史梯度，加速收敛 | 深度网络训练 |
| Adam | 自适应学习率 + 动量 | 深度学习默认选择 |
| Newton | 二阶方法，拟牛顿近似（BFGS）| 小规模精确优化 |

### 5.2 凸 vs 非凸

| 性质 | 凸优化 | 非凸优化 |
|------|--------|----------|
| 局部最优 | = 全局最优 | ≠ 全局最优 |
| 求解难度 | 多项式时间可解 | NP-困难（一般情况）|
| 代表应用 | SVM、线性回归 | 深度神经网络训练 |
| 保证 | 理论上可找到全局最优 | 实践中靠经验+调参 |

## 6. 经典问题

- 为什么深度学习训练能用 SGD 成功尽管目标函数非凸——有研究认为在高维空间鞍点多于局部极小
- 线性规划的内点法 vs 单纯形法——理论上内点法多项式时间，实践中单纯形法经常更快
- 对偶间隙——原问题和对偶问题的最优值之差

## 8. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 机器学习 | SGD/Adam 是训练神经网络的核心优化器 |
| 运筹学 | 线性规划、整数规划是运筹学的基础 |
| 控制理论 | LQR 和 MPC 依赖数值优化求解 |
| 经济学 | 博弈论中的均衡问题是不动点优化 |
