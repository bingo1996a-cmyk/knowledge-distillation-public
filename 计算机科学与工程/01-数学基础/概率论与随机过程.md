# 概率论与随机过程

## 1. 一句话定义

概率论研究随机现象的数学建模，随机过程研究随时间演化的随机系统，二者是机器学习、算法分析和系统建模的核心数学工具。

## 2. 核心问题

- 如何用数学语言描述不确定性？
- 如何从观测数据推断未知参数？
- 随机系统如何随时间演化？

## 3. 知识框架

| 模块 | 核心内容 | 在计算机科学中的典型应用 |
|------|----------|--------------------------|
| 概率基础 | 概率空间、条件概率、独立性、贝叶斯定理 | 朴素贝叶斯分类、垃圾邮件过滤 |
| 随机变量 | 离散/连续分布、期望、方差、矩 | 算法随机性分析、负载建模 |
| 极限定理 | 大数定律、中心极限定理 | 蒙特卡洛方法、A/B 测试 |
| 马尔可夫链 | 转移矩阵、平稳分布、吸收态 | PageRank、MCMC 采样 |
| 随机过程 | 泊松过程、布朗运动、鞅 | 排队论、网络流量建模 |

## 4. 关键概念

- **条件概率与贝叶斯定理**：P(A|B) = P(B|A)P(A)/P(B)，更新信念的数学机制
- **随机变量**：将随机结果映射到数值的函数，分为离散型和连续型
- **期望与方差**：量度"中心位置"和"离散程度"
- **马尔可夫性质**：给定现在，未来与过去无关——简洁而强大的建模假设
- **平稳分布**：马尔可夫链长时间运行的极限分布

## 5. 典型机制

### 5.1 贝叶斯推断框架

```
先验 P(θ) + 似然 P(D|θ) → 后验 P(θ|D) ∝ P(D|θ)P(θ)

先验：观察数据前对参数的信念
似然：给定参数下观察到数据的概率
后验：观察数据后对参数的更新信念
```

### 5.2 马尔可夫链蒙特卡洛（MCMC）

当后验分布难以直接采样时，构造一个以目标分布为平稳分布的马尔可夫链，通过模拟该链获得样本。

## 6. 经典问题

- 蒙提霍尔问题（条件概率直觉陷阱）
- 生日悖论（哈希碰撞概率分析）
- 赌徒破产问题（随机游走的吸收边界）
- 验证码的数学——人机区分的信息论基础

## 7. 工程实践

- 使用 `scipy.stats` 拟合分布并进行统计检验
- 实现简单的 MCMC 采样器（如 Metropolis-Hastings）
- 用蒙特卡洛方法估算 π 值
- 分析实际系统的请求到达模式（泊松过程拟合）
