# 范畴论入门

## 1. 一句话定义

范畴论（Category Theory）是数学结构的最抽象语言——不关心对象是什么，只关心对象之间的态射（Morphism）如何组合，它为函数式编程、类型论和程序语义提供统一的形式化框架。

## 2. 核心问题

- 如何用最少的原语（对象+态射+组合）统一描述所有数学结构？
- 函子和自然变换如何连接不同的范畴？
- 范畴论对编程语言设计有什么实际影响？

## 3. 知识框架

| 层次 | 核心概念 | 在计算机科学中的对应 |
|------|----------|----------------------|
| 范畴 | 对象 + 态射 + 组合 + 恒等 | 类型 + 函数 + 组合 + id |
| 函子 | 范畴之间的结构保持映射 | 类型构造器 + map（如 List）|
| 自然变换 | 函子之间的态射 | 多态函数（如 flatten）|
| 单子（Monad）| 自函子上的幺半群 | 副作用建模（IO、State）|
| 伴随 | 两个函子之间的特殊关系 | 构造/消除的对偶 |

## 4. 关键概念

- **范畴（Category）**：对象（Objects）的集合 + 态射（Morphisms/Arrows）+ 态射的组合（Composition）满足结合律 + 每个对象有恒等态射
- **函子（Functor）**：范畴之间的映射——将对象映射到对象、态射映射到态射、保持组合和恒等——Haskell 的 `fmap :: (a→b) → f a → f b` 
- **自然变换（Natural Transformation）**：两个函子之间的映射——"在不依赖具体元素的情况下将一个函子变形为另一个"
- **单子（Monad）**：一个函子 M 加上两个自然变换 unit: Id→M 和 join: M∘M→M——Haskell 用单子纯函数式地建模副作用
- **伴随（Adjunction）**：F ⊣ G——两个函子之间的普遍性质，是最深层构成——从 Galois 连接到 Curry-Howard 同构

## 5. 典型机制

### 5.1 编程中的范畴论概念

| 范畴论 | 编程对应 | 实例 |
|--------|----------|------|
| 范畴 | 类型系统 | 以类型为对象，纯函数为态射 |
| 函子 | 可映射的数据结构 | `List.map`、`Option.map` |
| 单子 | 可链式组合的计算 | `flatMap`/`>>=`（IO、异步）|
| 余积（Coproduct）| 和类型 | `Either`/`Result`/`enum` |
| 积（Product）| 积类型 | `tuple`/`struct`/`Pair` |

### 5.2 Curry-Howard-Lambek 对应

```
逻辑     ≈  类型论     ≈  范畴论
命题     ≈  类型       ≈  对象
证明     ≈  程序项     ≈  态射
合取     ≈  积类型     ≈  积
析取     ≈  和类型     ≈  余积
蕴含     ≈  函数类型   ≈  指数对象
```

- 用 Haskell 或 Scala（Cats/ZIO）体验函子-单子编程范式
