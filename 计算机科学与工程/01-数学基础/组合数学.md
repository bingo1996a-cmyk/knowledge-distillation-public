# 组合数学

## 1. 一句话定义

组合数学研究有限离散对象的计数、排列、选择和结构性质，是算法分析、密码学和概率方法的重要基础。

## 2. 核心问题

- 有多少种方式？（计数问题）
- 一定存在某种结构吗？（存在性问题，鸽巢原理、Ramsey 理论）
- 如何系统地生成所有可能？（枚举问题）

## 3. 知识框架

| 主题 | 核心内容 | 在计算机科学中的典型应用 |
|------|----------|--------------------------|
| 基本计数 | 排列、组合、二项式系数 | 概率计算、算法分析 |
| 容斥原理 | 用交集反推并集 | 计数含约束的组合 |
| 生成函数 | 普通型/指数型生成函数 | 递推求解、整数分拆 |
| 递推关系 | 常系数线性递推、分治递推 | 算法复杂度分析 |
| 图论组合 | Ramsey 理论、极值图论 | 网络设计、编码理论 |

## 4. 关键概念

- **排列与组合**：P(n,k) = n!/(n-k)!（有序选取）、C(n,k) = n!/(k!(n-k)!)（无序选取）——计数基础
- **二项式定理**：(1+x)^n 展开系数的组合意义——与二项式系数的多数恒等式连通
- **鸽巢原理（Pigeonhole Principle）**：n+1 个物品放入 n 个盒子，至少一个盒子 ≥ 2 个物品——存在性论证的基本工具
- **生成函数（Generating Function）**：将序列编码为幂级数——将组合操作转化为代数运算
- **递推求解**：迭代法、主定理（Master Theorem）——分析分治算法复杂度的核心工具

## 5. 典型方法

### 5.1 主定理（Master Theorem）

对于递推式 T(n) = aT(n/b) + f(n)：

```
情况 1: 若 f(n) = O(n^{log_b a - ε})  → T(n) = Θ(n^{log_b a})
情况 2: 若 f(n) = Θ(n^{log_b a})      → T(n) = Θ(n^{log_b a} log n)
情况 3: 若 f(n) = Ω(n^{log_b a + ε})  → T(n) = Θ(f(n))
```

### 5.2 常见算法复杂度对照

| 递推式 | 典型算法 | 复杂度 |
|--------|----------|--------|
| T(n) = 2T(n/2) + n | 归并排序 | O(n log n) |
| T(n) = T(n/2) + 1 | 二分搜索 | O(log n) |
| T(n) = 2T(n-1) + 1 | 汉诺塔 | O(2^n) |
| T(n) = T(n-1) + n | 选择排序 | O(n²) |

## 6. 经典问题

- 错排（Derangement）问题——信封问题
- 0/1 背包的计数——两个限制维度下的组合
- 卡塔兰数——有效括号序列、二叉树计数
- 斯特林数——第二类：n 个物品分成 k 个非空集合

## 7. 工程实践

- 用递推关系分析自己编写的递归算法时间复杂度
- 在实际编程中使用组合计数避免暴力枚举
- 用生成函数工具（如 SymPy）验证组合恒等式
- 用主定理快速估算分治算法复杂度

## 8. 与其他主题的关系

| 相关主题 | 关系 |

| 密码学 | 组合设计理论用于密码系统 |
