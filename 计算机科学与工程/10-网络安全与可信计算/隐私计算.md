# 隐私计算

## 1. 一句话定义

隐私计算（Privacy-Preserving Computation）在保护数据隐私的前提下实现数据的计算和分析——"数据可用不可见"，包括安全多方计算、同态加密、差分隐私和联邦学习等技术。

## 2. 核心问题

- 如何在不暴露原始数据的情况下完成联合计算？
- 如何在统计发布中保护个体隐私？
- 隐私保护与计算效率的权衡在哪里？

## 3. 知识框架

| 技术 | 核心思想 | 保护什么 |
|------|----------|----------|
| 安全多方计算（MPC）| 多方共同计算函数不泄露各自输入 | 计算过程中的输入隐私 |
| 同态加密（HE）| 在密文上直接计算，结果解密即正确 | 存储和处理中的数据 |
| 差分隐私（DP）| 注入可控噪声使个体记录不可区分 | 统计发布中的个体信息 |
| 联邦学习（FL）| 数据本地训练，模型参数聚合 | 训练数据的分布隐私 |
| 可信执行环境（TEE）| 硬件级隔离计算 | 运行时数据和代码 |

## 4. 关键概念

- **MPC 协议**：秘密共享（Shamir）、混淆电路（Yao）、不经意传输（OT）是 MPC 的三大基础构件
- **全同态加密（FHE）**：允许在密文上执行任意计算，但开销极大（10⁴-10⁶× 慢于明文）
- **ε-差分隐私**：对于只差一条记录的两个数据集，输出分布的差异不超过 e^ε 倍——ε 越小保护越强
- **横向联邦 vs 纵向联邦**：横向（样本不同特征同）vs 纵向（样本同特征不同）
- **数据最小化**：只收集和处理完成功能所必须的最少数据

## 5. 典型方法

### 5.1 隐私计算技术对比

| 技术 | 计算开销 | 通信开销 | 安全模型 |
|------|----------|----------|----------|
| MPC | 高 | 极高 | 恶意/半诚实 |
| FHE | 极高 | 中等 | 被动 |
| DP | 极低 | 极低 | 信息论 |
| FL | 低 | 中等 | 半诚实 |
| TEE | 极低 | 极低 | 硬件信任 |

### 5.2 联邦学习流程

```
1. 服务器分发初始模型
2. 各客户端本地训练（数据不出本地）
3. 上传模型更新（非原始数据）
4. 服务器聚合更新（FedAvg）
5. 重复 2-4 直到收敛
```

## 6. 经典问题

- 隐私-效用权衡——更强的隐私保护导致更差的分析精度
- FHE 的性能瓶颈——对实时应用来说太慢了
- FL 中的梯度泄露——梯度可能反向推断出训练数据
- 差分隐私的组合性质——多次查询累积隐私预算

## 7. 工程实践

- 用 PySyft 或 TensorFlow Privacy 训练差分隐私模型
- 实现简单的联邦学习（两个客户端 + 一个服务器）
- 使用 SEAL 或 OpenFHE 库进行简单同态加密计算
- 理解 Apple/Google 在用户数据采集中使用的差分隐私方案

## 8. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 密码学 | MPC、FHE 依赖密码原型 |
| 机器学习 | FL 和 DP-SGD 是隐私 ML 的主要范式 |
| 可信计算 | TEE 提供硬件级隐私保护 |
| 数据治理 | 隐私合规（GDPR）推动隐私计算需求 |
