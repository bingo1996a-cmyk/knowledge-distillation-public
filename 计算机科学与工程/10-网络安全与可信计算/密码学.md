# 网络安全与可信计算

## 1. 一句话定义

网络安全与可信计算研究保护信息的机密性、完整性和可用性，以及建立计算系统的信任基础。

## 2. 核心问题

- 如何在不安全信道中安全通信？
- 如何验证身份并控制访问？
- 如何在不暴露数据的前提下完成计算？

## 3. 知识框架

| 子领域 | 核心内容 | 代表性技术 |
|--------|----------|------------|
| 密码学 | 对称加密、公钥加密、哈希、数字签名 | AES、RSA、SHA-256、ECDSA |
| 网络安全 | 协议安全、入侵检测、防火墙 | TLS、VPN、IDS/IPS |
| 系统安全 | 漏洞发现、权限控制、沙箱 | ASLR、DEP、SELinux |
| 隐私计算 | 同态加密、安全多方计算、差分隐私 | MPC、联邦学习 |
| 可信计算 | 硬件可信根、远程证明、TEE | TPM、SGX、TrustZone |

## 4. 关键概念

- **机密性、完整性、可用性（CIA 三元组）**：信息安全的三个核心目标
- **对称加密 vs 公钥加密**：前者加解密同密钥、速度快；后者双密钥、无需共享秘密
- **数字证书与 PKI**：通过证书链建立公钥信任
- **零信任架构**：不信任网络边界，每次访问都验证
- **侧信道攻击**：利用物理实现特征而非算法缺陷获取信息

## 5. 典型机制

### 5.1 TLS 握手简图

```
客户端 → ClientHello → 服务端
客户端 ← ServerHello + 证书 ← 服务端
客户端 → 密钥交换 → 服务端
双方完成密钥协商，后续通信加密
```

### 5.2 哈希函数的安全属性

| 属性 | 说明 |
|------|------|
| 抗原像 | 给定 h，找不到 m 使 H(m)=h |
| 抗第二原像 | 给定 m1，找不到 m2 使 H(m1)=H(m2) |
| 抗碰撞 | 找不到任意 m1≠m2 使 H(m1)=H(m2) |

## 6. 经典问题

- 密钥分发问题——对称加密的前提是双方共享密钥
- 中间人攻击——如何验证通信对方的真实身份
- 缓冲区溢出——最经典的内存安全漏洞
- SQL 注入与 XSS——最经典的 Web 安全漏洞
- 安全与性能的矛盾——加密和验证总是有开销

## 7. 工程实践

- 使用 OpenSSL 生成证书、签名和加密数据
- 用 Wireshark 分析 TLS 握手过程
- 对实际应用进行基本的安全审计（OWASP Top 10）
- 设置安全的 Web 服务器（HTTPS、CSP、HSTS）

| 计算理论 | 密码原语的安全基础依赖计算困难问题 |
| 软件工程 | 安全开发贯穿整个 SDLC |
