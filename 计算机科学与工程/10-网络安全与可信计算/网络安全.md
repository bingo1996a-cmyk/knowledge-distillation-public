# 网络安全

## 1. 一句话定义

网络安全保护网络基础设施和数据在传输、存储和处理过程中的机密性、完整性和可用性，防御从物理层到应用层的各类攻击。

## 2. 核心问题

- 如何在不安全信道上建立安全的端到端通信？
- 如何检测和阻止恶意流量？
- 如何在不影响业务的前提下实现安全防护？

## 3. 知识框架

| 防护层次 | 核心内容 | 代表性技术 |
|----------|----------|------------|
| 通信安全 | 加密传输、身份认证 | TLS、IPsec、SSH |
| 边界防护 | 访问控制、流量过滤 | 防火墙、WAF |
| 入侵检测 | 异常检测、签名匹配 | Snort、Suricata |
| 认证授权 | 身份验证、访问控制 | OAuth 2.0、OIDC、SAML |
| DNS 安全 | 防劫持、防缓存中毒 | DNSSEC、DoH/DoT |

## 4. 关键概念

- **TLS（传输层安全）**：互联网加密通信的基石——HTTPS = HTTP + TLS
- **公钥基础设施（PKI）**：通过证书链建立对公钥的信任，根 CA 是信任锚
- **防火墙**：按规则过滤进出流量——包过滤 → 状态检测 → 应用层防火墙（WAF）
- **VPN（虚拟专用网络）**：在公共网络上建立加密隧道
- **零信任架构**：不信任任何网络边界，每次访问都需认证和授权

## 5. 典型机制

### 5.1 TLS 1.3 握手关键改进

```
TLS 1.2: 2-RTT（客户端↔服务端两次往返）
TLS 1.3: 1-RTT（合并密钥交换和认证）、0-RTT（恢复会话）

去除不安全算法（RSA 密钥交换、RC4、3DES、CBC 模式）
仅保留前向安全算法（ECDHE）
```

### 5.2 常见网络攻击与防御

| 攻击 | 描述 | 防御 |
|------|------|------|
| MITM | 攻击者在通信双方之间窃听/篡改 | TLS + 证书固定 |
| DDoS | 海量请求耗尽服务资源 | CDN、流量清洗、限流 |
| DNS 劫持 | 篡改 DNS 响应导向钓鱼站 | DNSSEC、DoH |
| SQL 注入 | 通过输入注入恶意 SQL | 参数化查询、WAF |
| XSS | 注入恶意脚本到网页 | CSP、输出编码 |

## 6. 经典问题

- 安全与性能的矛盾——加密和验证总是有延迟
- 证书过期导致大面积服务中断
- 网络层安全 vs 应用层安全——分层防护的必要性
- 加密流量的可见性问题——如何在不解密的情况下检测异常

## 7. 工程实践

- 配置 Nginx 的 HTTPS（Let's Encrypt 证书 + HSTS + CSP）
- 使用 `nmap` 扫描服务暴露端口
- 用 Wireshark 分析 TLS 握手和证书链
- 搭建简单的 IDS（如 Snort）检测恶意流量
