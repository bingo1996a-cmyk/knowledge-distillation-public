# 计算机网络与分布式系统

## 1. 一句话定义

计算机网络研究计算机之间的数据通信机制，分布式系统在此基础上研究多台计算机如何协同工作以提供统一的服务。

## 2. 核心问题

- 数据如何在不可靠的物理链路上可靠传输？
- 如何在不同层次抽象网络通信的复杂性？
- 多台计算机如何协同实现一致、可用、可扩展的系统？

## 3. 知识框架

| 子领域 | 核心内容 | 关键协议/系统 |
|--------|----------|---------------|
| 计算机网络 | 分层模型、路由、传输、拥塞控制 | TCP/UDP、IP、BGP |
| TCP/IP 协议族 | 协议设计、报文格式、状态机 | HTTP、DNS、TLS |
| 分布式系统 | 共识、复制、分片、一致性模型 | Raft、Paxos、ZooKeeper |
| 云计算 | 虚拟化、弹性伸缩、云原生 | AWS、容器编排 |
| 边缘计算 | 计算下沉、低延迟、分布式推理 | CDN、边缘 AI |
| 微服务 | 服务拆分、服务发现、可观测性 | gRPC、服务网格 |

## 4. 关键概念

- **分层模型**：OSI 7 层 / TCP/IP 4 层——将网络功能分解为可独立实现的层次
- **端到端原则**：复杂功能应放在网络端点而非中间节点实现
- **共识算法**：在部分节点故障的情况下达成一致——分布式系统的核心挑战
- **CAP 定理**：分布式系统只能在一致性、可用性、分区容忍性中做选择
- **最终一致性**：牺牲强一致性换取高可用性的设计选择

## 5. 典型机制

### 5.1 TCP 拥塞控制

| 阶段 | 行为 |
|------|------|
| 慢启动 | 拥塞窗口指数增长 |
| 拥塞避免 | 拥塞窗口线性增长 |
| 快速重传 | 收到 3 个重复 ACK 立即重传 |
| 快速恢复 | 不回到慢启动，从拥塞避免继续 |

### 5.2 Raft 共识

1. 领导者选举（任一时刻最多一个 Leader）
2. 日志复制（Leader 将日志同步到 Follower）
3. 提交与安全（多数派确认后提交）
