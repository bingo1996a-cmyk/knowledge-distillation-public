# 边缘计算

## 1. 一句话定义

边缘计算将计算和数据存储推向网络边缘（靠近数据源或用户），以减少延迟、节省带宽并支持离线运行。

## 2. 核心问题

- 如何在不依赖远距离云数据中心的情况下快速响应？
- 如何平衡边缘节点的有限算力与计算需求？
- 边缘与云之间如何协同？

## 3. 知识框架

| 层次 | 典型位置 | 延迟 | 典型设备 |
|------|----------|------|----------|
| 云 | 大型数据中心 | >50ms | 云服务器 |
| 边缘云 | 城市级/运营商机房 | 10-50ms | AWS Wavelength |
| 近边缘 | 企业/园区/基站 | 1-10ms | 边缘网关 |
| 远边缘 | 设备侧 | <1ms | 摄像头、传感器 |

## 4. 关键概念

- **计算卸载（Offloading）**：将部分计算从设备卸载到边缘节点，平衡延迟、功耗和算力
- **CDN（内容分发网络）**：最成熟的边缘应用——将静态内容缓存到靠近用户的边缘节点
- **云-边-端协同**：训练在云、推理在边、感知在端的经典三层架构
- **边缘 AI**：在边缘设备上直接运行 ML 推理（如 TensorFlow Lite、ONNX Runtime）

## 5. 典型架构

### 5.1 云-边-端架构

```
云端 ──── 大数据分析 · 模型训练 · 全局调度
  ↕
边缘层 ─── 数据预处理 · 实时推理 · 本地决策
  ↕
端设备 ── 数据采集 · 执行指令 · 轻量推理
```

### 5.2 边缘计算 vs 云计算关键差异

| 维度 | 边缘 | 云 |
|------|------|-----|
| 延迟 | <10ms | >50ms |
| 带宽 | 本地处理，不上传 | 需上传全部数据 |
| 算力 | 有限 | 几乎无限 |
| 隐私 | 数据本地处理 | 需传输到远端 |
| 离线可用 | 是 | 否 |

## 6. 经典问题

- 边缘节点异构性（CPU/内存/算力差异巨大）
- 间歇性连接下的数据同步策略
- 边缘安全——物理可接触设备的安全防护
- 计算任务的动态分割（什么在边缘做、什么在云做）

## 7. 工程实践

- 搭建简单的边缘推理系统（如用 Raspberry Pi + TensorFlow Lite）
- 使用 Cloudflare Workers 体验边缘函数编程
- 配置 CDN 加速静态资源分发
- 通过 MQTT 协议实现设备-边缘-云通信

## 8. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 物联网（IoT）| IoT 是边缘计算的主要驱动场景 |
| 5G 网络 | 低延迟 + 高带宽使边缘计算更可行 |
| 人工智能 | 边缘 AI 推理是边缘计算的核心应用 |
| 云计算 | 边缘是云的延伸，并非替代 |
