# 现代存储技术

## 1. 一句话定义

现代存储技术正在经历从 SATA SSD 到 NVMe、从 TCP 到 RDMA、从 PCIe 到 CXL 的代际升级——存储延迟已从毫秒级进入微秒级，要求整个软件栈重新适配。

## 2. 核心问题

- NVMe 如何在协议层面革了 AHCI/SATA 的命？
- RDMA 如何让数据在网线上实现内存级延迟？
- CXL 如何打破传统总线结构，实现内存和加速器的池化？

## 3. 知识框架

| 技术 | 核心创新 | 延迟量级 | 主要场景 |
|------|----------|----------|----------|
| NVMe | 多队列并行、简化协议栈 | ~50-100μs | 本地高性能 SSD |
| RDMA | 绕过内核、远程直接内存访问 | ~1-5μs | 分布式存储、HPC |
| CXL | 缓存一致性互连、内存池化 | ~100ns（内存）| 内存扩展、加速器 |
| SPDK | 用户态 NVMe 驱动 | ~10-50μs | 存储系统优化 |

## 4. 关键概念

- **NVMe（Non-Volatile Memory Express）**：抛弃 SATA/AHCI 的单一命令队列（最多 32 条命令，需加锁），改用 64K 个独立队列对——每个 CPU 核可独占队列，无锁高并发
- **RDMA（Remote Direct Memory Access）**：网卡直接读写远程机器的内存——绕过远程 CPU 和内核，单边操作（仅一方参与）。两种主要实现：InfiniBand（专用）和 RoCE（融合以太网）
- **CXL（Compute Express Link）**：基于 PCIe 物理层的缓存一致性互连——让 CPU、GPU、内存、加速器在统一的缓存一致性域内共享资源
- **SPDK（Storage Performance Development Kit）**：Intel 开源的用户态存储驱动框架——将 NVMe 驱动移到用户空间，轮询模式替代中断，零拷贝
- **PMem（Persistent Memory）**：字节寻址的非易失内存（Intel Optane，已停产）——介于 DRAM 和 SSD 之间的新层次

## 5. 典型机制

### 5.1 NVMe vs SATA

| 维度 | SATA/AHCI | NVMe |
|------|-----------|------|
| 队列数 | 1（需加锁）| 64K 对 |
| 每队列深度 | 32 | 64K |
| 协议开销 | 高（需经过 HBA 层）| 低（直接 PCIe）|
| 带宽上限 | 6 Gbps (~550MB/s) | 16 GT/s ×4 lanes (~8GB/s) |
| 软件栈 | 内核块层 | 可直接用户态（SPDK）|

### 5.2 存储延迟层级

```
L1 Cache:    ~1ns
DRAM:        ~80ns
PMem:        ~300ns        ← 非易失
NVMe SSD:    ~50-100μs     ← 本地闪存
RoCE RDMA:   ~1-5μs        ← 远程内存
TCP/IP:      ~50-100μs     ← 传统网络
SATA SSD:    ~500μs        ← 老协议
HDD:         ~5-10ms       ← 机械
```

## 6. 经典问题

- 内核存储栈开销——IO 调度、中断、上下文切换消耗数十微秒
- 微秒级存储下的软件栈瓶颈——传统文件系统和块层成为瓶颈
- RDMA 连接的可扩展性限制
- CXL 内存池化的安全和隔离

- 使用 `fio` 基准测试并对比 NVMe vs SATA SSD 的性能差异
