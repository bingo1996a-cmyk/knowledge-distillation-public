# 计算机体系结构

## 1. 一句话定义

计算机体系结构研究处理器、内存和 I/O 系统的设计与组织，决定硬件-软件接口（指令集）和性能、功耗、成本之间的权衡。

## 2. 核心问题

- 如何设计指令集使其高效且可扩展？
- 如何通过流水线、超标量和乱序执行提高指令吞吐量？
- 如何管理存储层次以弥合 CPU 和内存之间的速度鸿沟？

## 3. 知识框架

| 层次 | 核心内容 | 关键概念 |
|------|----------|----------|
| 指令集体系结构（ISA）| 指令格式、寻址模式、寄存器 | RISC vs CISC |
| 流水线 | 指令级并行、冒险与旁路 | 五级流水线 |
| 超标量 | 多发射、乱序执行、寄存器重命名 | Tomasulo 算法 |
| 存储层次 | 缓存、预取、一致性协议 | 局部性原理 |
| 多核与并行 | 多核架构、SIMD、多线程 | 阿姆达尔定律 |
| 领域特定架构 | GPU、TPU、NPU | 数据流、脉动阵列 |

## 4. 关键概念

- **指令集体系结构（ISA）**：软件和硬件之间的契约——定义了指令格式、寄存器、内存模型等程序员可见的接口
- **流水线冒险**：结构冒险（资源冲突）、数据冒险（依赖）、控制冒险（分支）
- **缓存局部性**：时间局部性（刚访问的可能再访问）和空间局部性（附近数据可能被访问）
- **乱序执行**：允许指令在不违反数据依赖的前提下以不同于程序顺序执行
- **缓存一致性**：多核系统中确保各核心缓存中共享数据的一致视图（MESI 协议）

## 5. 典型机制

### 5.1 经典五级流水线

```
取指(IF) → 译码(ID) → 执行(EX) → 访存(MEM) → 写回(WB)
   ↓          ↓         ↓          ↓         ↓
  PC+4     读寄存器    ALU      读/写内存   写寄存器
```

### 5.2 存储层次

| 层次 | 典型大小 | 延迟 |
|------|----------|------|
| 寄存器 | ~1KB | ~1ns |
| L1 缓存 | 32-64KB | ~2ns |
| L2 缓存 | 256-512KB | ~10ns |
| L3 缓存 | 8-32MB | ~30ns |
| 主存 | 8-64GB | ~80ns |
| SSD | 256GB-2TB | ~10-100μs |

## 6. 经典问题

- 分支预测失败带来的流水线冲刷代价
- 缓存抖动（Cache Thrashing）和伪共享（False Sharing）
- 内存墙（Memory Wall）——处理器速度增速远超内存访问速度
- 功耗墙（Power Wall）——登纳德缩放比例定律的终结
- 暗硅（Dark Silicon）——芯片上同时活跃的面积比例下降

## 7. 工程实践

- 使用 `perf stat` 统计 CPU 周期、缓存命中率和分支预测成功率
- 用 `objdump` 反汇编代码观察编译器生成的指令序列
- 设计缓存友好的数据结构（如 SoA vs AoS）
- 理解 Spectre/Meltdown 等微体系结构侧信道攻击的原理
