# 操作系统

## 1. 一句话定义

操作系统（Operating System, OS）是管理计算机硬件资源、为应用程序提供抽象接口、并保障系统安全与公平的核心系统软件。

## 2. 核心问题

- 如何让多个程序安全、公平地共享同一个 CPU？
- 如何为每个进程提供独立、连续的地址空间？
- 如何在性能、公平性、安全性之间做出合理的工程权衡？

## 3. 知识框架

| 子系统 | 核心机制 | 关键抽象 |
|--------|----------|----------|
| 进程管理 | 调度、上下文切换、进程间通信 | 进程、线程 |
| 内存管理 | 虚拟内存、分页、页面置换 | 地址空间 |
| 文件系统 | 文件抽象、目录、日志、缓存 | 文件、目录 |
| 并发控制 | 锁、信号量、管程、RCU | 互斥与同步 |
| 设备管理 | 中断、DMA、设备驱动模型 | 块设备、字符设备 |
| 安全机制 | 权限位、ACL、能力、沙箱 | 用户/内核态 |

## 4. 关键概念

- **虚拟化**：OS 的核心思想——将物理资源（CPU、内存、磁盘）虚拟化为多个逻辑副本，每个进程以为自己独占机器
- **内核态与用户态**：CPU 提供不同特权级，OS 内核运行在高特权级，应用程序运行在低特权级
- **系统调用**：应用程序请求 OS 服务的受控接口，是内核态和用户态之间的门
- **上下文切换**：保存当前进程状态，恢复另一个进程状态——OS 的"换场"操作
- **虚拟内存**：通过页表将虚拟地址映射到物理地址，支持隔离、保护和按需分页

## 5. 典型机制

### 5.1 Linux 进程调度

| 调度类 | 策略 | 适用场景 |
|--------|------|----------|
| CFS（完全公平调度）| 虚拟运行时间最小者优先 | 普通进程 |
| RT（实时调度）| 固定优先级，FIFO/RR | 实时任务 |
| Deadline | 最早截止时间优先（EDF）| 期限驱动的任务 |

### 5.2 页面置换算法

| 算法 | 策略 | 特点 |
|------|------|------|
| OPT | 替换未来最远使用的页 | 理论最优，不可实现 |
| LRU | 替换最近最少使用的页 | 近似 OPT，硬件支持开销大 |
| Clock（近似 LRU）| 环形扫描，访问位置 1，换出 0 | 实际系统常用 |

## 6. 经典问题

- 死锁：四个必要条件及预防/避免/检测/恢复策略
- 优先级反转：低优先线程持锁阻塞高优先线程——优先级继承解决方案
- 抖动（Thrashing）：进程集的工作集超过物理内存时，系统陷入持续的页面换入换出
- 惊群问题（Thundering Herd）：多个等待进程被同一事件唤醒但只有一个能处理

## 7. 工程实践

- 使用 `top` / `htop` / `ps` 观察进程调度和资源占用
- 阅读 `/proc/<pid>/maps` 理解进程的虚拟地址空间布局
- 用 `strace` 追踪系统调用，观察应用程序与内核的交互
- 实现一个简单的 shell 理解进程创建（fork+exec）和管道（pipe）
