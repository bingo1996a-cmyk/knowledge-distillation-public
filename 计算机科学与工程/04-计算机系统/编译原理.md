# 编译原理

## 1. 一句话定义

编译原理研究如何将高级编程语言翻译为机器可执行的目标代码，涵盖词法分析、语法分析、语义分析、中间代码生成、优化和目标代码生成六个阶段。

## 2. 核心问题

- 如何识别和解析编程语言的文本结构？
- 如何将源码转化为语义等价的机器指令？
- 如何在保证正确性的前提下优化代码性能？

## 3. 知识框架

| 阶段 | 输入 → 输出 | 关键技术 |
|------|-------------|----------|
| 词法分析 | 源码字符流 → Token 流 | 正则表达式、有限自动机 |
| 语法分析 | Token 流 → 抽象语法树 | 上下文无关文法、LL/LR 分析 |
| 语义分析 | AST → 标注 AST | 类型检查、作用域分析、符号表 |
| 中间代码生成 | 标注 AST → IR | 三地址码、SSA 形式 |
| 优化 | IR → 优化后 IR | 死代码消除、常量折叠、内联 |
| 目标代码生成 | IR → 目标机器码 | 指令选择、寄存器分配、指令调度 |

## 4. 关键概念

- **前端 vs 后端**：前端（语言相关）→ 中间表示（IR）→ 后端（目标相关），三段式设计的核心优点是可复用——m 种语言 × n 种目标平台只需 m+n 个编译模块
- **静态单赋值（SSA）**：每个变量只被赋值一次——极大简化了数据流分析和优化
- **LL vs LR 分析**：LL 自顶向下（手写递归下降），LR 自底向上（工具生成，如 yacc）
- **寄存器分配**：NP-完全问题，图着色是经典近似方法
- **即时编译（JIT）**：运行时编译，收集运行时信息指导优化

## 5. 典型机制

### 5.1 编译管线（以 LLVM 为例）

```
C/C++ 源码
   ↓ Clang 前端
LLVM IR (.ll)
   ↓ 优化遍（Passes）
优化后 LLVM IR
   ↓ 后端（x86/ARM/RISC-V）
目标机器码
```

### 5.2 主要优化技术分类

| 类别 | 优化技术 | 作用 |
|------|----------|------|
| 局部优化 | 常量折叠、代数化简 | 单基本块内 |
| 循环优化 | 循环不变量外提、强度削弱 | 减少循环开销 |
| 全局优化 | 死代码消除、公共子表达式消除 | 跨基本块 |
| 过程间优化 | 内联、死函数消除 | 跨函数 |

## 6. 经典问题

- 悬空 else 问题（语法歧义）
- 寄存器分配的 NP-完全性
- 指针别名分析（两个指针是否指向同一内存）
- 编译优化中的阶段排序问题

## 7. 工程实践

- 用 flex（词法）和 bison（语法）写一个简单的计算器
- 手写递归下降解析器解析 JSON
- 使用 LLVM 的 opt 工具观察各优化遍对 IR 的影响
- 阅读编译器的调试输出（如 GCC 的 `-fdump-tree-all`）
