# 计算机系统

## 1. 一句话定义

计算机系统研究计算机的硬件组成、系统软件层次以及从源代码到执行的完整过程，是连接硬件和上层应用的桥梁。

## 2. 核心问题

- 计算机硬件如何组织和运作？
- 操作系统如何管理硬件资源并向上提供抽象？
- 高级语言程序如何被翻译成机器指令并执行？

## 3. 知识框架

| 子领域 | 核心内容 | 关键抽象 |
|--------|----------|----------|
| 计算机组成原理 | 数字逻辑、数据通路、控制单元、存储层次 | 冯·诺依曼架构 |
| 计算机体系结构 | 指令集、流水线、超标量、SIMD、多核 | 指令集体系结构（Instruction Set Architecture, ISA） |
| 操作系统 | 进程管理、内存管理、文件系统、并发控制 | 进程、虚拟内存、文件 |
| 编译原理 | 词法/语法分析、中间表示、优化、代码生成 | 编译管线 |
| 嵌入式系统 | 微控制器、实时操作系统、硬件-软件协同 | 中断、外设抽象 |

## 4. 关键概念

- **冯·诺依曼架构**：存储程序概念——指令和数据存在同一内存中
- **指令流水线**：多条指令的不同阶段同时执行以提高吞吐量
- **虚拟内存**：通过地址映射为每个进程提供独立地址空间
- **进程与线程**：进程是资源分配单位，线程是 CPU 调度单位
- **中断与异常**：硬件/软件触发的事件处理机制
- **编译管线**：前端（源码→IR）→ 中端（优化）→ 后端（IR→目标代码）

## 5. 典型机制

### 5.1 存储层次

```
寄存器 > L1 缓存 > L2 缓存 > L3 缓存 > 主存 > 固态硬盘(SSD) > 机械硬盘(HDD)
  ↓         ↓         ↓         ↓        ↓        ↓          ↓
   1ns      2-4ns    10-20ns   30-50ns  50-100ns  10-100μs   1-10ms
```

### 5.2 操作系统四大管理

| 管理对象 | 核心机制 |
|----------|----------|
| 进程 | 调度、同步、通信、死锁处理 |
| 内存 | 分页、分段、虚拟内存、页面置换 |
| 存储 | 文件抽象、目录结构、日志、缓存 |
| 设备 | 中断、DMA、驱动程序模型 |

## 6. 经典问题

- 缓存一致性（Cache Coherence）问题
- 死锁的四个必要条件（互斥、持有并等待、不可抢占、循环等待）
- 优先级反转（Priority Inversion）
- 页面抖动（Thrashing）
- 编译优化中的阶段排序问题

## 7. 工程实践

- 使用 Linux `/proc` 文件系统观察进程、内存和调度行为
- 用 `strace` / `ltrace` 追踪系统调用
- 用 `perf` 分析 CPU 缓存命中率和分支预测表现
- 编写简单编译器的词法分析和语法分析阶段
