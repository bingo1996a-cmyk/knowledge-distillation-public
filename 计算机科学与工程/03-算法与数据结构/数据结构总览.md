# 算法与数据结构

## 1. 一句话定义

算法与数据结构是计算机科学的核心——数据结构决定如何组织存储数据，算法决定如何高效处理数据。

## 2. 核心问题

- 如何选择合适的数据结构来表达问题？
- 如何设计时间/空间复杂度最优的算法？
- 如何在不同约束之间做出权衡？

## 3. 知识框架

| 子主题 | 核心内容 | 代表性算法/结构 |
|--------|----------|-----------------|
| 基础数据结构 | 数组、链表、栈、队列、哈希表 | 哈希冲突解决、动态数组 |
| 树与图结构 | 二叉树、堆、平衡树、图表示 | AVL、红黑树、邻接表 |
| 排序与搜索 | 比较排序、线性排序、二分搜索 | 快速排序、基数排序 |
| 图算法 | 遍历、最短路径、最小生成树、网络流 | Dijkstra、Kruskal、Ford-Fulkerson |
| 动态规划 | 最优子结构、重叠子问题、状态设计 | 背包、最长公共子序列 |
| 高级技术 | 随机化、近似、并行 | 随机快速排序、近似 TSP、并行归并 |

## 4. 关键概念

- **时间复杂度**：算法执行时间随输入规模增长的渐近行为（大 O 记号）
- **空间复杂度**：算法占用的额外存储空间
- **NP-完全性**：判定哪些问题很难找到精确解的理论依据
- **分治 vs 动态规划 vs 贪心**：三种核心算法设计范式
- **最坏情况 vs 平均情况 vs 均摊分析**：不同分析视角

## 5. 典型方法和结构

### 5.1 排序算法对比

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|------|
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) | 否 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | 是 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | 否 |

### 5.2 动态规划要素

1. 定义状态
2. 找到状态转移方程
3. 确定边界条件
4. 选择递推方向（自顶向下或自底向上）

## 6. 经典问题

- 最短路径问题（Dijkstra、Bellman-Ford、Floyd-Warshall）
- 旅行商问题（TSP）的 NP-困难性
- 背包问题的多种变体
- 字符串匹配（KMP、Boyer-Moore）
- 图的连通性问题

## 7. 工程实践

- LeetCode/Codeforces 等平台的算法题目训练
- 在实际项目中分析性能瓶颈，选择合适的算法和数据结构
- 使用 profiling 工具验证算法在实际场景中的表现

## 8. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 计算理论 | 复杂度理论为算法分析提供理论基础 |
| 计算机系统 | 算法实现性能受缓存、指令集和体系结构影响 |
| 人工智能 | ML 训练算法的优化依赖数值优化和近似算法 |
