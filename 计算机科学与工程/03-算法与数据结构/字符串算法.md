# 字符串算法

## 1. 一句话定义

字符串算法研究文本串的高效处理——包括模式匹配、索引构建与压缩，是搜索引擎、生物信息学和编译器的核心底层技术。

## 2. 核心问题

- 如何在大文本中快速找到模式串的所有出现位置？
- 如何构建高效的后缀索引以支持任意子串查询？
- 如何在时间与空间之间取得平衡？

## 3. 知识框架

| 类别 | 核心算法/结构 | 典型应用 |
|------|---------------|----------|
| 精确匹配 | KMP、Boyer-Moore、Rabin-Karp | 文本编辑器搜索、grep |
| 后缀结构 | 后缀数组、后缀树、后缀自动机 | 全文索引、最长重复子串 |
| 前缀结构 | Trie（字典树）| 自动补全、IP 路由 |
| 字符串处理 | 最长公共子串、编辑距离 | diff、拼写检查 |
| 压缩相关 | LZ77/LZ78、Burrows-Wheeler | gzip、bzip2 |

## 4. 关键概念

- **前缀函数（KMP 核心）**：π[i] = 模式串前 i 个字符的最长相等前后缀长度——失配时利用已知信息跳过不必要的比较
- **后缀数组（Suffix Array）**：所有后缀按字典序排列的索引——O(n) 或 O(n log n) 构建，空间远小于后缀树
- **Trie（字典树）**：共享前缀的树形存储——查询时间与字符串长度成正比
- **LCP 数组**：排序后相邻后缀的最长公共前缀长度——后缀数组的强力辅助结构
- **滚动哈希（Rabin-Karp 核心）**：滑动窗口快速更新哈希值——O(n+m) 期望时间匹配

## 5. 典型方法

### 5.1 KMP 算法流程

```
1. 预处理：计算模式串的 π（前缀函数）数组
2. 匹配：扫描文本串
   - 字符匹配 → 双指针前进
   - 字符失配 → 模式串指针跳到 π[j-1]（利用已知匹配信息）
   - 全匹配 → 记录位置，继续搜索
时间复杂度：O(n+m)，n=文本长度，m=模式长度
```

### 5.2 字符串匹配算法对比

| 算法 | 预处理时间 | 匹配时间 | 特点 |
|------|------------|----------|------|
| 暴力 | O(1) | O(nm) | 简单直观 |
| KMP | O(m) | O(n) | 失配不回溯文本指针 |
| Boyer-Moore | O(m) | O(n/m) 最好 | 从右向左，实践极快 |
| Rabin-Karp | O(m) | O(n+m) 期望 | 基于哈希，易扩展到多模式 |

## 6. 经典问题

- 最长公共子串（Longest Common Substring）——后缀数组 + LCP
- 最长回文子串——Manacher 算法 O(n)
- 多模式匹配——Aho-Corasick 自动机
- 编辑距离的最优计算
