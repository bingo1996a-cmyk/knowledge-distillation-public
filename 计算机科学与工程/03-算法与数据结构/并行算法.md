# 并行算法

## 1. 一句话定义

并行算法研究如何利用多个处理器同时执行计算以加速问题求解，关注工作负载划分、同步开销和可扩展性。

## 2. 核心问题

- 如何将问题分解为可独立执行的子任务？
- 如何最小化处理器之间的通信和同步开销？
- 算法能否随处理器数量增加而有效加速？

## 3. 知识框架

| 主题 | 核心内容 | 关键模型 |
|------|----------|----------|
| 并行计算模型 | 抽象机器、复杂度度量 | PRAM、BSP、LogP |
| 并行分治 | 任务分解与合并 | 并行归并排序 |
| 并行前缀和 | 前缀和的并行计算 | Scan 算法 |
| 并行图算法 | BFS、MST 的并行化 | 并行 BFS |
| 并行矩阵运算 | 矩阵乘法的并行化 | Cannon 算法 |
| GPU 并行 | SIMD、线程块、内存层次 | CUDA 编程模型 |

## 4. 关键概念

- **工作量（Work）**：所有处理器执行操作的总和 W(n)——对应单处理器时间
- **跨度（Span/Depth）**：最长关键路径的长度 D(n)——对应无限处理器的最短时间
- **Brent 定理**：用 P 个处理器，时间 T ≤ W/P + D
- **阿姆达尔定律（Amdahl's Law）**：加速比 ≤ 1/(s + (1-s)/P)，s 为串行占比——提示串行部分将限制并行收益
- **Gustafson 定律**：问题规模随处理器数增长时，加速比可接近线性
- **数据竞争（Data Race）**：多个线程同时访问共享变量且至少一个是写——最危险的并行 Bug

## 5. 典型方法

### 5.1 并行归并排序

```
输入：数组 A[0..n-1]，p 个处理器
步骤：
1. 将 A 划分为 p 段，每段由一个处理器串行排序
2. log p 轮归并：
   - 第 i 轮：将 2^i 个有序段归并为 2^(i-1) 段
   - 使用并行归并在归并阶段加速

工作量：O(n log n)  与串行相同
跨度：O(log² n)
```

### 5.2 计算模型对比

| 模型 | 特点 | 适用 |
|------|------|------|
| PRAM | 忽略通信开销，所有处理器共享内存 | 理论分析 |
| BSP | 计算-通信-同步，三阶段 | 分布式计算 |
| CUDA | SIMT 模型，线程网格 | GPU 编程 |

## 6. 经典问题

- 并行编程中的数据竞争检测和避免
- 锁竞争（Lock Contention）的性能影响
- 伪共享（False Sharing）的隐蔽性能损耗
- 负载均衡 vs 通信开销的权衡

## 7. 工程实践

- 用 OpenMP 对 for 循环进行简单并行化
- 用 CUDA 实现向量加法和矩阵乘法
- 使用 Python 的 `multiprocessing` 或 `concurrent.futures` 进行任务并行
- 用 `perf` 分析共享缓存中的伪共享问题

## 8. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 计算机体系结构 | 多核架构、缓存一致性直接影响并行算法性能 |
| 操作系统 | 线程调度和同步原语是并行编程的基础 |
| 分布式系统 | 分布式算法是并行算法在网络环境下的扩展 |
| GPU 架构 | GPU 并行算法需适应 SIMD 和内存层次 |
