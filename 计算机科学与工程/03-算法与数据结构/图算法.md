# 图算法

## 1. 一句话定义

图算法研究在由节点和边构成的图结构上进行遍历、搜索、最短路径、连通性和流计算的算法，是解决网络分析和关系推断问题的核心工具。

## 2. 核心问题

- 如何在图中找到两个节点之间的最短路径？
- 如何确定图的最小连通方式？
- 如何计算网络中的最大流量？

## 3. 知识框架

| 子主题 | 核心问题 | 代表性算法 |
|--------|----------|------------|
| 图遍历 | 如何系统地访问图中所有节点？ | BFS、DFS |
| 最短路径 | 如何找到两点间代价最小的路径？ | Dijkstra、Bellman-Ford、Floyd-Warshall |
| 最小生成树 | 如何用最小代价连接所有节点？ | Kruskal、Prim |
| 网络流 | 如何计算网络中从源到汇的最大流量？ | Ford-Fulkerson、Edmonds-Karp |
| 强连通分量 | 如何找到有向图中互相可达的节点组？ | Kosaraju、Tarjan |
| 拓扑排序 | 如何对有依赖的任务排序？ | Kahn 算法 |

## 4. 关键概念

- **图表示**：邻接矩阵（O(V²) 空间，O(1) 查边）、邻接表（O(V+E) 空间，O(deg) 查边）
- **加权图 vs 无权图**：边是否有代价/距离
- **有向图 vs 无向图**：边的方向性
- **DAG（有向无环图）**：特殊的图结构，拓扑排序的基础
- **最小割最大流定理**：网络中最大流的值等于最小割的容量

## 5. 典型算法

### 5.1 Dijkstra 算法

```
输入：加权图 G，起点 s（要求边权非负）
输出：s 到所有节点的最短距离

1. 初始化距离数组 dist[s]=0，其它 =∞
2. 使用优先队列维护未处理节点
3. 每次取出距离最小的节点 u
4. 对 u 的每条出边 (u,v,w)：
   if dist[v] > dist[u] + w:
      dist[v] = dist[u] + w
      更新优先队列
5. 重复直到队列为空

时间复杂度：O((V+E) log V)，使用二叉堆
```

### 5.2 算法对比

| 算法 | 用途 | 时间复杂度 | 约束 |
|------|------|------------|------|
| BFS | 无权图最短路径 | O(V+E) | 无权 |
| Dijkstra | 加权最短路径 | O((V+E) log V) | 非负权 |
| Bellman-Ford | 加权最短路径 | O(VE) | 无负环 |
| Floyd-Warshall | 全源最短路径 | O(V³) | 无负环 |
