# 动态规划

## 1. 一句话定义

动态规划（Dynamic Programming, DP）通过将问题分解为重叠子问题并存储子问题结果以避免重复计算，是解决具有最优子结构性质问题的最通用方法之一。

## 2. 核心问题

- 如何识别一个问题的子问题结构？
- 如何设计状态和状态转移方程？
- 自顶向下（记忆化）还是自底向上（填表）？

## 3. 知识框架

| 主题 | 核心内容 | 代表性例题 |
|------|----------|------------|
| 序列 DP | 一维状态，线性转移 | 最长递增子序列、最大子数组和 |
| 双序列 DP | 二维状态，匹配型转移 | 最长公共子序列、编辑距离 |
| 背包 DP | 容量 + 物品选择 | 0/1 背包、完全背包 |
| 区间 DP | 区间拆分与合并 | 矩阵链乘法、石子合并 |
| 树形 DP | 在树上递归定义状态 | 树的最大独立集 |
| 状态压缩 DP | 用位表示集合状态 | 旅行商问题（TSP）|

## 4. 关键概念

- **最优子结构**：问题的最优解包含子问题的最优解——这是 DP 成立的前提
- **重叠子问题**：不同递归分支遇到同样的子问题——DP 通过存储结果避免重复
- **无后效性**：子问题的解一旦确定，不受后续决策影响
- **状态定义**：DP 的核心设计决策，决定了问题的建模质量
- **状态转移方程**：描述状态之间如何递推的数学关系

## 5. 典型方法

### 5.1 DP 解题四步法

```
1. 定义状态：dp[i] 或 dp[i][j] 表示什么？
2. 写出转移方程：dp[i] = f(dp[i-1], ..., 输入)
3. 确定边界条件：dp[0] 或 dp[0][0] 的值
4. 选择计算顺序：正序/逆序/按区间长度
```

### 5.2 背包问题三种变体

| 变体 | 状态 | 转移 |
|------|------|------|
| 0/1 背包 | dp[i][w] | dp[i][w]=max(dp[i-1][w], dp[i-1][w-wt[i]]+val[i]) |
| 完全背包 | dp[w] | dp[w]=max(dp[w], dp[w-wt[i]]+val[i]) |
| 多重背包 | dp[w] | 转化为 0/1 背包（二进制拆分） |

## 6. 经典问题

- 最长公共子序列（LCS）—— 序列比对的 DP 模版
- 编辑距离（Levenshtein Distance）—— 字符串差异度量
- 背包问题及其变体 —— 组合优化的 DP 范例
- 最短路径的 Bellman-Ford 算法 —— 图上的 DP

## 7. 工程实践

- 用 DP 实现 diff 工具（编辑距离）
- 在版本控制和代码对比中理解序列比对算法
- 用 DP 求解实际资源分配的优化问题
- LeetCode DP 标签题目集中训练

## 8. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 图算法 | 有向无环图（DAG）最短路径是 DP 的自然应用 |
| 随机算法 | 马尔可夫决策过程（MDP）用 DP 求解最优策略 |
| 强化学习 | 值迭代和策略迭代是 DP 的随机推广 |
| 近似算法 | 对 NP-困难问题，DP 可用于设计伪多项式时间算法 |
