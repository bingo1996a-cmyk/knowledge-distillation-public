# 随机算法

## 1. 一句话定义

随机算法在计算过程中引入随机性，通过概率分析保证期望时间复杂度或正确性，在某些问题上比确定性算法更简单、更高效。

## 2. 核心问题

- 随机性如何帮助简化算法设计？
- 如何分析随机算法的期望性能和失败概率？
- 如何在最坏情况下保证性能？

## 3. 知识框架

| 类型 | 特点 | 代表性算法 |
|------|------|------------|
| Las Vegas 算法 | 保证正确，运行时间随机 | 随机快速排序 |
| Monte Carlo 算法 | 保证时间，正确性随机 | Karger 最小割 |
| 随机采样 | 通过采样估计或逼近 | 拒绝采样、MCMC |
| 随机数据结构 | 结构依赖随机选择 | 跳表（Skip List）|

## 4. 关键概念

- **Las Vegas vs Monte Carlo**：LV 保证输出正确（时间随机），MC 保证时间（正确性随机）
- **Chernoff Bound（切尔诺夫界）**：随机变量偏离期望的概率上界——随机算法分析的核心工具
- **随机化枢轴**：将最坏情况转化为平均情况的简单技术（随机快速排序）
- **去随机化**：用确定方法（如条件期望法）消除随机性但保持性能

## 5. 典型算法

### 5.1 随机快速排序

```
随机选择枢轴 → 划分 → 左右递归

期望时间复杂度：O(n log n)
高概率时间复杂度：O(n log n)
最坏情况（极低概率）：O(n²)

与确定性快速排序（固定取首/尾）相比：
- 避免对已排序输入的性能退化
- 不需要输入分布的假设
```

### 5.2 主要随机算法对比

| 算法 | 类型 | 期望复杂度 | 用途 |
|------|------|------------|------|
| 随机快速排序 | LV | O(n log n) | 排序 |
| Karger 最小割 | MC | O(m log³ n) | 图割 |
| Rabin-Karp 字符串匹配 | MC | O(n+m) | 模式匹配 |
| Skip List | LV | O(log n) 操作 | 有序字典 |

## 6. 经典问题

- 中位数查找的随机 O(n) 算法（Quickselect）
- 哈希冲突概率与生日悖论
- 随机化在分布式系统中的去中心化决策
- 概率可验证明（PCP）定理与近似困难性

## 7. 工程实践

- 实现跳表（Skip List）理解随机数据结构的优势
- 用蓄水池抽样（Reservoir Sampling）处理流数据的均匀采样
- 在实际系统中观察哈希函数的负载均衡效果
- 理解负载均衡器中的随机选择策略

## 8. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 哈希表 | 全域哈希（Universal Hashing）是随机算法的重要应用 |

| 机器学习 | 随机梯度下降（SGD）、Dropout 中的随机性 |
| 密码学 | 随机数是密码系统安全的基础 |
