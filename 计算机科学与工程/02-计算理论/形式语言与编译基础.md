# 形式语言与编译基础

## 1. 一句话定义

形式语言是用严格的数学方式定义语言（字符串集合）及其识别和生成机制，是编译原理的词法分析和语法分析的理论基础。

## 2. 核心问题

- 如何精确描述编程语言的语法规则？
- 什么样的语言可以被什么样的自动机识别？
- 乔姆斯基谱系如何对应到编译器不同阶段？

## 3. 知识框架

| 语言层次 | 对应自动机 | 文法规则 | 编译阶段对应 |
|----------|------------|----------|--------------|
| 正则语言（3 型）| 有限自动机 | A→aB | 词法分析（Token）|
| 上下文无关语言（2 型）| 下推自动机 | A→α | 语法分析（AST）|
| 上下文相关语言（1 型）| 线性有界自动机 | αAβ→αγβ | 语义分析（类型检查）|
| 递归可枚举（0 型）| 图灵机 | 无限制 | 优化（任意变换）|

## 4. 关键概念

- **正则表达式**：描述正则语言的简洁方式——词法分析器（Lexer）的核心
- **上下文无关文法（CFG）**：描述编程语言语法结构的标准方式——巴科斯-瑙尔范式（BNF）是常用记法
- **推导与归约**：推导从开始符号生成句子，归约从句子回到开始符号——对应自顶向下（LL）和自底向上（LR）分析
- **二义性**：一个句子有多于一个解析树——需要文法重写或优先级规则消歧
- **乔姆斯基范式（CNF）**：每条文法规则形如 A→BC 或 A→a，便于理论分析

## 5. 典型机制

### 5.1 LL vs LR 分析

| 特性 | LL（自顶向下）| LR（自底向上）|
|------|---------------|---------------|
| 分析方向 | 从开始符号到句子 | 从句子到开始符号 |
| 能处理文法 | LL 文法子集 | LR 文法超集（更大）|
| 手写实现 | 递归下降，容易手写 | 表驱动，通常工具生成 |
| 典型工具 | ANTLR | yacc/bison |

### 5.2 词法分析的实现

```
正则表达式 → NFA（Thompson 构造）
          → DFA（子集构造）
          → 最小化 DFA（Hopcroft 算法）
          → 驱动代码（最长匹配 + 优先级）
```

## 6. 经典问题

- 哪些语法是上下文无关但不是正则的？（考虑嵌套括号：a^n b^n）
- 移进-归约冲突和归约-归约冲突
- 左递归——直接左递归可消除，间接左递归也可消除

## 7. 工程实践

- 用 flex（词法）和 bison（语法）为一个小语言生成解析器
- 手写递归下降解析器解析 JSON 或简单计算器
- 理解 Python `ast` 模块如何解析代码为抽象语法树
- 使用 ANTLR 可视化解析树
