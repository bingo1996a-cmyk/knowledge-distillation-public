# 电路复杂性

## 1. 一句话定义

电路复杂性研究布尔电路解决问题的资源下限，试图回答"计算一个函数至少需要多大的电路"——是解决 P vs NP 问题最有希望的攻击路径之一。

## 2. 核心问题

- 为什么证明电路下界可能比直接证明 P ≠ NP 更容易？
- 哪些函数已被证明需要大电路？
- 电路复杂性如何解释神经网络的表达能力？

## 3. 知识框架

| 概念 | 核心内容 | 代表结果 |
|------|----------|----------|
| 布尔电路 | 门（AND/OR/NOT）+ 导线组成的有向无环图 | 每个布尔函数都有电路实现 |
| 电路复杂度 | 计算某个函数所需的最小电路规模或深度 | 多数函数的电路大小为指数 |
| 电路类 | 基于规模/深度/门类型限制的类 | AC⁰、TC⁰、NC¹、P/poly |
| 下界证明 | 证明某函数不在某电路类中 | PARITY ∉ AC⁰ |

## 4. 关键概念

- **电路与算法的区别**：算法处理可变长输入，一个电路处理一个固定大小的输入——电路的"非一致性"使它可以编码不可计算信息
- **P/poly**：可由多项式规模电路族求解的问题类——已知 NP ⊆ P/poly（尚未被排除）
- **AC⁰**：常数深度、不限入度 AND/OR 门的电路类——不能计算 PARITY（即 n 位异或，需至少指数规模 AC⁰ 电路）
- **下界证明的稀缺性**：经过数十年，目前最强的下界结果仍是"不能通过 6n 个门大小的电路计算"（对一般电路）——证明电路下界异常困难

## 5. 典型结果

### 5.1 电路类层级

```
AC⁰ ⊂ TC⁰ ⊆ NC¹ ⊆ P/poly

AC⁰: 常数深度，不限入度
TC⁰: AC⁰ + 多数门（阈值门）
NC¹: O(log n) 深度，限入度 2
P/poly: 多项式规模
```

### 5.2 已知的重要下界

| 函数 | 电路类下界 |
|------|-----------|
| PARITY | ∉ AC⁰（需指数大小）|
| 多数（MAJORITY）| ∉ AC⁰ |
| 一般函数（计数的）| 需要 Ω(2^n/n) 个门 |
| NP-完全问题 | 无超多项式下界（P vs NP 的等价形式）|
