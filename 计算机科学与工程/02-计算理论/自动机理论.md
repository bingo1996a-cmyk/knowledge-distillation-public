# 计算理论

## 1. 一句话定义

计算理论研究"什么是可计算的、计算需要多少资源、以及计算的数学性质"，是计算机科学最底层的理论基础。

## 2. 核心问题

- 哪些问题是计算机可以解决的？（可计算性）
- 解决问题的难度如何度量？（计算复杂性）
- 计算的形式模型是什么样的？（自动机与形式语言）

## 3. 知识框架

| 子领域 | 核心内容 | 关键问题 |
|--------|----------|----------|
| 自动机理论 | 有限自动机、下推自动机、图灵机 | 不同计算模型的表达能力 |
| 可计算性理论 | 图灵可计算性、停机问题、归约 | 什么问题是不可计算的？ |
| 复杂性理论 | P、NP、NP-完全、空间复杂性 | 问题按难度如何分类？ |
| 形式语言 | 正则语言、上下文无关语言、乔姆斯基谱系 | 语言如何分类？与自动机的对应？ |

## 4. 关键概念

- **图灵机（Turing Machine）**：计算的最通用模型，定义了"可计算"的边界
- **邱奇-图灵论题（Church-Turing Thesis）**：所有直觉上可计算的函数都是图灵可计算的
- **停机问题（Halting Problem）**：不可计算问题的经典例子
- **P vs NP**：计算机科学最重要的未解决问题之一
- **乔姆斯基谱系（Chomsky Hierarchy）**：形式语言的 4 层分类（正则 < 上下文无关 < 上下文相关 < 递归可枚举）

## 5. 典型机制

### 5.1 自动机层级

```
有限自动机 (FA) ⊂ 下推自动机 (PDA) ⊂ 线性有界自动机 (LBA) ⊂ 图灵机 (TM)
     ↕                  ↕                    ↕                  ↕
  正则语言  ⊂  上下文无关语言  ⊂   上下文相关语言  ⊂  递归可枚举语言
```

### 5.2 多项式时间归约

如果一个 NP 问题 A 可以在多项式时间内归约到另一个 NP 问题 B，那么 B 至少和 A 一样难。这建立了 NP-完全问题的理论基础。

## 6. 经典问题

- 停机问题不可判定
- SAT 是第一个被证明 NP-完全的问题（Cook-Levin 定理）
- P 是否等于 NP？
- 正则语言的泵引理

## 7. 工程实践

- 用正则表达式做模式匹配（词法分析）
- 用上下文无关文法描述编程语言语法（语法分析）
- 在算法设计中识别 NP-困难问题，转向近似算法或启发式方法
