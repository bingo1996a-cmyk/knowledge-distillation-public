# 可计算性理论

## 1. 一句话定义

可计算性理论研究"什么问题可以被计算机解决"，以图灵机为最通用的计算模型，建立了可计算与不可计算的严格边界。

## 2. 核心问题

- 所有问题都能被计算机解决吗（答案是：不能）？
- 如何证明一个问题比另一个更难？
- 哪些问题虽然不可判定但可以被部分解决？

## 3. 知识框架

| 主题 | 核心内容 | 里程碑结果 |
|------|----------|------------|
| 计算模型 | 图灵机、λ 演算、递归函数 | Church-Turing 论题 |
| 可判定性 | 哪些问题可判定、哪些不可 | 停机问题、对角化 |
| 归约 | 将一个问题转化为另一个 | 映射归约、图灵归约 |
| 判定过程 | 可判定理论的自动推理 | Presburger 算术 |
| 计算层级 | 算术层级、分析层级 | 递归可枚举集的复杂性 |

## 4. 关键概念

- **图灵机（Turing Machine）**：一个有限控制器 + 一条无限长的带——这是"计算"的形式化定义
- **Church-Turing 论题**：每个直觉上可计算的函数都是图灵机可计算的——这不是定理，而是对"可计算"的定义
- **停机问题（Halting Problem）**：判断任意程序是否会在有限步内停机——第一个被证明不可判定的问题
- **对角化（Diagonalization）**：康托尔发明的证明技术，用于证明存在语言不能被任何图灵机识别
- **可判定 vs 可识别**：可判定（程序总是停机并回答是/否）vs 图灵可识别（对于"是"实例会停机接受，对于"否"实例可能永远运行）

## 5. 典型方法

### 5.1 停机问题不可判定的证明（概要）

```
假设存在一个程序 H(P, I) 能判断程序 P 在输入 I 上是否停机。
构造恶意程序 D：
  D(X): if H(X, X) == "停机" then 死循环 else 停机
问：D(D) 是否停机？
- 如果 D(D) 停机 → H 判断 D(D) 停机 → D 进入死循环 → 矛盾
- 如果 D(D) 不停机 → H 判断 D(D) 不停机 → D 返回停机 → 矛盾
结论：H 不可能存在
```

### 5.2 常见不可判定问题

| 问题 | 不可判定的原因 |
|------|---------------|
| 停机问题 | 对角化，计算理论的基础 |
| 希尔伯特第十问题 | 丢番图方程的可解性 |
| Post 对应问题 | 字符串匹配的不可判定性 |
| 一阶逻辑永真性 | 一阶逻辑的不可判定性 |

## 6. 经典问题

- 是否存在比停机问题"更难"的问题（答案是：有，通过图灵跳越）？
- 所有数学问题是否都可判定（哥德尔不完备定理的结论：否）？
- 编程语言的类型系统与可判定性的关系

## 7. 工程实践

- 在编译器开发中理解静态分析的可判定性边界
- 将实际问题建模为已知可判定/不可判定问题框架
- 理解类型检查器（Type Checker）为什么必须是可判定的
- 使用 SMT 求解器探索可判定片段的实际求解能力
