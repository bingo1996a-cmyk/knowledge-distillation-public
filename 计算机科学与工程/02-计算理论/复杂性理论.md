# 复杂性理论

## 1. 一句话定义

复杂性理论在可计算的前提下，研究解决问题需要多少计算资源（时间、空间），并按难度将问题分类，形成从 P 到 NP、PSPACE、EXP 的复杂类层级。

## 2. 核心问题

- P 是否等于 NP？
- 问题难度如何被严格分类和比较？
- 随机性和交互如何影响计算能力？

## 3. 知识框架

| 主题 | 核心内容 | 代表性结果 |
|------|----------|------------|
| 时间复杂性 | P、NP、EXP 类 | Cook-Levin 定理 |
| 空间复杂性 | L、PSPACE、Savitch 定理 | PSPACE = NPSPACE |
| NP-完全性 | 归约、完全问题 | 3SAT 的 NP-完全性 |
| 电路复杂性 | 电路下界 | P/poly、AC⁰ |
| 随机性与交互 | BPP、IP、PCP | IP = PSPACE |

## 4. 关键概念

- **P 类**：可在多项式时间内求解的问题——"高效可解"的形式化定义
- **NP 类**：解可在多项式时间内验证的问题——"容易检查但未必容易找到"
- **NP-完全**：NP 中最难的问题——如果任何一个 NP-完全问题 ∈ P，则 P = NP
- **多项式时间归约**：问题 A 可被多项式时间算法利用问题 B 的求解器解决→ A ≤_P B
- **PSPACE**：可在多项式空间中求解（可能花指数时间）

## 5. 典型方法

### 5.1 经典复杂性类层级

```
P ⊆ NP ⊆ PH ⊆ PSPACE ⊆ EXP ⊆ NEXP

已知：P ≠ EXP（时间层级定理）
未知：P 是否等于 NP（最大未解之谜）
```

### 5.2 经典 NP-完全问题

| 问题 | 描述 |
|------|------|
| SAT（布尔可满足性）| Cook-Levin 定理：第一个 NP-完全问题 |
| 3SAT | SAT 限制为每个子句 3 个文字 |
| 顶点覆盖 | 选 k 个顶点覆盖所有边 |
| 哈密顿路径 | 经过所有节点恰好一次 |
| 子集和 | 是否存在子集之和等于目标值 |
| 旅行商问题（TSP）| 最短哈密顿回路 |

## 6. 经典问题

- P vs NP——如果 P=NP，密码学会坍塌，优化会变得容易
- BPP 是否等于 P——随机性能否被去随机化
- 电路的指数下界——证明某些问题需要指数规模电路
- 量子计算机是否能在多项式时间内解决经典 NP-完全问题（大多数研究者认为不能）

## 7. 工程实践

- 识别实际中遇到的 NP-困难问题，不试图求精确解
- 用 ILP 求解器（如 Gurobi）理解"实际可解" vs "理论 NP-困难"
- 使用 SAT 求解器解决组合约束问题
- 理解密码方案背后的困难假设（大数分解、离散对数）

## 8. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 可计算性理论 | 先问"是否可计算"，再问"需要多少资源" |
| 算法设计 | 复杂性指导算法策略：精确 vs 近似 vs 启发式 |
| 密码学 | 密码安全依赖计算困难性 |
| 量子计算 | BQP 与经典复杂类的关系 |
