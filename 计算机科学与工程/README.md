# 计算机科学与工程知识库

本知识库面向计算机科学与工程的学习、科研和工程实践，采用 Markdown 编写，支持本地浏览、全文检索和长期版本管理。

## 知识库定位

- **学科地图**：建立计算机科学与工程的整体认知框架
- **核心概念**：系统化整理关键术语、模型与机制
- **算法与系统**：覆盖经典算法、系统设计与实现
- **工程实践**：支撑软件开发、系统设计、架构选型、部署运维
- **论文与教材**：经典文献、顶级会议期刊、图灵奖成果索引
- **学习路线**：面向不同目标的分层学习路径

## 目录结构

```
计算机科学与工程/
├── 00-总纲/                         # 知识库说明、学科地图、写作规范
├── 01-数学基础/                      # 离散数学、线性代数、概率论、逻辑、信息论

├── 03-算法与数据结构/                 # 数据结构、图算法、DP、随机算法、近似算法、并行算法
├── 04-计算机系统/                     # 组成原理、操作系统、编译原理、体系结构、嵌入式
├── 05-软件工程/                      # 需求、架构、设计模式、测试、DevOps、项目管理
├── 06-数据库与数据工程/               # 关系数据库、分布式数据库、数据仓库、大数据、数据治理
├── 07-计算机网络与分布式系统/          # 网络、TCP/IP、分布式系统、云计算、边缘计算、微服务
├── 08-人工智能与机器学习/             # ML、DL、RL、图ML、LLM、智能体
├── 09-人机交互与图形学/               # HCI、图形学、可视化、XR
├── 10-网络安全与可信计算/             # 密码学、网络安全、系统安全、隐私计算、可信计算
├── 11-工程实践专题/                   # Python/C++工程化、Linux、Git、容器/K8s、API设计
├── 12-论文与经典文献/                 # 经典论文、顶会期刊、图灵奖、教材索引
├── 13-学习路线/                      # 本科、研究生、软件工程师、AI工程师、系统工程师

├── assets/                          # 图片、图表、参考文献
├── scripts/                         # 链接检查、索引构建、元数据验证
└── docs/                            # 设计文档
```
