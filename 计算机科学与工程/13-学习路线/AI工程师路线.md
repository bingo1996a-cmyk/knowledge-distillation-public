# AI 工程师路线

## 1. 一句话定义

本路线面向目标是成为机器学习/AI 工程师的学习者，覆盖从数学基础到模型部署的全栈 ML 能力。

## 2. 核心问题

- AI 工程师和 AI 研究员的技能区别是什么？
- 如何平衡理论深度和工程实践能力？
- 在 LLM 时代 AI 工程师的核心竞争力是什么？

## 3. 五阶段路线

### 阶段一：数学与编程准备

| 技能 | 要点 | 时间 |
|------|------|------|
| 线性代数 | 矩阵运算、特征值/SVD、内积空间 | 2-3 周 |
| 概率论 | 分布、贝叶斯、期望和方差 | 2-3 周 |
| 微积分 | 导数、链式法则、梯度 | 1-2 周 |
| Python + NumPy | 数组操作、广播、向量化 | 持续 |

### 阶段二：经典机器学习

| 技能 | 要点 |
|------|------|
| 监督学习 | 线性/逻辑回归、SVM、决策树、随机森林、XGBoost |
| 无监督学习 | K-means、PCA、t-SNE |
| 模型评估 | 交叉验证、偏差-方差、混淆矩阵、ROC-AUC |
| 工具 | scikit-learn 完整工作流 |

### 阶段三：深度学习

| 任务 | 要点 |
|------|------|
| 神经网络基础 | MLP、反向传播、激活函数、正则化 |
| CNN | 卷积、池化、经典架构（ResNet） |
| RNN/LSTM/GRU | 序列建模 |
| Transformer | 自注意力、位置编码 |
| 框架 | PyTorch——模型定义、训练、验证、保存 |

### 阶段四：ML 工程化（MLOps）

| 技能 | 要点 |
|------|------|
| 数据工程 | 数据管道、特征存储、数据版本管理 |
| 实验管理 | MLflow/W&B 跟踪实验和模型 |
| 模型部署 | REST API 服务、ONNX/TensorRT 优化 |
| 监控 | 数据漂移、模型性能退化检测 |

### 阶段五：LLM 与前沿应用

| 技能 | 要点 |
|------|------|
| LLM 基础 | Prompt Engineering、少样本学习 |
| 微调 | LoRA/QLoRA、指令微调 |
| RAG | 检索增强生成——嵌入 + 向量搜索 + 生成 |
| Agent | 工具调用、多步推理、多智能体协作 |

## 4. 工程实践

- 从零实现线性回归和逻辑回归（理解而不仅是调用）
- 参加 Kaggle 比赛获得端到端经验
- 部署一个完整的 ML 模型服务
- 用 LoRA 微调开源 LLM 并部署

## 5. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 数学基础 | ML 的数学底座 |
| 数据库/数据工程 | AI 系统的数据基础设施 |
| 软件工程 | ML 系统需遵循软件工程实践 |
