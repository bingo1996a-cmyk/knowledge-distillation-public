# 安全工程师路线

## 1. 一句话定义

本路线面向目标是安全工程师的学习者，覆盖从基础攻防知识到安全架构和应急响应，强调"知道怎么攻击才知道怎么防御"的安全思维。

## 2. 核心问题

- 安全工程师如何建立从攻击到防御的完整视角？
- 如何从底层系统知识中理解安全漏洞的本质？
- 如何在安全深度的不同方向（Web/二进制/网络/云安全）中选择？

## 3. 四阶段路线

### 阶段一：安全基础

| 技能 | 要点 |
|------|------|
| 网络安全基础 | TCP/IP、HTTP、TLS/DNS 协议理解 |
| 操作系统安全 | 进程、权限、用户态/内核态、文件权限 |
| Web 基础 | 前后端交互、数据库、Cookie/Session |
| 编程 | Python（脚本）、C（理解底层）、JavaScript |

### 阶段二：攻击技术入门

| 技能 | 要点 |
|------|------|
| Web 安全 | OWASP Top 10——SQLi、XSS、CSRF、SSRF |
| 网络攻防 | 扫描（nmap）、抓包（Wireshark）、中间人 |
| 密码学基础 | 对称/非对称、哈希、证书、JWT |
| CTF | 通过比赛练习实际攻防技能 |

### 阶段三：进阶方向选择

选择一个方向深入：

| 方向 | 核心技能 |
|------|----------|
| Web/应用安全 | 代码审计、WAF、API 安全、SSO/OAuth |
| 二进制/逆向 | 反汇编（IDA/Ghidra）、fuzzing、漏洞利用 |
| 基础设施/云安全 | K8s 安全、IAM、网络策略、Terraform 安全 |
| 安全开发（AppSec）| 安全编码、威胁建模、代码审查 |

### 阶段四：防御与架构

| 技能 | 要点 |
|------|------|
| 威胁建模 | STRIDE 方法论、攻击面分析 |
| 安全架构 | 零信任、纵深防御、最小权限 |
| 应急响应 | DFIR、证据收集、复盘 |
| 安全自动化 | SOAR、安全编排 |

## 4. 工程实践

- 搭建本地靶场（OWASP WebGoat、DVWA）做渗透练习
- 参加 CTF 比赛（PicoCTF 入门 → DEF CON CTF 进阶）
- 学习使用 Burp Suite、Metasploit、nmap 等安全工具
- 对自有项目进行威胁建模和安全审查

## 5. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 网络安全与可信计算 | 安全工程师的理论基础 |
| 计算机网络/OS | 底层系统知识是漏洞理解的前提 |
| DevOps | DevSecOps——安全左移 |
