# 嵌入式工程师路线

## 1. 一句话定义

本路线面向目标是嵌入式/IoT 开发者的学习者，从裸机编程到底层驱动再到联网嵌入式系统，逐步建立软硬件协同能力。

## 2. 核心问题

- 嵌入式工程师如何建立"看得见硬件、写得出软件"的跨界能力？
- 如何在资源极度受限的环境中编程？
- 如何调试看不见的硬件问题？

## 3. 四阶段路线

### 阶段一：硬件与 C 语言基础

| 技能 | 要点 |
|------|------|
| C 语言 | 指针、位运算、结构体、内存对齐、volatile |
| 数字电路基础 | GPIO、寄存器、时序图 |
| 单片机入门 | Arduino/STM32——点亮 LED、读取传感器 |
| 工具 | 万用表、逻辑分析仪、示波器基本使用 |

### 阶段二：裸机与 RTOS

| 技能 | 要点 |
|------|------|
| 外设驱动 | UART、SPI、I2C、PWM 的寄存器级编程 |
| 中断 | ISR 编写、中断优先级、嵌套 |
| RTOS | FreeRTOS 任务调度、队列、信号量 |
| 低功耗 | 休眠模式、时钟门控 |

### 阶段三：嵌入式 Linux

| 技能 | 要点 |
|------|------|
| Linux 内核基础 | 设备树、内核模块、字符设备驱动 |
| Buildroot/Yocto | 构建自定义 Linux 镜像 |
| 交叉编译 | 工具链、sysroot、CMake 交叉编译配置 |
| 启动流程 | Boot ROM → U-Boot → Kernel → rootfs |

### 阶段四：联网与安全

| 技能 | 要点 |
|------|------|
| 无线协议 | BLE、Wi-Fi、LoRa、Zigbee |
| IoT 通信 | MQTT、CoAP |
| 安全 | 安全启动、固件签名、密钥存储 |
| OTA | 固件升级策略、A/B 分区 |

## 4. 学习建议

- 买一块开发板（STM32 Nucleo / ESP32）动手比看文档重要得多
- 学会看数据手册和参考手册——这是嵌入式的基本功
- 示波器和逻辑分析仪是嵌入式开发的"眼睛"

## 5. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 嵌入式系统 | 路线的理论基础 |
| 操作系统 | RTOS + 嵌入式 Linux |
| 计算机网络 | IoT 通信协议 |
