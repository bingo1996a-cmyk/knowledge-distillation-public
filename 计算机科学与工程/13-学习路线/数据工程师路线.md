# 数据工程师路线

## 1. 一句话定义

本路线面向目标是数据工程师的学习者，覆盖从数据管道构建、数据仓库建模到数据平台运维的完整技能栈。

## 2. 核心问题

- 数据工程师和数据分析师/数据科学家的技能差异是什么？
- 如何构建可靠、可扩展的数据管道？
- 数据工程师在 AI 时代的新角色是什么？

## 3. 四阶段路线

### 阶段一：数据处理基础

| 技能 | 要点 |
|------|------|
| SQL 精通 | 复杂查询、窗口函数、CTE、查询优化 |
| Python 数据处理 | pandas、数据处理范式 |
| 数据建模 | 星型/雪花模式、SCD、数据仓库设计 |
| Shell/Linux | 命令行文本处理、管道 |

### 阶段二：数据管道

| 技能 | 要点 |
|------|------|
| ETL/ELT 工具 | dbt、Airflow、Mage |
| 批处理 | Spark——RDD/DataFrame API、分区优化 |
| 流处理 | Kafka + Flink/Kafka Streams |
| 数据格式 | Parquet、Avro、Iceberg |

### 阶段三：数据平台

| 技能 | 要点 |
|------|------|
| 数据仓库 | 列存概念、分区和分桶策略 |
| 数据湖/湖仓 | Delta Lake、Iceberg、S3 数据架构 |
| 容器与 K8s | 数据基础设施的容器化 |
| 基础设施即代码 | Terraform 管理数据资源 |

### 阶段四：数据治理与工程文化

| 技能 | 要点 |
|------|------|
| 数据质量 | Great Expectations、dbt tests |
| 数据血缘与目录 | DataHub、Amundsen |
| CI/CD for Data | 数据管道的测试和自动化部署 |
| 成本优化 | 计算和存储资源的成本控制 |

## 4. 学习建议

- 不要先学所有工具再动手——从 SQL + Python 出发逐步扩展
- 关注数据可靠性而非只是数据管道——"管道运行了 ≠ 数据是正确的"
- 理解业务——数据工程师的价值最终体现在数据能不能被业务用起来

## 5. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 数据库与数据工程 | 数据工程的理论和实践基础 |
| 云计算 | 现代数据平台构建在云上 |
| DevOps | 数据工程的 CI/CD 实践 |
