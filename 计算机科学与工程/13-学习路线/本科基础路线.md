# 学习路线

## 1. 一句话定义

本域提供面向不同目标（本科基础、研究生科研、软件工程师、AI 工程师、系统工程师）的分层学习路线。

## 2. 核心问题

- 不同目标的学习者应优先学什么？
- 学习的先后顺序如何安排？
- 每个阶段应达到什么水平？

## 3. 五条路线总览

| 路线 | 目标人群 | 核心侧重 |
|------|----------|----------|
| 本科基础路线 | 本科生 | 建立系统、理论、应用的全景基础 |
| 研究生科研路线 | 硕士/博士 | 选定方向深入 + 科研方法论 |
| 软件工程师路线 | 后端/前端/全栈 | 工程能力 + 系统知识 + 业务理解 |
| AI 工程师路线 | ML/DL 从业者 | 算法 + 工程 + 数据 |
| 系统工程师路线 | 基础架构/SRE | 操作系统 + 网络 + 分布式 + 性能 |

## 4. 本科基础路线

### 4.1 四个阶段

| 阶段 | 主题 | 核心课程 |
|------|------|----------|
| 阶段一：基础 | 编程入门 + 数学基础 | 程序设计、离散数学、微积分 |
| 阶段二：核心 | 数据结构 + 组成 + 理论 | 数据结构与算法、计算机组成、计算理论 |
| 阶段三：系统 | 操作系统 + 网络 + 编译 | OS、计算机网络、编译原理 |
| 阶段四：应用 | 数据库 + AI + 软件工程 + 安全 | DB、ML、软件工程、密码学 |

### 4.2 建议顺序

```
程序设计 → 离散数学 → 数据结构与算法 → 计算机组成原理
                                         ↓
                                    操作系统 ← 计算机网络
                                         ↓
                    {数据库, 编译原理, AI基础, 软件工程, 安全}
```

## 5. 研究生科研路线

| 阶段 | 重点 | 行动项 |
|------|------|--------|
| 阶段一：方向选择 | 了解各领域研究现状 | 阅读综述论文，参加研讨会 |
| 阶段二：深挖领域 | 精通选定的子领域 | 精读 50+ 篇论文，复现关键方法 |
| 阶段三：独立研究 | 发现并解决问题 | 提出假设、设计实验、撰写论文 |
| 阶段四：学术建设 | 建立学术影响力 | 投稿、参与社区、审稿 |

核心建议：研一开始精读论文而非刷课；尽早动手做实验而非只在纸上设计。

## 6. 软件工程师路线

| 阶段 | 重点 | 关键技能 |
|------|------|----------|
| 阶段一：编程 | 扎实的编程基础 | 至少精通一门语言（Python/Java/C++），数据结构和算法 |
| 阶段二：系统 | 理解计算系统 | OS 基础、网络协议、数据库使用 |
| 阶段三：工程 | 工程化能力 | Git、CI/CD、测试、Docker、设计模式 |
| 阶段四：架构 | 系统设计能力 | 分布式系统、架构设计、容量规划 |
| 阶段五：领域 | 业务领域专长 | 根据行业方向深入特定技术和业务 |

## 7. AI 工程师路线

| 阶段 | 重点 | 关键技能 |
|------|------|----------|
| 阶段一：数学 | ML 数学基础 | 线性代数、概率论、优化 |
| 阶段二：基础 | 经典 ML 方法 | 回归、分类、聚类、集成方法 |
| 阶段三：深度学习 | 神经网络 | CNN、RNN、Transformer、PyTorch |
| 阶段四：工程化 | ML 系统工程 | 数据工程、模型部署、MLOps |
| 阶段五：前沿 | 大模型/Agent | 预训练、微调、RLHF、RAG、多模态 |

## 8. 系统工程师路线

| 阶段 | 重点 | 关键技能 |
|------|------|----------|
| 阶段一：OS | 操作系统深入 | 内核原理、进程调度、内存管理、文件系统 |
| 阶段二：网络 | 网络深入 | 协议栈、高性能网络、SDN |
| 阶段三：分布式 | 大规模系统 | 共识、复制、负载均衡、故障处理 |
| 阶段四：基础设施 | 平台能力 | K8s、IaC、监控告警、容量规划 |
| 阶段五：性能 | 性能工程 | Profiling、优化、基准测试 |
