# 软件工程师路线

## 1. 一句话定义

本路线面向目标是成为专业软件开发者的学习者，从编程基础到系统设计，逐步建立工程能力。

## 2. 核心问题

- 软件工程师的核心能力栈是什么？
- 如何在不同阶段选择优先级？
- 如何从初级工程师成长为高级/架构工程师？

## 3. 五阶段路线

### 阶段一：编程基础（0-6 月）

| 技能 | 要点 |
|------|------|
| 一门主流语言 | Python 或 Java——语法、标准库、基本调试 |
| 数据结构与算法基础 | 数组、链表、哈希表、栈、队列、树、排序和搜索 |
| Git 基础 | clone/commit/push/pull/branch/merge |
| 命令行 | Linux 基本命令、Shell 脚本基础 |

### 阶段二：构建应用（6-12 月）

| 技能 | 要点 |
|------|------|
| 数据库 | SQL 查询、表设计、基本的索引优化 |
| 前后端基础 | 选择一个框架，构建完整的 CRUD 应用 |
| 测试 | 单元测试、集成测试概念 |
| 开发工具 | IDE、调试器、包管理器熟练使用 |

### 阶段三：工程化能力（1-2 年）

| 技能 | 要点 |
|------|------|
| CI/CD | 自动化构建、测试、部署流水线 |
| Docker | 容器化应用 |
| 设计模式 | 能识别和应用常见设计模式 |
| 代码审查 | 参与审查和被审查 |

### 阶段四：系统设计（2-4 年）

| 技能 | 要点 |
|------|------|
| 架构基础 | 分层架构、微服务、事件驱动 |
| 分布式系统 | 缓存、消息队列、一致性 |
| 性能优化 | Profiling、SQL 优化、缓存策略 |
| 安全 | OWASP Top 10、认证授权 |

### 阶段五：领域专家（4+ 年）

选择 1-2 个方向深入：后端/前端/基础设施/数据工程/安全/移动端，建立跨领域的系统视野。

## 4. 各阶段重点书目

| 阶段 | 推荐阅读 |
|------|----------|
| 编程基础 | The Pragmatic Programmer |
| 构建应用 | Clean Code (Martin)、各框架官方教程 |
| 工程化 | Effective Java/Python、Designing Data-Intensive Applications |
| 系统设计 | System Design Interview (Alex Xu)、DDIA |

## 5. 工程实践

- 参与开源项目（从修小 bug 开始）
- 维护个人项目并持续迭代
- 做一次架构重构体验权衡
- 写技术博客总结学习

## 6. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 软件工程 | 路线中的理论依据来自软件工程方法论 |
| 数据库/网络 | 后端工程师的必备知识 |
