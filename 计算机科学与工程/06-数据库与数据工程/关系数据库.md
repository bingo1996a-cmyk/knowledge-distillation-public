# 数据库与数据工程

## 1. 一句话定义

数据库与数据工程研究如何高效、可靠、安全地存储、查询、管理和治理大规模数据。

## 2. 核心问题

- 如何组织数据使其能被高效查询和更新？
- 如何在分布式环境下保证数据一致性、可用性和分区容忍性？
- 如何管理数据的全生命周期——从产生、清洗、存储到应用和归档？

## 3. 知识框架

| 子领域 | 核心内容 | 代表性系统 |
|--------|----------|------------|
| 关系数据库 | 关系模型、SQL、事务、索引 | PostgreSQL、MySQL |
| 分布式数据库 | 复制、分片、共识、分布式事务 | Spanner、CockroachDB |
| 数据仓库 | OLAP、列式存储、ETL/ELT | Snowflake、ClickHouse |
| 大数据系统 | MapReduce、流处理、湖仓一体 | Spark、Flink、Iceberg |
| 数据治理 | 数据质量、元数据管理、血缘 | DataHub、Atlas |

## 4. 关键概念

- **事务（ACID）**：原子性、一致性、隔离性、持久性——保证数据正确性的基础
- **CAP 定理**：一致性、可用性、分区容忍性三者最多同时满足两个
- **SQL 与关系代数**：声明式查询语言与形式化基础
- **索引结构**：B+ 树、LSM 树、哈希索引——不同场景下的存储加速策略
- **OLTP vs OLAP**：在线事务处理 vs 在线分析处理——行存 vs 列存

## 5. 典型机制

### 5.1 事务隔离级别

| 级别 | 脏读 | 不可重复读 | 幻读 |
|------|------|------------|------|
| Read Uncommitted | 是 | 是 | 是 |
| Read Committed | 否 | 是 | 是 |
| Repeatable Read | 否 | 否 | 是 |
| Serializable | 否 | 否 | 否 |

### 5.2 二阶段锁（2PL）与 MVCC

- 2PL 通过锁定保证可串行化，简单但有锁开销
- 多版本并发控制（Multi-Version Concurrency Control, MVCC）通过维护数据快照实现读写不阻塞

## 6. 经典问题

- 连接（JOIN）的查询优化
- 分布式事务的原子提交（两阶段提交 vs 三阶段提交）
- 数据倾斜问题
- 流处理中的精确一次（Exactly-Once）语义

## 7. 工程实践

- 使用 `EXPLAIN` 分析 SQL 查询执行计划
- 根据查询模式设计合理的索引策略
- 搭建简单的读副本（Read Replica）实现读写分离
- 使用 CDC（Change Data Capture）实现实时数据同步
