# 术语规范

## 1. 一句话定义

本文件规定知识库中术语使用、命名和格式的统一规范，保证全库表述一致性。

## 2. 核心问题

- 同一概念在不同语境下有多个名称时如何处理？
- 中英文术语如何搭配？
- 缩写和全称的关系如何处理？

## 3. 术语使用规则

### 3.1 中英文处理

- 正文以中文叙述为主
- 关键术语首次出现时标注英文全称和缩写：虚拟内存（Virtual Memory, VM）
- 后续出现可直接使用中文或缩写
- 已有通用中文译名的术语优先使用中文

### 3.2 缩写规范

| 规则 | 示例 |
|------|------|
| 首次出现给出全称 + 缩写 | 传输控制协议/网际协议（Transmission Control Protocol/Internet Protocol, TCP/IP） |
| 后续可单独使用缩写 | TCP/IP |
| 极通用的缩写可不标注全称 | CPU、GPU、RAM |

### 3.3 多义术语处理

对存在多义或争议的术语：
- 在页面中选择最通用的定义，并在"待核查问题"中标注其他含义
- 涉及术语争议的条目汇总到 `99-待核查与问题清单/术语争议.md`

## 4. 文件与目录命名

| 项目 | 规范 | 示例 |
|------|------|------|
| 一级目录 | 两位数字 + `-` + 中文描述 | `03-算法与数据结构/` |
| Markdown 文件 | 中文文件名，UTF-8 编码 | `动态规划.md` |
| 图片/图表 | 英文小写 + 连字符 | `cpu-pipeline.png` |

## 5. 符号与记号约定

- 时间复杂度使用标准大 O 记号：O(n)、O(n log n)
- 伪代码优先使用类似 Python 的缩进风格
- 数学符号遵循 AMS 标准

## 6. 待核查问题

- 部分术语的业界标准中文译名需进一步确认
- 新兴领域（如 LLM、Agent）的术语体系仍在演化，需持续跟踪
