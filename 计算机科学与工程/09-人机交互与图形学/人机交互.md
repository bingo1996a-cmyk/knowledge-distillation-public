# 人机交互与图形学

## 1. 一句话定义

人机交互研究人类与计算系统之间的交互设计，图形学研究图像的生成、处理和显示，二者共同决定计算系统的用户体验和视觉呈现。

## 2. 核心问题

- 如何设计直观、高效、可访问的用户界面？
- 如何生成真实感和交互式的 2D/3D 图形？
- 如何将抽象数据转化为可理解的视觉表示？

## 3. 知识框架

| 子领域 | 核心内容 | 代表性技术/系统 |
|--------|----------|-----------------|
| 人机交互 | 可用性、交互设计、用户研究 | 图形界面、语音交互、触控 |
| 计算机图形学 | 渲染管线、几何建模、动画 | OpenGL、Vulkan、光线追踪 |
| 可视化 | 数据可视化、信息可视化、科学可视化 | D3.js、VTK |
| 扩展现实 | VR、AR、MR | Apple Vision Pro、Meta Quest |

## 4. 关键概念

- **可用性（Usability）**：系统被高效、有效、满意使用的能力
- **渲染管线**：顶点处理→光栅化→片元处理→输出合并的标准图形流水线
- **直接操作**：用户通过拖拽、点击、手势直接操作屏幕对象的交互范式
- **可视化编码**：将数据属性映射到视觉通道（位置、颜色、大小、形状）

## 5. 典型机制

### 5.1 实时渲染管线

```
顶点数据 → 顶点着色器 → 光栅化 → 片元着色器 → 帧缓冲 → 屏幕
```

### 5.2 交互设计原则

| 原则 | 说明 |
|------|------|
| 可见性 | 系统状态应清晰可见 |
| 反馈 | 每次操作应有即时响应 |
| 约束 | 防止用户犯错 |
| 一致性 | 相似操作应有相似结果 |
| 可逆性 | 操作应可撤销 |

## 6. 经典问题

- Fitts' Law：目标大小和距离对选择时间的影响
- 渲染质量与帧率的权衡
- 3D 场景的可见性判定（Occlusion Culling）
- 大规模图数据的可视化

## 7. 工程实践

- 使用 CSS/HTML 实现响应式用户界面
- 使用 Three.js 构建简单的 3D 交互场景
- 用 D3.js 或 ECharts 实现数据可视化仪表盘
- 进行简单的可用性测试（Usability Testing）
