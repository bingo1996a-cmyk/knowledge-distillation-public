# 扩展现实

## 1. 一句话定义

扩展现实（XR）涵盖虚拟现实（VR）、增强现实（AR）和混合现实（MR），通过在现实世界叠加虚拟信息或完全构建虚拟环境，重新定义人与信息的交互方式。

## 2. 核心问题

- 如何实时融合虚拟内容和真实世界？
- 如何消除 VR 中的眩晕感和不适？
- 让用户感觉身临其境（临在感/Presence）的关键是什么？

## 3. 知识框架

| 技术 | 核心特点 | 典型设备 |
|------|----------|----------|
| VR（虚拟现实）| 完全替代真实世界视觉 | Meta Quest、Valve Index |
| AR（增强现实）| 在真实世界上叠加虚拟信息 | 手机 AR、AR 眼镜 |
| MR（混合现实）| 虚拟与真实物体实时交互 | Apple Vision Pro、HoloLens |

## 4. 关键概念

- **临在感（Presence）**：用户感觉"我在那里"而非"我在看屏幕"——VR 的核心体验目标
- **六自由度（6DoF）**：3 个平移自由度 + 3 个旋转自由度——允许用户在空间中自然移动
- **SLAM（同步定位与建图）**：设备在未知环境中实时构建地图并定位自身——AR 的核心基础算法
- **延迟-临在感关系**：头部运动到显示更新的延迟需 < 20ms，否则产生眩晕
- **空间计算**：将数字交互从屏幕扩展到三维物理空间——Apple 定义的新代际

## 5. 典型机制

### 5.1 VR 渲染的特殊挑战

```
普通游戏：60fps，单眼渲染
VR 渲染：90-120fps，双眼分别渲染
计算量 ≈ 2× 分辨率 × 1.5-2× 帧率
→ 需要注视点渲染（Foveated Rendering）等优化
```

### 5.2 AR 的核心技术栈

```
传感器（摄像头+IMU+深度）→ SLAM 定位
                     ↓
              场景理解（平面检测/物体识别）
                     ↓
              虚拟内容渲染与对齐
                     ↓
              显示（光学透视/视频透视）
```

## 6. 经典问题

- VR 眩晕——视觉-前庭系统冲突
- 遮挡处理——虚拟物体如何在真实物体后面
- 光照一致性——虚拟物体的光照需匹配真实环境
- 延迟问题——从传感器到显示的全链路延迟
- 交互范式的探索——什么是空间计算的"鼠标和键盘"

## 7. 工程实践

- 用 Unity + XR Interaction Toolkit 或 Unreal Engine 开发 VR 应用
- 用 ARKit（iOS）或 ARCore（Android）开发手机 AR 体验
- 理解注视点渲染和异步时间扭曲（ATW）等 VR 性能优化
- 设计空间 UI——从 2D 平面到 3D 空间的交互转换

## 8. 与其他主题的关系

| 相关主题 | 关系 |

| 计算机视觉 | SLAM、物体追踪是 AR 的关键 |
| GPU/体系结构 | XR 的极端性能需求推动硬件创新 |
