# 计算机图形学

## 1. 一句话定义

计算机图形学研究如何在计算机中表示、生成和显示图像，涵盖从 3D 几何建模到真实感渲染的完整流程。

## 2. 核心问题

- 如何将 3D 场景转化为屏幕上的 2D 像素？
- 如何模拟光与物体表面的交互以产生真实感图像？
- 如何高效表示和处理复杂的几何形状？

## 3. 知识框架

| 子领域 | 核心内容 | 关键技术 |
|--------|----------|----------|
| 几何建模 | 曲面、网格、隐式表示 | Bézier、NURBS、细分曲面 |
| 渲染 | 从 3D 场景生成 2D 图像 | 光栅化、光线追踪 |
| 着色 | 材质、光照模型 | Phong、PBR、BRDF |
| 纹理与贴图 | 表面细节的映射和过滤 | 漫反射贴图、法线贴图、Mipmap |
| 动画 | 关键帧、骨骼、物理模拟 | 插值、蒙皮、粒子系统 |

## 4. 关键概念

- **渲染管线**：顶点处理→图元装配→光栅化→片元处理→帧缓冲输出的标准流程
- **光栅化 vs 光线追踪**：光栅化（投影+扫描线填充，快）vs 光线追踪（模拟光线路径，真实但慢）
- **变换矩阵**：模型变换（局部→世界）→ 视图变换（世界→相机）→ 投影变换（相机→屏幕）
- **PBR（基于物理的渲染）**：遵循能量守恒和真实物理反射模型的渲染方法
- **可微渲染**：渲染过程可求导——是神经渲染和 3D 重建的基础

## 5. 典型机制

### 5.1 图形渲染管线

```
顶点数据 → 顶点着色器（坐标变换）
    → 曲面细分/几何着色器（可选）
    → 光栅化（转换为片元）
    → 片元着色器（逐像素颜色计算）
    → 深度/模板测试 → 混合 → 帧缓冲
```

### 5.2 光线追踪 vs 光栅化

| 特性 | 光栅化 | 光线追踪 |
|------|--------|----------|
| 速度 | 极快（实时）| 较慢（历史准实时）|
| 全局光照 | 需技巧/Baking | 自然支持 |
| 反射/折射 | 需额外技术 | 自然产生 |
| 主要用途 | 游戏、实时应用 | 电影、建筑可视化 |

## 6. 经典问题

- 可见性判定（Occlusion Culling）— 哪些物体被遮挡
- 阴影映射（Shadow Mapping）中的走样问题
- 透明物体渲染中的深度排序
- 细节层次（LOD）管理

## 7. 工程实践

- 用 Three.js 或 WebGL 创建简单的 3D 场景
- 实现 Blinn-Phong 着色模型
- 理解 GPU 架构（SIMD 宽度、Warp/Wavefront）如何影响渲染性能
- 使用 Blender 理解渲染管线的实际应用

## 8. 与其他主题的关系

| 相关主题 | 关系 |
|----------|------|
| 线性代数 | 变换矩阵是坐标转换的核心 |
| GPU/体系结构 | GPU 是为图形运算优化的并行处理器 |
| 深度学习 | NeRF、3D Gaussian Splatting 是图形学+AI 交叉 |
