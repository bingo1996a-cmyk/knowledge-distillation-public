# 可视化

## 1. 一句话定义

可视化将抽象数据转化为可感知的视觉形式，利用人类视觉系统的高带宽和模式识别能力来理解复杂数据和现象。

## 2. 核心问题

- 如何为不同数据类型选择最有效的视觉编码？
- 如何避免视觉误导和认知偏差？
- 如何在大规模高维数据中揭示隐藏的结构？

## 3. 知识框架

| 子领域 | 处理的数据类型 | 典型技术 |
|--------|---------------|----------|
| 数据可视化 | 表格数据、多维数据 | 柱状图、散点图、平行坐标 |
| 信息可视化 | 层次、网络、文本数据 | 树图、力导向图、词云 |
| 科学可视化 | 标量/向量/张量场 | 等值面、体绘制、流线 |
| 可视分析 | 交互式探索数据 | 刷选、联动视图、缩放过滤 |

## 4. 关键概念

- **视觉通道**：位置、长度、角度、面积、颜色（色调/饱和度/亮度）、形状——不同的视觉通道有不同数据映射精度
- **可视化编码原则**：数据属性 → 视觉通道的选择应基于数据的类型和视觉感知效率
- **预注意（Pre-attentive）处理**：某些视觉属性（颜色、大小、方向）在 200ms 内被自动处理——高效可视化的基础
- **谎言因子（Lie Factor）**：视觉效果的大小 ÷ 数据差异的大小——好的可视化应接近 1
- **数据墨水比例（Data-Ink Ratio）**：Tufte 原则——最大化有意义的视觉元素，最小化装饰

## 5. 典型方法

### 5.1 视觉通道排序（Mackinlay 排名）

```
定量数据（数值）:
  位置 > 长度 > 角度/斜率 > 面积 > 亮度 > 颜色饱和度

类别数据（标签）:
  位置 > 颜色色调 > 形状 > 纹理
```

### 5.2 常用可视化图表选择

| 数据关系 | 推荐图表 |
|----------|----------|
| 比较 | 柱状图、分组柱状图 |
| 时序趋势 | 折线图、面积图 |
| 分布 | 直方图、箱线图、密度图 |
| 相关性 | 散点图、热力图 |
| 构成 | 堆积柱状图、饼图、树图 |
| 层次 | 树图、旭日图 |
| 网络关系 | 力导向图、和弦图 |

## 6. 经典问题

- 高维数据的可视化（维数灾难）
- 大数据量下的渲染性能
- 误导性可视化——轴截断、面积感知偏差
- 颜色盲友好设计

## 7. 工程实践

- 用 Matplotlib/Seaborn（Python）或 ggplot2（R）绘制统计图表
- 用 ECharts 或 D3.js 构建交互式 Web 可视化
- 使用 Tableau 或 Observable Plot 快速探索数据
- 设计仪表盘（Dashboard）时遵循信息层级和视觉焦点原则
